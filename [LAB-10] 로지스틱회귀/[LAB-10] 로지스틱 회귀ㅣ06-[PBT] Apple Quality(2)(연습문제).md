## 4. 가정확인

### 문제 21

종속변수 `Quality`를 0/1로 라벨링했을 때, `good`에 부여되는 숫자는 무엇인가요? *(정수 1개)*

**정답.** `1`

**해설.**
`my_prep.labeling()`은 **알파벳 순서**로 0부터 매기므로 `bad = 0`, `good = 1`이 됨.

**이 방향이 이후 모든 해석을 결정함.** 모형이 예측하는 것은 **P(Quality = good)** 이고, 뒤에 나오는 오즈비는 전부 "사과가 `good`일 오즈"에 대한 값임. 만약 라벨이 반대로 붙었다면 모든 오즈비가 역수가 되어 결론이 뒤집힘.

### 문제 22

7개 변수를 모두 넣은 기준선 모형에서, 유의수준 5% 기준으로 유의하지 않은 독립변수는 몇 개인가요? *(정수 1개)*

**정답.** `1`

**해설.**
`Crunchiness` **하나뿐**임(p = 0.253). 나머지 6종은 모두 p < 0.001로 유의함.

**이변량 분석에서는 3종(`Weight`·`Acidity`·`Crunchiness`)이 무관했는데, 모형에 넣으니 탈락 후보가 1종으로 줄었음.** 단독 비교와 다변량 모형은 다른 질문에 답한다는 뜻임.

### 문제 23

이변량 분석(T검정)에서 유의확률 0.797로 "차이가 없다"고 나왔지만, 기준선 모형에서는 z = −13.70으로 강하게 유의해진 변수는 무엇인가요? *(변수명 1개)*

**정답.** `Acidity`

**해설.**
T검정 p = 0.797 → 기준선 모형 p < 0.001로 **완전히 뒤집힘.** 오즈비는 **0.745**로, 산도가 1점 높아지면 `good`일 오즈가 약 **25.5% 감소**함.

`Weight`도 같은 일이 벌어짐(T검정 p = 0.928 → z = 9.40).

**즉 EDA에서 유의하지 않다는 이유만으로 변수를 버렸다면, 강력한 예측 변수 2개를 통째로 잃었을 것임.**

### 문제 24

문제 23처럼 단독 비교에서는 효과가 가려져 있다가 다른 변수를 통제하자 드러나는 현상을 무엇이라 하나요? *(용어 1개)*

**정답.** `억제효과`

**해설.**
억제효과(suppression)임. 다른 변수가 만들어내는 변동을 걷어내야 비로소 그 변수의 순수한 효과가 보이는 경우임.

**이것이 "탐색적 분석 결과만으로 변수를 버리면 안 되는" 이유임.** 변수 제거의 판정 시점은 EDA가 아니라 **모형 적합 이후**임.

### 문제 25

기준선 모형에서 표준화 계수(βstd)가 가장 큰 변수는 무엇인가요? *(변수명 1개)*

**정답.** `Size`

**해설.**
`Size` **1.252**가 가장 크고, `Sweetness` 1.105, `Juiciness` 0.854 순임.

**영향력 비교는 오즈비가 아니라 βstd로 함.** 오즈비는 "그 변수 1점당" 값이라 변수마다 1점의 의미가 다르면 직접 비교할 수 없음. 값의 범위를 통일한 표준화 계수라야 크기를 견줄 수 있음.

### 문제 26

Box-Tidwell 검정 결과, 7종 중 로짓 선형성을 위배한 변수는 몇 종인가요? *(정수 1개)*

**정답.** `5`

**해설.**
`Weight`·`Crunchiness`·`Juiciness`·`Acidity`·`Size` **5종**이 p < 0.05로 위배임.

**로지스틱 회귀에서 "선형성"은 종속변수와의 직선 관계가 아니라 로짓과의 직선 관계임.** 이것이 깨지면 모형이 표현할 수 있는 관계의 모양 자체가 데이터와 맞지 않는다는 뜻임.

### 문제 27

위배 정도가 가장 심한(검정통계량 z의 절댓값이 가장 큰) 변수는 무엇인가요? *(변수명 1개)*

**정답.** `Weight`

**해설.**
`Weight` **z = 11.16**이 가장 크고, `Crunchiness` 9.85, `Juiciness` −8.08, `Acidity` −5.55, `Size` 4.32 순임.

**처방은 위배가 가장 심한 것부터 하나씩 함.** 한꺼번에 고치면 어느 처방이 무엇을 바꿨는지 알 수 없기 때문임.

### 문제 28

7종 중 선형성을 충족해 처방 대상에서 제외된 변수는 무엇인가요? *(변수명 1개)*

**정답.** `Sweetness`

**해설.**
`Sweetness`(p = 0.545)와 `Ripeness`(p = 0.295) 둘 다 초기 검정은 통과했지만, **루프를 돌리는 도중 `Ripeness`는 위배로 바뀌어 5라운드에서 처방됨.** 끝까지 원본으로 남은 것은 `Sweetness` 하나임.

**초기 진단 결과가 최종 처방 목록이 아님을 보여주는 대목임.**

### 문제 29

`Weight`를 처방한 다음 라운드에서 다시 진단했을 때, 위배로 잡힌 변수는 몇 종인가요? *(정수 1개)*

**정답.** `5`

**해설.**
라운드 1도 5종, 라운드 2도 **5종**임. 하나를 고쳤는데도 **숫자가 줄지 않음.**

라운드별 위배 개수는 5 → 5 → 3 → 3 → 2 → 1 → 0으로 움직임. **한 변수를 고치면 다른 변수의 진단 결과가 함께 바뀌기 때문**이며, 이것이 처방 후 반드시 **재진단**을 해야 하는 이유임.

### 문제 30

루프가 종료되기까지 실제로 처방이 이루어진 라운드는 몇 번인가요? *(정수 1개)*

**정답.** `6`

**해설.**
`Weight` → `Crunchiness` → `Juiciness` → `Acidity` → `Ripeness` → `Size` 순으로 **6개 라운드**에서 처방됐고, **7라운드에서 위배 변수가 사라져 종료**됨.

처방 순서도 눈여겨볼 만함. `Crunchiness`는 T검정 p = 0.985(완전 무관), 기준선 모형 p = 0.253(제거 후보)이었는데 **선형성 진단에서는 두 번째로 심한 위배**로 잡힘.

### 문제 31

6종에 공통으로 채택된 처방 방법은 무엇인가요? *(영문 1개)*

**정답.** `square`

**해설.**
6종 모두 **제곱항 추가(square)** 로 처방됨. `recipe`에 `method: square`와 중심화 기준값이 함께 기록되어, 신규 데이터에도 **똑같은 기준으로** 재현할 수 있음.

**기준값을 다시 계산하면 안 됨.** 신규 데이터의 평균으로 중심화하면 학습 때와 어긋나 예측이 망가짐.

### 문제 32

제곱항과 함께 후보였던 로그 변환이 이 데이터에서는 한 번도 시도되지 않았습니다. 7종 모두가 포함하고 있어 로그를 쓸 수 없게 만든 값은 무엇인가요? *(용어 1개)*

평행이동해서 억지로 쓸 수는 있지만 **이동량이 자의적이어서 계수 해석이 무너지므로** 기본 설정에서는 시도하지 않음(`allow_shifted_log = False`).

제곱항으로도 로그 변환으로도 해소되지 않아 구간화·스플라인이 필요하다고 기록된 변수는 몇 개인가요? *(정수 1개)*

### 문제 35

제곱항이 모형에 있으면 1차항이 유의하지 않아도 남겨야 한다는 원칙을 무엇이라 하나요? *(용어 1개)*

**후진소거법과 정면으로 충돌하는 지점임.** 자동 규칙은 유의하지 않은 1차항을 지우려 하지만, 여기서는 통계적 원칙이 앞섬. 실제 판단은 #10의 성능 비교표에서 나란히 놓고 함.

성능 비교를 위해 정의한 전처리 체크포인트는 모두 몇 개인가요? *(정수 1개)*

### 문제 37

8개 체크포인트 전부에 공통으로 적용된 전처리 옵션은 무엇인가요? *(옵션명 1개)*

### 문제 38

가정 검정을 반영한 계열에서 후진소거법이 제거한 변수는 무엇인가요? *(변수명 1개)*

`Crunchiness_c`(p = 0.787)가 제거됨. 미반영 계열에서는 원본 `Crunchiness`(p = 0.253)가 제거됐음.

**문제는 `Crunchiness_c`가 `Crunchiness_c2`의 짝인 1차항이라는 점임.** 짝을 지우면 계층 원칙 위반이므로, 이 자동 제거는 그대로 받아들이면 안 됨.

### 문제 39

정규화를 적용한 3번과 적용하지 않은 2번을 비교하면, 성능 지표 중 값이 달라지는 것은 몇 개인가요? *(정수 1개)*

**정규화는 계수의 척도만 바꿀 뿐 모형 자체를 바꾸지 않기 때문임.** 로지스틱 회귀에서 스케일링은 성능 향상 수단이 아니라 **계수 비교를 편하게 하는 도구**임.

### 문제 40

AIC가 가장 낮은(가장 좋은) 모델의 이름은 무엇인가요? *(모델명 1개)*

**정답.** `5_가정반영+후진소거`

**해설.**
AIC **3672.041**로 최소임. 그다음이 `4_가정반영` 3673.968임.

**AUC 0.824 → 0.868, AIC 4128.9 → 3672.0.** 이상치 대체·공선성 제거·정규화를 전부 합친 것보다 **로짓 선형성 처방 하나가 압도적으로 큰 개선**을 만들었음. 기계적 전처리는 잡음을 다듬는 일이지만, 제곱항 추가는 **모형이 표현할 수 있는 관계의 모양 자체를 바꾸는 일**이기 때문임.

### 문제 41

`compare_models()`가 1순위로 지목한 모델을 그대로 쓰지 않고, 실제로 최종 채택한 모델은 무엇인가요? *(모델명 1개)*

**정답.** `4_가정반영`

**해설.**
자동 선택은 근소 격차 그룹 안에서 변수가 하나 적은 `5_가정반영+후진소거`를 1순위로 지목함. 하지만 5번이 지운 변수가 제곱항의 짝인 `Crunchiness_c`이므로, **계층 원칙에 따라 4번을 채택**함.

**간명성 규칙이 통계적 원칙보다 앞설 수는 없음.** 자동 선택 결과는 언제나 분석자가 검토해야 함.

### 문제 42

두 모델의 AIC 차이는 얼마인가요? *(소수 둘째 자리)*

**정답.** `1.93`

**해설.**
3673.968 − 3672.041 = **1.93**임.

**이 숫자가 판단의 근거임.** 변수 하나를 지워 얻는 AIC 이득이 2도 안 되는데, 그 대가로 계층 원칙을 깨야 한다면 남기는 쪽이 맞음. "원칙이니까 남긴다"가 아니라 **"이득이 이만큼 작으니 남긴다"** 로 말해야 보고서가 됨.

## 6. 결과보고

### 문제 43

최종 채택 모델의 독립변수는 몇 개인가요? *(정수 1개)*

**정답.** `13`

**해설.**
`Sweetness` 1개 + 제곱항 처방을 받은 6종 × (1차항 + 제곱항) 2개 = **13개**임.

원래 7개였던 변수가 13개로 늘어남. **곡선을 표현할 수 있게 된 대가로 모형이 복잡해진 것**이며, 이는 한계점에 기록할 사항임.

### 문제 44

모형 적합도 보고에 제시된 Pseudo R²는 얼마인가요? *(소수 셋째 자리)*

**정답.** `0.342`

**해설.**
LL = −1822.984, LL-Null = −2772.581 → LLR χ²(13) = 1899.193, p < .001, Pseudo R² = **0.342**로 매우 우수한 적합임.

> 참고 — 성능 비교표에는 같은 값이 `0.343`으로 찍힘. 실제 값이 0.3425 부근이라 **반올림 경계에 걸려 표시가 갈린 것**이지 다른 값이 아님. 보고서에 옮길 때는 **어느 출력에서 가져온 값인지** 밝혀야 검토가 가능함.

**Pseudo R²는 선형회귀의 R²처럼 "분산 설명 비율"로 읽지 않음.** 보통 0.2 ~ 0.4면 매우 우수한 적합으로 봄.

### 문제 45

13개 독립변수 중 유의수준 5% 기준으로 유의하지 않은 것은 무엇인가요? *(변수명 1개)*

**정답.** `Crunchiness_c`

**해설.**

### 문제 54

"산도가 낮을수록 `good`이다"라는 결과를 두고 "산도를 인위적으로 낮추면 사과가 좋아진다"고 말할 수는 없습니다. 이 분석이 밝힌 것은 인과관계가 아니라 무엇인가요? *(용어 1개)*

**정답.** `연관관계`

**해설.**
관측 데이터로 적합한 회귀모형은 **연관관계(association)** 를 말할 뿐임. 인과를 주장하려면 실험 설계나 인과추론 절차가 필요함.

이 데이터에는 한계가 더 있음. 값이 이미 표준화된 상태라 **"크기 1점"이 몇 mm인지 알 수 없어 오즈비를 현장 단위로 옮길 수 없고**, `good`/`bad` 판정 기준도 공개되어 있지 않아 모형이 학습한 것은 "객관적 품질"이 아니라 **"이 데이터를 만든 사람의 판정 기준"** 일 수 있음.
