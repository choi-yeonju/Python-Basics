## 0. 전체 그림

```
가설검정
    │
    ├── ① 정규성 (Normality)
    ├── ② 등분산성 (Homoscedasticity)
    └── ③ 독립성 (Independence)
```

세 가지가 만족되면 → p-value를 믿을 수 있음
만족하지 않으면 → 비모수 검정 사용 or 데이터 변환

**실무/실습 진행 순서**: ① 정규성 확인 → ② 등분산성 확인(정규성 결과에 따라 Bartlett/Levene 자동 분기) → ③ 적절한 가설검정

## 1. 정규성 (Normality)

**질문**: 검정 대상 데이터가 정규분포를 따르는가?

**필요한 이유**: t-test, ANOVA, Pearson 상관분석 등은 "정규분포를 따른다"는 가정 위에서 통계량이 유도됨. 가정이 깨지면 p-value가 왜곡됨.

| 방법                                                      | 내용                                                            |
| --------------------------------------------------------- | --------------------------------------------------------------- |
| 히스토그램                                                | 종모양(bell shape)인지 육안 확인                                |
| 왜도(Skewness)                                            | 좌우 대칭성. 보통 -1~1 이면 큰 문제 없음                        |
| 첨도(Kurtosis)                                            | 뾰족한 정도                                                     |
| **Shapiro-Wilk** (`scipy.stats.shapiro`)          | 실무에서 가장 많이 사용. H0: 정규분포다                         |
| **D'Agostino-Pearson** (`scipy.stats.normaltest`) | 왜도+첨도를 결합한 정규성 검정. Shapiro-Wilk와 함께 자주 비교됨 |
| Kolmogorov-Smirnov (K-S)                                  | 표본 수가 매우 클 때(n>2000) 대안                               |
| Q-Q Plot                                                  | 검정통계량 없이 점들이 대각선에 붙는지 시각 판단                |

**공통 판단 기준**: p ≥ 0.05 → 정규성 만족 / p < 0.05 → 정규성 위반

> `shapiro`와 `normaltest`는 검정 방식이 다름(전자는 통계량 W 기반, 후자는 왜도·첨도 결합)이라 결과가 항상 100% 일치하진 않음. 두 개를 같이 돌려서 비교해보는 것도 좋은 습관.

## 2. 등분산성 (Homoscedasticity)

**질문**: 비교할 그룹들의 분산이 같은가?

| 검정     | 사용 조건                                 | scipy 함수               |
| -------- | ----------------------------------------- | ------------------------ |
| Bartlett | 정규성을 만족할 때 사용                   | `scipy.stats.bartlett` |
| Levene   | 정규분포가 아니어도 사용 가능 (더 robust) | `scipy.stats.levene`   |

두 검정 모두 H0: "분산이 같다" / p≥0.05 → 등분산, p<0.05 → 등분산 아님

**Levene 검정의 `center` 파라미터**:

- `center='median'` (기본값): 중앙값 기준, 이상치에 덜 민감해서 실무에서 선호
- `center='mean'`: 평균 기준, 정규분포에 가까울 때 사용
- `center='trimmed'`: 절사평균 기준

## 3. 독립성 (Independence)

**질문**: 관찰치들이 서로 영향을 주지 않는가?

별도의 검정통계량 없이 **데이터 수집(연구 설계) 단계**에서 확보 (무작위 샘플링, 반복측정 회피 등).

회귀분석 맥락에서는 잔차(residual)의 독립성으로 재등장 → **Durbin-Watson 검정**으로 확인 (2에 가까우면 독립).

### 4-1. `ci()` — 모평균 신뢰구간

```python
from math import sqrt
from pandas import DataFrame
from scipy.stats import t
from scipy.stats import normaltest, bartlett, levene

def ci(data, column=None, clevel=0.95):
    """
    주어진 데이터에 대한 모평균의 신뢰구간을 계산하는 함수

    Args:
        data (Series | list | ndarray | DataFrame): 연속형 데이터 또는 데이터프레임
        column (str): data가 데이터프레임인 경우 대상 컬럼명 (기본값: None)
        clevel (float): 신뢰수준 (기본값: 0.95)

    Returns:
        tuple: (신뢰구간 하한, 신뢰구간 상한)
    """
    if column is not None:
        data = data[column]

    n = len(data)                    # 표본 크기
    dof = n - 1                      # 자유도
    sample_mean = data.mean()        # 표본 평균
    sample_std = data.std()          # 표본 표준편차
    sample_std_error = sample_std / sqrt(n)  # 표준오차

    return t.interval(clevel, dof, loc=sample_mean, scale=sample_std_error)
```

**핵심 포인트**:

- 표준정규분포(Z)가 아니라 **t분포**를 사용 → 모표준편차를 모르고 표본표준편차로 추정하기 때문. 표본이 작을수록 t분포가 정규분포보다 꼬리가 두꺼워서 구간이 더 넓게 잡힘.
- `dof = n - 1`: 자유도는 표본평균을 이미 추정에 썼기 때문에 하나 줄어듦.
- `t.interval(clevel, dof, loc=..., scale=...)`: scipy의 t분포 객체에서 신뢰수준에 해당하는 구간을 바로 반환해주는 함수. `loc`은 중심(표본평균), `scale`은 표준오차.

### 4-2. `test_assumptions()` — 정규성 + 등분산성 일괄 검정 (핵심 함수)

```python
def test_assumptions(data, columns=None, alpha=0.05, center="median"):
    """
    가설 검정의 가정(정규성, 등분산성)을 일괄적으로 검정하여 결과표를 반환하는 함수

    각 변수에 대해 정규성 검정(normaltest)을 수행하고, 변수가 두 개 이상인 경우
    등분산성 검정을 수행한다. 이때 모든 변수가 정규성을 충족하면 Bartlett 검정을,
    하나라도 충족하지 못하면 Levene 검정을 선택적으로 사용한다.

    Args:
        data (DataFrame): 검정대상이 되는 데이터프레임
        columns (list): 검정에 사용할 컬럼명 목록 (기본값: None -> 수치형 컬럼 전체)
        alpha (float): 유의수준 (기본값: 0.05)
        center (str): Levene 검정시 사용할 중심 경향값 (기본값: "median")

    Returns:
        DataFrame: field를 인덱스로 하는 검정 결과표
                   (test, statistic, p-value, result 컬럼 포함)
    """
    if columns is None:
        columns = data.select_dtypes(include="number").columns.tolist()

    if type(columns) == str:
        columns = [columns]

    report = []
    normal_dist = True  # 모든 변수가 정규성을 충족하는지 여부

    # 각 변수에 대한 정규성 검정
    for c in columns:
        s, p = normaltest(data[c])
        normalize = p >= alpha

        report.append({
            "field": c,
            "test": "normaltest",
            "statistic": s,
            "p-value": p,
            "result": normalize
        })

        normal_dist = normal_dist and normalize

    # 변수가 두 개 이상인 경우 등분산성 검정
    if len(columns) > 1:
        samples = [data[c].astype("float") for c in columns]

        if normal_dist:  # 모든 변수가 정규성 충족 -> Bartlett 검정
            name = "Bartlett"
            s, p = bartlett(*samples)
        else:            # 하나라도 정규성 미충족 -> Levene 검정
            name = "Levene"
            s, p = levene(*samples, center=center)

        report.append({
            "field": name,
            "test": "equal_var",
            "statistic": s,
            "p-value": p,
            "result": p >= alpha
        })

    return DataFrame(report).set_index("field")
```

**동작 흐름 정리**:

```
data, columns 입력
    ↓
columns 미지정 시 → 수치형 컬럼 전체 자동 선택
    ↓
각 컬럼마다 normaltest() 실행 → 정규성 결과 report에 누적
    ↓
normal_dist 플래그: 모든 컬럼이 정규성 만족해야 True 유지 (AND 누적)
    ↓
컬럼이 2개 이상이면:
    normal_dist == True  → Bartlett 검정 (정규성 만족 가정)
    normal_dist == False → Levene 검정 (정규성 미충족 대응)
    ↓
결과표(DataFrame) 반환: field / test / statistic / p-value / result
```

**설계상 눈여겨볼 포인트**:

- `normal_dist = normal_dist and normalize` → 파이썬 논리 AND 누적 패턴. 컬럼이 3개, 4개로 늘어나도 **단 하나라도** 정규성 미충족이면 최종적으로 Levene으로 자동 전환됨. "실무에서 가정 위반 시 대안을 자동 선택"하는 로직을 코드로 그대로 구현한 것.
- `data[c].astype("float")`: Bartlett은 정수형(int) 컬럼을 넣으면 에러가 나거나 타입 이슈가 생길 수 있어서 명시적으로 float 변환. 반면 주석에 적혀있듯 Levene은 이런 제약이 상대적으로 덜함.
- `result` 컬럼의 의미가 검정마다 다름: normaltest row에서는 "정규성 만족 여부", Bartlett/Levene row에서는 "등분산 만족 여부" — 같은 컬럼명이지만 문맥상 다른 가설을 나타내니 결과표 해석할 때 주의.

### 5-2. 정규성 검정 — Shapiro-Wilk vs normaltest 비교

```python
normal_tmpl = "statistic:{0:.3f}, p-value: {1:.3f}, 정규성 충족 여부: {2}"

# Shapiro-Wilk
s, p = shapiro(origin['store1'])
normal_tmpl.format(s, p, p >= 0.05)

s, p = shapiro(origin['store2'])
normal_tmpl.format(s, p, p >= 0.05)

# D'Agostino-Pearson (normaltest)
s, p = normaltest(origin['store1'])
normal_tmpl.format(s, p, p >= 0.05)

s, p = normaltest(origin['store2'])
normal_tmpl.format(s, p, p >= 0.05)
```

→ 같은 데이터를 두 가지 정규성 검정으로 각각 확인하는 연습. 두 검정 결과가 대체로 일치하는지 비교해보는 게 학습 포인트.

### 5-3. 등분산성 검정 — Bartlett vs Levene

```python
var_tmpl = "statistic: {0:.3f}, p-value: {1:.3f}, 등분산성 충족 여부: {2}"

# Bartlett (정규성 만족 가정)
s, p = bartlett(origin['store1'].astype('float'),
                 origin['store2'].astype('float'))
var_tmpl.format(s, p, p >= 0.05)

# Levene (파라미터 수 제한 없음 — 그룹이 몇 개든 가능)
s, p = levene(origin['store1'], origin['store2'], center='median')
var_tmpl.format(s, p, p >= 0.05)
```

> 노트북 주석 그대로: **"파라미터 수의 제한이 없다"** — Levene은 `bartlett(a, b)`처럼 두 그룹만이 아니라 `levene(a, b, c, d, ...)`처럼 여러 그룹을 한 번에 넣을 수 있음. 다중 그룹 ANOVA 사전 검정에서 이 유연성 때문에 Levene이 더 널리 쓰임.

## 6. 대표 예제 3개 (개념 → 검정 방향 감 잡기용)

### 예제 1. 신약 효과 검정 (왼쪽 단측검정)

| 항목        | 내용                                                                  |
| ----------- | --------------------------------------------------------------------- |
| H0          | μ = 7 (신약은 효과가 없다)                                           |
| H1          | μ < 7 (신약이 치료기간을 단축시킨다)                                 |
| 검정 방향   | 왼쪽 단측검정                                                         |
| 유의수준 α | 0.05                                                                  |
| 검정통계량  | t = -2.45                                                             |
| 기각역      | t < -1.699                                                            |
| 판단        | -2.45 < -1.699 →**H0 기각**                                    |
| 결론        | 신약은 기존 약보다 치료기간을 단축한다고 볼 충분한 통계적 근거가 있다 |

### 예제 2. 병원 검사 — 왼쪽 단측 vs 양측 비교

**혈압(운동 프로그램, 왼쪽 단측)**: H0: μ=120, H1: μ<120, p=0.18 > 0.05 → **H0 기각 못함** (효과 있다고 보기엔 근거 부족)

**혈당(스크리닝, 양측)**: H0: μ=100, H1: μ≠100, 기각역 z<-1.96 또는 z>1.96

> 의료 맥락에서 2종 오류(실제 이상인데 정상으로 오진)가 1종 오류보다 훨씬 치명적이라, 스크리닝 설계 시 α를 다소 높여서라도 β를 낮추는 방향으로 가는 경우가 많음.

### 예제 3. 품질검사 — 양측 vs 왼쪽 단측

**음료 용량(양측)**: H0: μ=500, H1: μ≠500, z=2.40 > 1.96 → **H0 기각** (유의한 차이 있음)

**부품 강도(왼쪽 단측, 최소기준)**: H0: μ≥50, H1: μ<50, α=0.01(엄격), z<-2.33이면 불량 판정

## 8. 헷갈리기 쉬운 포인트 모음

- **`shapiro` vs `normaltest`**: 둘 다 정규성 검정이지만 알고리즘이 다름 (W 통계량 vs 왜도·첨도 결합). 결과가 다를 수 있으니 둘 다 참고.
- **Bartlett vs Levene**: Bartlett은 정규성 가정 필요 + 2그룹 특화 느낌, Levene은 정규성 불필요 + 그룹 수 제한 없음 → 실무에서 Levene이 더 범용적으로 쓰임.
- **`result` 컬럼 의미 문맥 의존**: `test_assumptions()` 결과표에서 같은 `result` 컬럼이라도 정규성 행인지 등분산성 행인지에 따라 "무엇을 만족했다는 건지"가 달라짐.
- **"H0 기각 못함" ≠ "H0가 맞다"**: 근거 부족이지 증명된 게 아님.
- **유의수준 바꾸면 판정이 뒤집힐 수 있음**: α=0.05에서는 "만족"이던 게 α=0.03(더 엄격)에서는 뒤집힐 수도, 반대로 α=0.1로 완화하면 또 달라질 수 있음. p-value 자체를 보고 문턱값에 얼마나 가까운지 같이 봐야 함.
