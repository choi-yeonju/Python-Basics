# 가설검정의 3대 가정 & 대표 예제 정리

> 작성일: 2026-07-07
> 목적: 가설검정(t-test, ANOVA, 회귀분석 등) 전제조건 + 대표 예제 3개 완전 정리

---

## 0. 전체 그림

```
가설검정
    │
    ├── ① 정규성 (Normality)
    ├── ② 등분산성 (Homoscedasticity)
    └── ③ 독립성 (Independence)
```

세 가지가 만족되면 → p-value를 믿을 수 있음
만족하지 않으면 → 비모수 검정 사용 or 데이터 변환

실무 진행 순서:
**① 정규성 확인 → ② 등분산성 확인 → ③ 적절한 가설검정(t-test/ANOVA) → ④ p-value + 효과크기 같이 해석**

---

## 1. 정규성 (Normality)

**질문**: 검정 대상 데이터가 정규분포를 따르는가?

**필요한 이유**: t-test, ANOVA, Pearson 상관분석 등 모수 검정은 "정규분포를 따른다"는 가정 위에서 통계량이 유도됨. 가정이 깨지면 p-value가 왜곡됨.

**확인 방법**

| 방법                        | 내용                                                                                     |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| 히스토그램                  | 종모양(bell shape)인지 육안 확인                                                         |
| 왜도(Skewness)              | 좌우 대칭성. 보통 -1~1 (또는 -2 ~ 2)이면 큰 문제 없음                                   |
| 첨도(Kurtosis)              | 뾰족한 정도                                                                              |
| **Shapiro-Wilk 검정** | 실무에서 가장 많이 사용. H0: 정규분포다 / p>0.05 → 정규성 만족, p<0.05 → 정규성 위반   |
| Kolmogorov-Smirnov (K-S)    | 표본 수가 매우 클 때(n>2000) Shapiro-Wilk 대신 사용                                      |
| Q-Q Plot                    | 검정통계량 없이 점들이 대각선에 붙는지 시각 판단. 표본 클 때 검정보다 신뢰하는 경우 많음 |

**주의**: Shapiro-Wilk는 표본이 크면 아주 작은 편차에도 p<0.05가 나오는 경향(민감도 과다) → 대규모 데이터에서는 육안 판단(히스토그램/Q-Q) 병행 권장.

**중심극한정리(CLT)와의 관계**: 표본 크기가 충분히 크면(n≥30 기준) 모집단이 정규분포가 아니어도 표본평균의 분포는 정규분포에 근사 → 대규모 데이터에서는 정규성 위반을 상대적으로 관대하게 봐줌.

---

## 2. 등분산성 (Homoscedasticity)

**질문**: 비교할 그룹들의 분산이 같은가?

**필요한 이유**: t-test, ANOVA는 집단 간 분산이 비슷하다고 가정. 분산 차이가 크면 평균 비교 결과가 왜곡됨.

**확인 방법**

| 검정          | 사용 조건                                                  |
| ------------- | ---------------------------------------------------------- |
| Bartlett 검정 | 정규성을 만족할 때 사용                                    |
| Levene 검정   | 정규분포가 아니어도 사용 가능 → 실무에서 더 선호 (robust) |

두 검정 모두 H0: "분산이 같다" / p>0.05 → 등분산, p<0.05 → 등분산 아님

---

## 3. 독립성 (Independence)

**질문**: 관찰치들이 서로 영향을 주지 않는가?

**필요한 이유**: 독립성이 깨지면 표본 개수가 실제보다 많아 보이는 효과가 생겨 p-value가 잘못 계산됨.

**깨지기 쉬운 경우**: 같은 사람 반복측정, 쌍둥이·가족 데이터, 시계열 데이터

**확인 방법**: 별도의 검정통계량 없음. 보통 **데이터 수집(연구 설계) 단계**에서 확보

- 무작위 샘플링
- 한 사람을 한 번만 측정
- 표본이 서로 영향 주지 않게 설계

**회귀분석 맥락에서는 다시 등장**: 잔차(residual)의 독립성 문제로 확인

- **Durbin-Watson 검정**: 잔차의 자기상관(autocorrelation) 검정. 2에 가까우면 독립, 0에 가까우면 양의 자기상관, 4에 가까우면 음의 자기상관
- VIF(다중공선성)와 헷갈리기 쉬움 → VIF는 **독립변수 간 상관**, Durbin-Watson은 **잔차의 독립성**. 서로 다른 가정 체크

## 4. 요약 표

| 가정     | 확인 내용                | 대표 검정                       | p > 0.05 의미 |
| -------- | ------------------------ | ------------------------------- | ------------- |
| 정규성   | 데이터가 정규분포인가    | Shapiro-Wilk, K-S               | 정규성 만족   |
| 등분산성 | 집단 분산이 같은가       | Levene, Bartlett                | 등분산성 만족 |
| 독립성   | 데이터끼리 영향이 없는가 | 별도 검정 없이 연구 설계로 확보 | -             |

**실무 우선순위**: 정규성 > 등분산성 (가장 자주 확인) / 독립성은 설계 단계에서 이미 확보한다고 가정

## 5. 가정 위반 시 대안

| 상황                          | 대안                                                   |
| ----------------------------- | ------------------------------------------------------ |
| 정규성 위반                   | 비모수 검정으로 전환                                   |
| 등분산성 위반 (정규성은 만족) | Welch's t-test / Welch's ANOVA (등분산 가정 없는 버전) |
| 분포 자체를 교정하고 싶을 때  | 로그 변환, Box-Cox 변환 후 재검정                      |

**모수 검정 ↔ 비모수 검정 대응표**

| 모수 검정 (정규성 가정 O) | 비모수 대안 (정규성 가정 X)      |
| ------------------------- | -------------------------------- |
| 독립표본 t-test           | Mann-Whitney U 검정              |
| 대응표본 t-test           | Wilcoxon 부호순위 검정           |
| 일원분산분석(ANOVA)       | Kruskal-Wallis 검정              |
| 반복측정 ANOVA            | Friedman 검정                    |
| Pearson 상관계수          | Spearman 상관계수, Kendall's tau |

## 6. p-value 관련 추가 개념

- **1종 오류(Type I)**: H0가 참인데 기각 (false positive). 유의수준 α = 1종 오류 허용률
- **2종 오류(Type II)**: H0가 거짓인데 채택 (false negative)
- **p-value ≠ 효과크기**: 표본이 크면 아주 작은 차이도 p<0.05로 나옴 → Cohen's d, Cramér's V, eta-squared 등 효과크기를 같이 봐야 함
- **다중비교 보정**: 여러 그룹을 짝지어 반복 검정하면 우연히 유의하게 나올 확률이 누적됨 → ANOVA 후 사후검정(Tukey HSD, Bonferroni 보정) 필수

## 7. 가설검정 흐름 (기본 틀)

```
문제 상황
  ↓
H0 : 효과/차이가 없다
H1 : 효과/차이가 있다 (방향에 따라 <, >, ≠ 결정)
  ↓
유의수준 α 설정 (보통 0.05, 엄격할 땐 0.01)
  ↓
검정통계량 계산 (Z 또는 t)
  ↓
기각역 확인 (H1 방향이 기각역 위치를 결정)
  ↓
검정통계량이 기각역 안에 있으면 → H0 기각
검정통계량이 채택역 안에 있으면 → H0 채택 못함(기각 실패)
  ↓
결론 작성 (p-value 방식도 동일: p<α면 기각)
```

**핵심 연결고리**: H1의 방향(>, <, ≠)이 기각역의 위치(우측/좌측/양쪽)를 결정. 단측검정은 α를 한쪽에 전부 배분(임계값 1.645), 양측검정은 양쪽에 절반씩 배분(임계값 ±1.96) → 그래서 임계값이 달라짐.

**주의**: "귀무가설을 채택한다"가 아니라 "기각하지 못한다"로 표현하는 게 정확함. 근거 부족이지 "효과 없음"을 증명한 게 아님.

## 8. 대표 예제 3개

### 예제 1. 신약 효과 검정 (왼쪽 단측검정)

**상황**: 기존 감기약은 평균 7일 만에 낫는다. 신약이 "7일보다 더 빨리 낫게 한다"고 주장. 환자 30명 실험 결과 평균 치료기간 5.8일.

| 항목        | 내용                                                                                  |
| ----------- | ------------------------------------------------------------------------------------- |
| H0          | μ = 7 (신약은 효과가 없다, 기존과 같다)                                              |
| H1          | μ < 7 (신약이 치료기간을 단축시킨다)                                                 |
| 검정 방향   | 왼쪽 단측검정                                                                         |
| 유의수준 α | 0.05                                                                                  |
| 검정통계량  | t = -2.45                                                                             |
| 기각역      | t < -1.699                                                                            |
| 채택역      | t ≥ -1.699                                                                           |
| 판단        | -2.45 < -1.699 → 기각역에 속함 →**H0 기각**                                   |
| p-value     | 0.011 < 0.05 → 동일하게 기각                                                         |
| 결론        | 유의수준 5%에서 신약은 기존 약보다 치료기간을 단축한다고 볼 충분한 통계적 근거가 있다 |

> **주의**: H1을 "μ ≠ 7"로 잡으면 양측검정이 되어버리는데, 이는 "신약이 더 오래 걸려도 유의미하다"는 의미가 되어 회사 주장과 안 맞음. 연구 가설이 방향성을 가지면 반드시 단측검정 사용.

---

### 예제 2. 병원 건강검진 / 검사 (오른쪽 vs 왼쪽 단측 비교)

**상황 A (운동 프로그램 - 혈압 감소 기대)**: 정상인 평균 혈압 120mmHg. 운동 프로그램 후 혈압이 낮아졌는지 검정.

| 항목        | 내용                                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| H0          | μ = 120 (혈압 그대로)                                                                                                         |
| H1          | μ < 120 (혈압이 낮아졌다)                                                                                                     |
| 검정 방향   | 왼쪽 단측검정                                                                                                                  |
| 유의수준 α | 0.05                                                                                                                           |
| 실험 결과   | p = 0.18                                                                                                                       |
| 판단        | 0.18 > 0.05 →**H0 기각 못함**                                                                                           |
| 결론        | 운동 프로그램이 혈압을 낮춘다고 보기에는 통계적으로 충분한 근거가 없다 (효과가 없다는 뜻이 아니라 증명할 근거가 부족하다는 뜻) |

**상황 B (질병 스크리닝 - 양측 이상 감지)**: 정상인 평균 혈당 100mg/dL. 환자 집단 혈당이 정상과 "다른가"(높든 낮든) 검정.

| 항목        | 내용                    |
| ----------- | ----------------------- |
| H0          | μ = 100                |
| H1          | μ ≠ 100               |
| 검정 방향   | 양측검정                |
| 유의수준 α | 0.05                    |
| 기각역      | t < -1.96 또는 t > 1.96 |
| 채택역      | -1.96 ≤ t ≤ 1.96      |

**의료 검사에서 1종/2종 오류의 실질적 의미** (중요 포인트):

- 1종 오류(α): 정상인데 "이상 있다" 판정 → false positive → 불필요한 재검사, 환자 불안
- 2종 오류(β): 실제 이상인데 "정상" 판정 → false negative → 치료 시기 놓침, **훨씬 치명적**
- → 그래서 의료 스크리닝은 α를 다소 높게 잡아서라도 β(2종 오류)를 줄이는 방향으로 설계하는 경우가 많음. 순수 통계 이론과 실무 판단 기준이 다를 수 있는 좋은 예.

### 예제 3. 제품 품질 검사 (양측검정 & 좌측 단측검정 두 버전)

**버전 A (음료 용량 - 양측검정)**: 광고 용량 500mL. 실제 평균이 500mL인지(많아도 적어도 문제) 검사.

| 항목        | 내용                                              |
| ----------- | ------------------------------------------------- |
| H0          | μ = 500                                          |
| H1          | μ ≠ 500                                         |
| 검정 방향   | 양측검정                                          |
| 유의수준 α | 0.05                                              |
| 기각역      | z < -1.96 또는 z > 1.96                           |
| 검정통계량  | z = 2.40                                          |
| 판단        | 2.40 > 1.96 → 기각역에 속함 →**H0 기각**  |
| 결론        | 평균 용량은 500mL와 통계적으로 유의한 차이가 있다 |

**버전 B (부품 강도 - 왼쪽 단측검정, 최소 기준 충족 여부)**: 부품 평균 강도가 최소 50N 이상이어야 통과.

| 항목        | 내용                                                |
| ----------- | --------------------------------------------------- |
| H0          | μ ≥ 50 (기준 충족)                                |
| H1          | μ < 50 (기준 미달)                                 |
| 검정 방향   | 왼쪽 단측검정                                       |
| 유의수준 α | 0.01 (품질관리는 보통 더 엄격)                      |
| 기각역      | z < -2.33                                           |
| 채택역      | z ≥ -2.33                                          |
| 판단 로직   | z < -2.33이면 → 불량 라인으로 판정, 공정 점검 필요 |

> 품질관리는 α를 0.01, 0.001처럼 보수적으로 잡는 경우 많음. 잘못 기각(멀쩡한 라인을 불량으로 세움)하면 생산 중단 비용이 크기 때문.

## 10. 가설검정 3가지 유형 요약 (암기용)

| 상황                                 | H0          | H1           | 검정            |
| ------------------------------------ | ----------- | ------------ | --------------- |
| 신약 효과 (개선 방향 확실)           | μ = 기존값 | μ < 기존값  | 왼쪽 단측검정   |
| 교육·마케팅 등 향상 기대            | μ = 기존값 | μ > 기존값  | 오른쪽 단측검정 |
| 제품 품질/기준 이탈 여부 (방향 무관) | μ = 기준값 | μ ≠ 기준값 | 양측검정        |

**핵심 판단 기준**: 연구 목적이 "한쪽 방향으로의 변화"를 주장하면 단측, "기준에서 벗어났는가(방향 무관)"를 확인하면 양측.
