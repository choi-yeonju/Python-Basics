## 📦 LAB 05 — 데이터 품질 검사 (Quality Check)

### 핵심 흐름
```
원본 데이터 로드
    → 자료형 변환 (set_type)
    → 중복 검사/제거 (check_duplicates)
    → 결측치 확인 (check_missing_values)
    → 품질 검사 결과 저장 (.to_excel)
    → 기술 통계량 확인 (categorical_summary / numerical_summary)
```

---

### 1. `set_type()` — 자료형 변환

```python
df1 = my_qtcheck.set_type(origin, as_category=['cut', 'color', 'clarity'])
```

- `as_int`, `as_float`, `as_string`, `as_category`, `as_datetime` 파라미터로 컬럼별 타입 지정
- 내부적으로 `.astype()` / `pd.to_datetime()` 호출
- 변환 후 `.info()` 자동 출력
- **원본은 건드리지 않음** → `data.copy()` 후 작업, 결과를 새 변수에 받아야 함

> 💡 범주형으로 변환하는 이유: 메모리 절약 + 통계 함수에서 "범주형"으로 인식되게 하기 위해

---

### 2. `check_duplicates()` — 중복 검사

```python
df2 = my_qtcheck.check_duplicates(df1)
```

- `df.duplicated()` : 각 행이 중복인지 True/False 반환
- `.sum()` 으로 중복 행 개수 집계
- `drop=True` (기본값) 이면 `drop_duplicates()` 로 중복 제거
- 중복 제거 후 결과를 반환 → 변수에 받아야 유지됨

---

### 3. `check_missing_values()` — 결측치 확인

```python
my_qtcheck.check_missing_values(df2)
```

- `isna().sum()` : 컬럼별 결측치 개수
- `(na_count / len(data)) * 100` : 결측치 비율(%)
- 결과를 DataFrame으로 반환 (Missing Count / Missing Ratio %)

---

### 4. `categorical_summary()` — 범주형 변수 기술 통계

```python
category_desc = my_qtcheck.categorical_summary(df2, save_path="diamonds_category_summary.xlsx")
```

- `describe(include="category")` 로 범주형 기술 통계 (unique, top, freq 등)
- `value_counts=True` (기본값) 이면 각 컬럼별 빈도표도 출력
- `save_path` 지정 시 Excel로 저장 (Summary 시트 + 컬럼별 시트)
- 여러 시트 저장에 `ExcelWriter(mode='a', engine='openpyxl')` 사용

---

### 5. `numerical_summary()` — 수치형 변수 기술 통계

```python
desc_df = my_qtcheck.numerical_summary(df2, save_path="diamonds_numerical_summary.xlsx")
```

이 함수가 계산하는 것들:

| 항목 | 내용 |
|------|------|
| 기본 통계 | count, mean, std, min, 25%, 50%, 75%, max |
| `rel_diff` | `|평균 - 중앙값| / 중앙값` (평균-중앙값 상대 차이율) |
| `rdiff_flag` | similar / diff / large_diff (분포 대칭성 판단) |
| `iqr` | Q3 - Q1 |
| `upper_bound` | Q3 + 1.5 × IQR (이상치 상한 경계) |
| `lower_bound` | Q1 - 1.5 × IQR (이상치 하한 경계) |
| `upper_outliers` | 상한 초과 이상치 수 / 비율 |
| `lower_outliers` | 하한 미만 이상치 수 / 비율 |
| `outliers` | 통합 이상치 수 / 비율 |
| `skew` | 왜도 (분포 비대칭 방향) |
| `skew_interpret` | left tail / right tail / symmetric |
| `kurt` | 첨도 (분포 뾰족함) |
| `kurt_interpret` | platykurtic / leptokurtic / mesokurtic |
| `log_need` | log1p / reverse_log1p / none (로그 변환 필요성 판정) |

#### 왜도 / 첨도 해석

```
왜도(skew)
  < -0.5  →  left tail (왼쪽 꼬리, 오른쪽 치우침)
  > +0.5  →  right tail (오른쪽 꼬리, 왼쪽 치우침)
  그 외   →  symmetric

첨도(kurt)  [pandas 기준: 초과 첨도, 정규분포 = 0]
  < 0  →  platykurtic (납작한 분포)
  > 0  →  leptokurtic (뾰족한 분포)
  = 0  →  mesokurtic (정규분포와 유사)
```

#### 로그 변환 판정 로직

```python
skew >= 1                    → "log1p"         # 강한 우측 꼬리
0.5 < skew < 1, kurt > 0     → "log1p"         # 우측 꼬리 + 뾰족
skew <= -1                   → "reverse_log1p"  # 강한 좌측 꼬리
-1 < skew < -0.5, kurt > 0   → "reverse_log1p"  # 좌측 꼬리 + 뾰족
그 외                        → "none"
```

## 📊 LAB 06 — 데이터 시각화 기초

### 2. 한글 폰트 설정

```python
import glob as gl
from matplotlib import font_manager as fm
from matplotlib import pyplot as plt

fpath = "./helpers/fonts"
font_files = gl.glob(os.path.join(fpath, "*.ttf"))

for f in font_files:
    fm.fontManager.addfont(f)           # 시스템에 폰트 등록
    fprop = fm.FontProperties(fname=f)  # 폰트 속성 읽기
    fname = fprop.get_name()            # 폰트 이름 추출
    plt.rcParams['font.family'] = fname # matplotlib에 적용
```

> 💡 이 작업을 안 하면 한글이 □□□□으로 깨짐

---

### 3. `plt.rcParams` — 전역 그래프 설정

```python
my_dpi = 200
plt.rcParams['font.size'] = 12              # 기본 폰트 크기
plt.rcParams['axes.unicode_minus'] = False  # 마이너스 기호 깨짐 방지
plt.rcParams['figure.dpi'] = my_dpi         # 화면 출력 해상도
plt.rcParams['savefig.dpi'] = my_dpi        # 저장 해상도
plt.rcParams['lines.linewidth'] = 2         # 선 굵기
plt.rcParams['axes.axisbelow'] = True       # 격자선을 그래프 뒤로 배치
```

> 한 번 설정하면 이후 모든 그래프에 자동 적용됨

---

### 4. 그래프 기본 템플릿 (matplotlib 직접 사용)

```python
width, height = 1280, 640
my_figsize = (width / 100, height / 100)  # 픽셀 → 인치 변환 (dpi=100 기준)

fig, ax = plt.subplots(rows, cols, figsize=my_figsize, dpi=my_dpi)
ax.grid(True, alpha=0.5)

ax.set_title("제목", color="#6a91ca", fontsize=24, fontweight=700, pad=15)
ax.set_xlabel("X축", color="#ff6600", fontsize=16, fontweight=500, labelpad=5)
ax.set_ylabel("Y축", color="#ff00ff", fontsize=16, fontweight=500, labelpad=5)

plt.tight_layout()
plt.savefig("myplot.png", dpi=my_dpi)
plt.show()
plt.close()  # 메모리 해제
```

#### `fig` vs `ax` 차이

| 객체 | 역할 |
|------|------|
| `fig` (Figure) | 전체 캔버스. 크기, 저장, 전체 레이아웃 담당 |
| `ax` (Axes) | 실제 그래프 영역. 제목, 축, 데이터 표시 담당 |

> `subplots(rows, cols)` 로 여러 그래프를 격자 배치 가능

### 5. `my_plot` 모듈 — 반복 코드 추상화

```python
from helpers import my_plot

fig, ax = my_plot.init(rows=1, cols=1, width=1280, height=640,
                       title="My Plot", xlabel="X-axis", ylabel="Y-axis")
# ... 그래프 그리기 ...
my_plot.show(save_path="output.png")
```

#### `init()` 내부 동작
- 픽셀 → 인치 변환 (`width / 100`)
- `plt.subplots()` 호출
- `grid`, `title`, `xlabel`, `ylabel` 자동 설정
- `fig, ax` 반환

#### `show()` 내부 동작
- `save_path` 있으면 `plt.savefig()` 호출
- `plt.tight_layout()` → `plt.show()` → `plt.close()`

> 💡 `plt.close()` 를 빠뜨리면 이전 그래프 객체가 메모리에 쌓임

### 6. Seaborn LinePlot 패턴 3가지

```python
import seaborn as sb

# 패턴 1: 리스트 직접 전달 (자동으로 인덱스가 X축)
sb.lineplot([10, 20, 30, 40, 50])

# 패턴 2: x, y 개별 지정
sb.lineplot(x=[2, 3, 4, 5, 6], y=[10, 20, 30, 40, 50])

# 패턴 3: DataFrame + 컬럼명 (실무에서 가장 많이 씀)
sb.lineplot(data=origin, x='Date', y='Quantity')

# hue: 범주형 컬럼으로 색상 구분
sb.lineplot(data=origin, x='Date', y='Quantity', hue='Flavor')

# palette: 색상 팔레트 지정
sb.lineplot(data=origin, x='Date', y='Quantity', hue='Flavor', palette='PuRd')
```

#### `hue` 파라미터
- 범주형 컬럼을 기준으로 **색상별로 여러 선**을 하나의 그래프에 그림
- 범례(legend) 자동 생성

## 🔑 오늘의 핵심 포인트

1. **pandas 메서드는 원본을 바꾸지 않는다** — 항상 결과를 변수에 받아야 유지됨
2. **IQR 이상치 탐지** = `Q1 - 1.5×IQR` ~ `Q3 + 1.5×IQR` 범위 밖이 이상치
3. **왜도 > 0.5 이면 오른쪽 꼬리** → 로그 변환 고려
4. **matplotlib는 fig(캔버스) + ax(그래프 영역)** 이중 구조
5. **`plt.close()` 습관화** — 메모리 누수 방지
6. **seaborn은 matplotlib 위에 올라탄다** — `sb.lineplot()` 호출 전에 `fig, ax` 먼저 만들어야 커스터마이징 가능
