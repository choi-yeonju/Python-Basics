# 데이터 시각화 레퍼런스 가이드 (`my_plot` 모듈 기준)

차트를 그릴 때 "이 상황엔 어떤 차트를 써야 하나 + 옵션이 뭐가 있나"를 바로 찾아보기 위한 가이드.
`helpers.py`의 `my_plot` 모듈(`init`, `show`, `lineplot`, `kdeplot`, `histplot`, `boxplot`, `violinPlot`, `heatmap`, `barplot`, `countplot`, `pieplot`, `stackplot`) 기준으로 정리.

---

## 0. 공통 구조

모든 그래프 함수는 동일한 패턴으로 동작:

```python
fig, ax = init(width, height, title, xlabel, ylabel)   # 1. 캔버스 초기화
sb.xxxplot(data=..., x=..., y=..., ...)                 # 2. 실제 그래프 그리기
show(save_path=save_path)                                # 3. 표시 + 저장 + 닫기
```

### 공통 파라미터 (거의 모든 함수에 있음)

| 파라미터 | 의미 | 기본값 |
|---|---|---|
| `data` | 시각화할 DataFrame | - |
| `x`, `y` | 축에 쓸 컬럼명 | - |
| `hue` | 범주 구분 컬럼명 (색상별로 나눔) | `None` |
| `palette` | 색상 팔레트 이름 (`"tab20"`, `"Set2"`, `"pastel"` 등) | `None` |
| `title` / `xlabel` / `ylabel` | 제목 / 축 레이블 | `None` |
| `width` / `height` | 캔버스 픽셀 크기 | `1280 / 640` |
| `save_path` | 저장 경로 (지정 시 파일로 저장) | `None` |

## 1. 어떤 상황에 어떤 차트를 쓰나 (선택 가이드)

| 목적 | 추천 차트 | 함수 |
|---|---|---|
| 시간 흐름/추세 보기 | 선 그래프 | `lineplot` |
| 값의 분포 모양 보기 (연속형) | 히스토그램, 커널밀도 | `histplot`, `kdeplot` |
| 그룹 간 분포 비교 (이상치, 사분위) | 박스플롯 | `boxplot` |
| 그룹 간 분포 비교 (전체 모양까지) | 바이올린플롯 | `violinPlot` |
| 그룹별 평균/합계 등 대표값 비교 | 막대그래프 | `barplot` |
| 그룹별 개수(빈도) 비교 | 카운트플롯 | `countplot` |
| 전체 대비 구성비 (한 시점) | 파이/도넛 | `pieplot` |
| 카테고리별 합계 + 세부 구성 동시에 | 누적 막대 | `stackplot` |
| 카테고리별 구성 "비율"만 비교 (합계 다를 때도) | 100% 누적 막대 | `stackplot(ratio=True)` |
| 두 범주 교차 값 비교 (표 형태) | 히트맵 | `heatmap` |

### ⚠️ 지난번에 짚었던 함정: Stacked bar의 한계
- Stacked bar는 **첫 세그먼트만 0 기준선**이고 나머지는 떠 있어서, **"카테고리를 가로질러 특정 hue의 값 비교"**엔 부적합.
- 이런 질문("Color별로 어느 Cut에서 제일 비싼가")엔 **heatmap**이나 **grouped bar**, **lineplot**이 더 적합.
- → 즉, "합계 비교"는 stacked bar가 좋고, "개별 항목 간 비교"는 다른 차트가 좋다.

## 2. 차트별 핵심 옵션

### 2-1. `lineplot` — 추세/시계열
```python
my_plot.lineplot(data=df, x="날짜", y="매출", hue="지역",
                  linewidth=2.0, linestyle="-", marker="o", markersize=6)
```
- `linestyle`: `"-"` 실선, `"--"` 점선, `":"` 점점선
- `marker`: `"o"`, `"s"`, `"^"` 등 (데이터 포인트 표시)

### 2-2. `kdeplot` — 커널 밀도 (분포 모양)
```python
my_plot.kdeplot(data=df, x="가격", hue="등급", fill=True, meanline=True)
```
- `fill=True`: 곡선 아래 면적 채움
- `meanline=True`: 평균선 자동 표시 (단, `hue` 있으면 범주별 평균선, 조합 제약 있음)

### 2-3. `histplot` — 히스토그램
```python
my_plot.histplot(data=df, x="가격", bins=20, hue="등급", kde=True)
```
- `bins`: 정수(구간 개수) 또는 리스트(직접 경계 지정)
- `kde=True`: 히스토그램 위에 밀도곡선 겹쳐 표시

### 2-4. `boxplot` / `violinPlot` — 그룹별 분포 비교
```python
my_plot.boxplot(data=df, x="등급", y="가격", hue="색상", orient='v')
my_plot.violinPlot(data=df, x="등급", y="가격", orient='v')
```
- `orient`: `'v'`(세로) / `'h'`(가로)
- boxplot: 중앙값, 사분위, 이상치를 정확한 값으로 보고 싶을 때
- violin: 분포의 전체 모양(다봉/단봉 등)까지 보고 싶을 때

### 2-5. `heatmap` — 교차표 값 비교
```python
my_plot.heatmap(data=pivot_df, annot=True, fmt="0.2f", linewidths=0.5, palette="Blues")
```
- `data`는 2차원 형태(보통 `pivot_table` 결과)여야 함
- `annot=True`: 셀 안에 숫자 표시
- `fmt`: 표시 형식 (`"0.2f"` = 소수 2자리 등, 포맷 문법은 별도 가이드 참고)

### 2-6. `barplot` — 그룹별 대표값(평균 등)
```python
my_plot.barplot(data=df, x="등급", y="가격", hue="색상", estimator=np.mean)
```
- `estimator`: 막대 높이 계산 방식 (`np.mean`, `np.sum`, `np.median` 등)
- `order`: 막대 순서 직접 지정 (리스트)

### 2-7. `countplot` — 개수(빈도) 세기
```python
my_plot.countplot(data=df, x="등급", hue="색상")
```
- `barplot`과 달리 `y`에 집계할 값 컬럼 필요 없음 (그냥 행 개수를 셈)

### 2-8. `pieplot` — 구성비 (파이/도넛)
```python
my_plot.pieplot(x=df['비율'], labels=df.index, autopct="%0.1f%%",
                 donutchart=True, wedge_width=0.7)
```
- `donutchart=True`: 도넛 형태로 변경
- `explode`: 특정 조각만 떨어뜨려 강조 (리스트, 강조할 위치만 값 부여)
- `counterclock=False`: 시계방향으로 그리기 (기본값)

### 2-9. `stackplot` — 누적 막대 / 100% 누적 막대
```python
my_plot.stackplot(data=df, x="지역", y="종사자 수", hue="산업",
                   aggfunc=np.sum, orient='h', ratio=False,
                   text=True, text_format="{:.1f}", palette="tab20")
```
- `orient`: `'v'`(세로, `bottom=` 사용) / `'h'`(가로, `left=` 사용)
- `ratio=True`: 절대값 대신 **비율(%)로 자동 변환**, `text_format` 없으면 `"{:.1f}%"`로 강제 지정됨
- `aggfunc`: 누적 전 집계 방식 (합계면 `np.sum`, 평균이면 `np.mean`)
- `text_format`: 막대 안 숫자 표시 형식 → [포맷 문법 가이드](#) 참고

## 3. `bar` vs `barh` — 세로/가로 막대 파라미터 대응표

같은 "누적"이라도 방향에 따라 파라미터 이름이 다름. 헷갈려서 에러 자주 남.

| | 세로 막대 (`bar`, `orient='v'`) | 가로 막대 (`barh`, `orient='h'`) |
|---|---|---|
| 누적 시작점 | `bottom=` | `left=` |
| 범주 축 | x | y |
| 값 축 | y | x |
| `ax.text()` 좌표 | `x=범주, y=누적값` | `x=누적값, y=범주` |

```python
# 세로
ax.bar(df.index, df['A'], label='A')
ax.bar(df.index, df['B'], bottom=df['A'], label='B')   # bottom!

# 가로
ax.barh(df.index, df['A'], label='A')
ax.barh(df.index, df['B'], left=df['A'], label='B')    # left!
```

**주의**: `barh`에 `bottom=`을 넣으면 `TypeError: got multiple values for keyword argument 'bottom'` 발생 (barh 내부가 `bottom`을 이미 y로 자동 매핑하기 때문).

## 4. 누적값 계산 패턴 (반복문 안에서 자주 틀리는 부분)

n번째 세그먼트의 텍스트 y(또는 x) 위치 = **그 전까지 쌓인 값의 합 + 현재 값의 절반**

```python
for i in df.index:
    ax.text(x=i, y=df['A'][i]/2, s=..., ...)                              # 1번째: 0 + A/2
    ax.text(x=i, y=df['A'][i] + df['B'][i]/2, s=..., ...)                 # 2번째: A + B/2
    ax.text(x=i, y=df['A'][i] + df['B'][i] + df['C'][i]/2, s=..., ...)    # 3번째: A+B + C/2
```

`stackplot` 함수 내부처럼 컬럼 수가 유동적이면 `.iloc[:, :i].sum(axis=1)`로 일반화:
```python
df.iloc[j, :i].sum() + val/2   # i번째 컬럼까지의 누적합 + 현재값 절반
```

**흔한 실수**: 반복문 안에서 `df['컬럼']`처럼 `[i]` 인덱싱을 빼먹으면 스칼라가 아니라 시리즈 전체가 계산에 섞여 들어감 → 항상 "이번 반복에서 쓰는 값은 스칼라인가?" 체크.

## 5. 모듈화 함수 만들 때 체크리스트 (지난 디버깅에서 나온 패턴들)

- [ ] 함수 시그니처 끝에 `:` 빠뜨리지 않기
- [ ] 색상 hex 코드 자릿수 확인 (`#ffffff` = 6자리)
- [ ] `if text:` 같은 "옵션 실행 블록"이 `if orient=='v': / else:` 분기 **안에** 잘못 갇혀있지 않은지 확인 → orient 상관없이 실행돼야 하는 코드는 분기 **밖**에
- [ ] `legend()`, `show()`처럼 "전체 다 그린 후 한 번만" 호출해야 하는 코드가 `for` 반복문 **안에** 잘못 들어가 있지 않은지 확인
- [ ] `ratio=True` 같은 옵션이 켜졌을 때 축 범위(`set_ylim`/`set_xlim`)도 같이 맞춰줬는지 확인

| `"pastel"` | 부드러운 톤 |
| `"Blues"`, `"Reds"` 등 | heatmap처럼 연속값 강도 표현할 때 (순서형) |

`hue` 넘기면 seaborn이 자동으로 팔레트 적용하지만, `bar`/`barh`처럼 직접 반복문 돌리는 경우엔 `color_list[i]`로 수동 지정 필요.
