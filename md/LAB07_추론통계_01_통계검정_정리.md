# 통계 검정 방법 정리 (t-test / ANOVA / 카이제곱)

## 0. 큰 틀: 검정 방법 선택 기준

검정 방법은 크게 두 가지 질문으로 결정된다.

1. **종속변수가 연속형인가, 범주형인가?**
2. **비교하는 집단(그룹)이 몇 개인가?**

| 독립변수(그룹) | 종속변수 | 집단 수 | 검정 방법 |
|---|---|---|---|
| 범주형 | 연속형 | 1개 (기준값과 비교) | 일표본 t검정 |
| 범주형 | 연속형 | 2개, 독립 | 독립표본 t검정 |
| 범주형 | 연속형 | 2개, 대응(전/후) | 대응표본 t검정 |
| 범주형 | 연속형 | 3개 이상 | ANOVA |
| 범주형 | 범주형 | 관계없음 | 카이제곱(교차분석) |

---

## 1. t-test 3가지

### 1) 일표본 t검정 (One-sample t-test)
- **목적**: 하나의 집단 평균이 특정 기준값(모집단 평균)과 다른지 검정
- **예시**: "우리 반 시험 평균이 전국 평균 70점과 다른가?"
- **가설**
  - H0: 집단 평균 = 기준값
  - H1: 집단 평균 ≠ 기준값
- **Python**
```python
from scipy import stats
stats.ttest_1samp(data, popmean=70)
```

### 2) 독립표본 t검정 (Independent samples t-test)
- **목적**: 서로 다른(독립적인) 두 집단의 평균 비교
- **예시**: "남성 그룹과 여성 그룹의 평균 구매액이 다른가?"
- **전제조건**: 등분산성 검정(Levene's test) 먼저 확인 → 등분산 여부에 따라 옵션 다름
- **가설**
  - H0: 두 집단 평균이 같다
  - H1: 두 집단 평균이 다르다
- **Python**
```python
from scipy import stats
# 등분산 검정
stats.levene(group1, group2)
# 독립표본 t검정 (등분산 가정 여부에 따라 equal_var 조정)
stats.ttest_ind(group1, group2, equal_var=True)
```

### 3) 대응표본 t검정 (Paired samples t-test)
- **목적**: 같은 대상에서 측정한 전/후 값 비교 (짝지어진 데이터)
- **예시**: "다이어트 프로그램 전/후 몸무게 차이가 있는가?"
- **가설**
  - H0: 전후 평균 차이 = 0
  - H1: 전후 평균 차이 ≠ 0
- **Python**
```python
from scipy import stats
stats.ttest_rel(before, after)
```

## 2. ANOVA (분산분석)

- **왜 필요한가**: t-test는 2개 집단까지만 비교 가능. 집단이 **3개 이상**이면 t-test를 반복 사용 시 1종 오류(false positive)가 누적됨 → ANOVA로 한 번에 검정
- **목적**: 3개 이상 집단의 평균이 통계적으로 유의하게 다른지 검정
- **검정통계량**: F값 (집단 간 분산 / 집단 내 분산)
- **가설**
  - H0: 모든 집단의 평균이 같다
  - H1: 적어도 한 집단은 평균이 다르다
- **주의**: ANOVA에서 유의하다고 나와도 **어느 집단끼리 다른지는 알려주지 않음** → 사후검정(post-hoc test) 필요
  - 대표적 사후검정: Tukey HSD, Bonferroni

- **Python**
```python
from scipy import stats
stats.f_oneway(group1, group2, group3)

# 사후검정 (Tukey HSD)
from statsmodels.stats.multicomp import pairwise_tukeyhsd
pairwise_tukeyhsd(endog=data['value'], groups=data['group'], alpha=0.05)
```

- **참고**: 독립변수가 2개 이상이면 이원분산분석(Two-way ANOVA)으로 확장 (Olist 프로젝트의 OLS 회귀분석/VIF 체크와 연결되는 개념)

## 3. 교차분석(카이제곱) vs t검정 — 구분 기준

핵심은 **두 변수의 척도(scale)가 무엇인가**이다.

| 상황 | 검정 방법 |
|---|---|
| 범주형 × 범주형 | **카이제곱검정 (교차분석, chi-square test)** |
| 범주형(그룹) × 연속형(평균) | **t검정 / ANOVA** |

### 카이제곱검정 (Chi-square test)
- **목적**: 두 범주형 변수 간에 관련성(독립성)이 있는지 검정
- **예시**: "성별(남/여) × 구매여부(구매/미구매)가 서로 관련이 있는가?"
- **가설**
  - H0: 두 변수는 독립이다 (관련 없다)
  - H1: 두 변수는 독립이 아니다 (관련 있다)
- **효과크기**: Cramér's V (관련성이 유의해도 강도가 약하면 실질적 의미는 작을 수 있음 — Olist 프로젝트에서 V<0.02로 판단한 것과 동일한 맥락)
- **Python**
```python
import pandas as pd
from scipy.stats import chi2_contingency

cross_tab = pd.crosstab(df['성별'], df['구매여부'])
chi2, p, dof, expected = chi2_contingency(cross_tab)
```

### t검정 / ANOVA (다시 요약)
- 그룹(범주형)에 따라 **연속형 변수의 평균**이 다른지 볼 때 사용
- 그룹 2개 → t검정 / 그룹 3개 이상 → ANOVA

---

## 4. 한눈에 정리

```
종속변수가 연속형인가?
├─ Yes → 그룹이 몇 개인가?
│         ├─ 1개 (기준값과 비교) → 일표본 t검정
│         ├─ 2개, 독립 → 독립표본 t검정
│         ├─ 2개, 대응(전/후) → 대응표본 t검정
│         └─ 3개 이상 → ANOVA (+ 사후검정)
└─ No (범주형) → 카이제곱검정 (교차분석)
```

## 5. 검정 전 체크리스트

- [ ] 종속변수 척도 확인 (연속형 vs 범주형)
- [ ] 비교 집단 수 확인
- [ ] (t검정/ANOVA 경우) 등분산성 검정 여부 확인 — Levene's test
- [ ] (t검정/ANOVA 경우) 정규성 검정 여부 확인 — Shapiro-Wilk test (표본이 작을 때 특히 중요)
- [ ] 정규성/등분산 가정이 깨지면 비모수 검정 고려
  - t검정 대체: Mann-Whitney U test (독립), Wilcoxon signed-rank test (대응)
  - ANOVA 대체: Kruskal-Wallis test
- [ ] 유의하다면 효과크기(effect size)도 함께 보고 — Cohen's d(t검정), Cramér's V(카이제곱), eta squared(ANOVA)
