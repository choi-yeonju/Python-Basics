## 1. 전체 파이프라인에서 이 랩의 위치

머신러닝 모델링 전 전처리는 **"데이터 분할 이전에 할 일"**과 **"분할 이후에 할 일"**로 나뉩니다. 이 구분이 중요한 이유는, 분할 이후에 해야 할 작업(결측치 대체, 이상치 대체, 인코딩, 스케일링)을 분할 전에 전체 데이터로 해버리면 **검증 데이터의 정보가 학습 데이터로 새어 들어가는 데이터 누수(data leakage)**가 발생하기 때문입니다.

| 이번 랩 — 분할 이전에 수행 | 다음 랩 — 분할 이후에 수행 |
|---|---|
| ① 비율형 파생변수 생성 | ① 학습·검증용 데이터 분할 |
| ② 범주형(절단 플래그, 해안 접근성 등) 파생변수 생성 | ② 결측치·이상치 대체 |
| ③ 공간특성 반영 | ③ 더미변수 인코딩 |
| ④ 로그 변환, 명목형 라벨링 | ④ 다중공선성 확인 (VIF) |
| | ⑤ 스케일링 |
| | ⑥ 차원축소 (필요한 경우만) |

**왜 이렇게 나뉘는가?**
- 비율형 파생변수(방 개수 ÷ 인구 수 같은 것)는 원본 데이터의 성격 자체를 바꾸는 작업이라 전체 데이터에 적용해도 미래 정보가 새는 게 아닙니다. (단순 산술 연산이므로 분할 여부와 무관)
- 반면 결측치를 평균으로 채우거나 스케일링을 할 때 쓰는 "평균값"이나 "표준편차"는 **학습 데이터에서만 계산해서 검증 데이터에 적용**해야 하므로, 반드시 분할 이후에 해야 합니다.
- sklearn은 `fit_transform`(학습 데이터에 적용) / `transform`(검증 데이터에 적용)을 나눠서 이 원칙을 강제합니다. 지금까지 만든 `my_qtcheck`, `my_prep`, `my_stats` 같은 개인 모듈은 이 sklearn 자동화 흐름을 이해하기 위해 그 안의 로직을 손으로 풀어본 것입니다.

**핵심 원칙**: 전처리는 임의로 하는 게 아니라 **EDA가 남긴 과제 목록을 실행**하는 것입니다.

| EDA 결론 | 전처리 계획 |
|---|---|
| 총량 변수 4종 — 설명력 약함(ρ=+0.086~+0.205), 서로 중복(ρ≥0.90) | 비율형으로 재구성 |
| median_income — 유일한 실질 설명변수(ρ=+0.677) | 1인당 소득으로 정제 |
| 상한 절단 지점 3곳 존재 | 플래그로 표시 |
| ocean_proximity — 단독 설명력 최상위(np2=0.238) | 2범주로 재분류 |
| 위·경도 | 공간특성으로 반영 |

> "왜 이 변수를 만들었냐"는 질문에 EDA 결과로 답할 수 있어야 합니다. 이게 통계를 아는 분석가와 그렇지 않은 분석가의 차이입니다.

## 2. 파생변수(Feature Engineering) 개념

**정의**: 기존 변수(원시 데이터)를 가공·결합·변환하여 새롭게 만든 변수. 목적은 모델의 예측력과 데이터의 해석력을 높이는 것.

**생성 프로세스**: 원시 데이터 → 변수 선택 → 변환·결합 → 파생변수 생성

**주요 생성 기법 4가지**
1. **산술 결합(Arithmetic)** — 예: BMI = 체중 / 키²
2. **비율·비교(Ratio)** — 예: 부채비율 = 부채 / 자산
3. **시간 파생(Time-based)** — 예: 가입일 → 가입경과일, 요일, 계절
4. **구간화(Binning)** — 예: 연령 → 10대·20대·30대…

**기대효과**
- 비선형 관계 표현: 단일 변수로 못 잡는 패턴을 잡음
- 모델 예측력 향상: 정보 밀도를 높여 학습 효율 개선
- 도메인 지식 반영: 전문가의 통찰을 수치 변수로 구현

## 3. 비율형 파생변수 — "규모"를 지우고 "성격"만 남기기

### 3-1. 왜 필요한가

California Housing 데이터는 "구역(census block group)" 단위로 집계된 데이터입니다. `total_rooms`, `total_bedrooms`, `population`, `households`는 모두 **"이 구역에 총 몇 개가 있는지"**를 세어놓은 총량(count) 변수입니다.

문제는, 인구가 많은 구역은 이 네 변수가 **전부 같이 커진다는 것**입니다. 즉 이 네 변수는 "구역이 크다"는 공통 성분을 공유하고 있어서 (1) 개별 설명력이 약하고 (2) 서로 상관이 0.90 이상으로 심하게 겹칩니다(다중공선성).

**핵심 아이디어**: 총량끼리 나누면 "구역이 크다"는 공통 성분이 약분되고, **구역의 성격**만 남습니다.

### 3-2. 만든 변수 5종

| 파생변수 | 계산식 | 의미 |
|---|---|---|
| rooms_per_person | total_rooms ÷ population | 1인당 방 수 — 주거 여유 공간 |
| rooms_per_household | total_rooms ÷ households | 가구당 방 수 — 주택 규모 |
| bedrooms_per_room | total_bedrooms ÷ total_rooms | 방 중 침실 비율 — 낮을수록 거실·기타 공간이 넓은 고급 주택 |
| population_per_household | population ÷ households | 가구당 인구 — 과밀도 |
| income_per_person | median_income ÷ population_per_household | 1인당 구매력 — 가구 소득을 가구원 수로 나눔 |

`income_per_person`이 특별한 이유: `median_income`은 **가구** 중위소득입니다. 같은 소득이라도 가구원 수가 많으면 1인당 몫은 줄어들기 때문에, 방금 만든 비율형 파생변수(`population_per_household`, 가구당 인구)로 나눠서 **1인당 실질 구매력**을 만듭니다. 즉 파생변수를 만드는 데 다른 파생변수를 재료로 쓴 사례입니다.

### 3-3. 코드

```python
# 1인당 방 수 : 주거 여유 공간
df["rooms_per_person"] = df["total_rooms"] / df["population"]

# 가구당 방 수 : 주택 규모
df["rooms_per_household"] = df["total_rooms"] / df["households"]

# 방 중 침실 비율 : 낮을수록 거실, 기타 공간이 넓은 고급 주택
df["bedrooms_per_room"] = df["total_bedrooms"] / df["total_rooms"]

# 가구당 인구 : 과밀도
df["population_per_household"] = df["population"] / df["households"]

# 1인당 소득 = 가구 중위소득 / 가구당 인구
df["income_per_person"] = df["median_income"] / df["population_per_household"]
```

각 변수를 만들 때마다 `column_means` 딕셔너리(컬럼명 → 한글 설명)를 `.update()`로 같이 갱신했습니다. 딕셔너리의 `update()`는 기존 키가 있으면 값을 갱신, 없으면 새로 추가합니다. — 이렇게 해두면 나중에 그래프 제목이나 표에 자동으로 한글 설명을 붙일 수 있습니다.

### 3-4. 나눗셈 파생변수를 만들 때 반드시 점검할 것

나눗셈이 성립하려면 **분모에 0이 없어야** 합니다. 0으로 나누면 `inf`(무한대)가 발생합니다.

```python
# ① 분모로 쓴 변수의 최솟값 점검 (0이 있으면 inf가 발생)
print(df[["population", "households", "total_rooms"]].min())

# ② 파생 결과에 결측치가 생기지 않았는지 확인
check = df[["rooms_per_person", "rooms_per_household",
            "bedrooms_per_room", "population_per_household"]]
print(check.isna().sum())

# ③ 파생 결과에 무한대가 생기지 않았는지 확인
print(check.isin([float("inf"), float("-inf")]).sum())
```

**이 3단계 점검은 비율형 파생변수를 만들 때마다 항상 반복해야 하는 정형화된 루틴**입니다. 다른 데이터셋에서도 나눗셈 파생변수를 만들면 반드시 이 3가지(분모 최솟값 / 결측 / 무한대)를 확인하세요.

## 4. 범주형 파생변수

### 4-1. 상한 절단 플래그 — "여기서 잘렸다"는 표시

EDA에서 발견한 이산점(특정 값에 몰려있는 군집)은 실제 값이 아니라 **조사 상한(survey cap)에서 잘린 값**인 경우가 많습니다. 값을 고치거나 지우지 않고, "여기서 잘렸다"는 사실만 별도의 이진(0/1) 변수로 표시합니다.

| 변수 | 절단값 | 건수 | 파생변수 이름 | 비고 |
|---|---|---|---|---|
| 주택 연령 | 52년 | 1,265건 (6.2%) | `is_age_capped` | 설명변수 → 플래그 생성 |
| median_income | 15.0 | 50건 (0.2%) | `is_income_capped` | 설명변수 → 플래그 생성 |
| 집값(median_house_value) | 500,001$ | 958건 (4.7%) | **생성하지 않음** | 종속변수 → 플래그 만들면 타깃 누수 |

**원칙 (매우 중요)**: 독립변수에서 파생된 플래그는 만들고, **종속변수에서 파생된 플래그는 만들지 않는다.** 종속변수에서 파생된 변수를 다시 독립변수로 넣으면, "정답의 정보"가 모델 입력으로 흘러들어가 모형 성능이 비정상적으로(거짓으로) 높게 나옵니다. 이것이 **타깃 누수(target leakage)** 입니다.

```python
# housing_median_age(주택 중위 연령)가 52 이상이면 1, 아니면 0
df["is_age_capped"] = (df["housing_median_age"] >= 52).astype(int)

# median_income(중위 소득)이 15 이상이면 1, 아니면 0
df["is_income_capped"] = (df["median_income"] >= 15.0).astype(int)
```

**실무 함정**: `median_income`의 절단값이 15.0(2건)과 15.0001(48건) **두 값으로 나뉘어 저장**되어 있었습니다. `==`로 잡으면 2건만 잡히고 50건을 놓칩니다. `>=`로 잡아야 절단된 50건을 전부 포착합니다. → **"절단값을 눈으로 확인하지 않고 `==`로 성급하게 필터링하면 안 된다"**는 교훈.

### 4-2. 명목형 범주 재구성 — 5범주 → 2범주

**원칙**: 통계적으로는 유의해도 **효과크기가 구분해주지 못하는 범주는 묶는다.**

EDA 사후검정(Games-Howell) 결과:
- 해안권 3종(`<1H OCEAN` · `NEAR OCEAN` · `NEAR BAY`)은 서로 통계적으로 유의해도 효과크기가 전부 Negligible(무시할 수준) → 하나로 묶는다.
- `ISLAND`는 표본이 5건뿐이라 검정력이 없다(판정 불가) → 해안권에 흡수한다.
- `INLAND`는 해안권 범주들과 효과크기가 크다 → 별도로 유지.

```python
# INLAND를 제외한 나머지 범주를 COASTAL(연안)로 병합
df["ocean_area"] = df["ocean_proximity"].apply(
    lambda x: "INLAND" if x == "INLAND" else "COASTAL").astype("category")
```

| 병합 전 ocean_proximity | 건수 | | 병합 후 ocean_area | 건수 |
|---|---|---|---|---|
| \<1H OCEAN | 9,034 | → | COASTAL | 13,937 (68.2%) |
| NEAR OCEAN | 2,628 | → | | |
| NEAR BAY | 2,270 | → | | |
| ISLAND | 5 | → | | |
| INLAND | 6,496 | → | INLAND | 6,496 (31.8%) |

병합 후 극심한 5범주 불균형(ISLAND 0.02%)이 2:1 비율로 크게 해소되었습니다. 다만 범주 수가 5개→2개로 줄었으므로, 원래 5범주 비교에 썼던 **Welch ANOVA는 더 이상 맞지 않고, 2집단 비교이므로 T검정(또는 그 비모수 버전인 Mann-Whitney U test)으로 전환**해야 합니다. — "검정 방법은 범주 수에 따라 바뀐다"는 걸 기억해두세요.

## 5. 공간특성 반영 (Spatial Feature Engineering)

이 랩에서 가장 새로운 개념 파트입니다. 위·경도라는 좌표 정보를 그냥 두 개의 숫자 변수로 넣지 않고, **공간적 특성**으로 변환해서 넣는 방법을 다룹니다.

### 5-1. 공간자기상관(Spatial Autocorrelation)이란

**정의**: 인접한 위치의 관측값들이 서로 유사하거나 상이한 패턴을 보이는 정도. 지리학 제1법칙(Tobler, 1970) — **"가까운 것은 멀리 있는 것보다 더 닮아 있다"**는 직관을, 실제 데이터에서 통계적으로 검증한 것입니다.

**3가지 패턴**
- **양의 공간자기상관**: 비슷한 값끼리 공간적으로 군집한다 (높은 값 옆에 높은 값, 낮은 값 옆에 낮은 값). 예: 강남역·신논현역·역삼역 주변 상권.
- **음의 공간자기상관**: 값이 번갈아 나타난다 (높은 값 옆에 낮은 값). 예: 체스판처럼 골목 상권이 번갈아 뜨는 경우.
- **공간자기상관 없음**: 값이 무작위·우연적으로 흩어져 있다. 예: 로또 1등 당첨 판매점 분포.

### 5-2. Moran's I — 공간자기상관을 재는 통계량

**개념을 말로 풀면**: Moran's I는 "한 지역의 값이, 그 지역과 이웃한 지역들의 값과 얼마나 비슷한 방향으로 움직이는가"를 하나의 숫자로 요약한 지표입니다. 일반적인 상관계수가 "두 변수"의 관계를 재는 것이라면, Moran's I는 "**같은 변수의, 이웃한 관측치끼리의 관계**"를 잽니다(자기상관이라는 이름이 붙는 이유).

| Moran's I 값 | 의미 |
|---|---|
| 0보다 큼 | 양의 자기상관 (Hot Spot 군집형) |
| 0보다 작음 | 음의 자기상관 (체스판 분산형) |
| 0에 가까움 | 공간적으로 무작위 (공간적 독립성) |

**해석 판정표**

| Moran's I | p-value | 해석 |
|---|---|---|
| I > 0 | p < 0.05 | 양의 공간자기상관이 유의함 |
| I < 0 | p < 0.05 | 음의 공간자기상관이 유의함 |
| I > 0 또는 I < 0 | p ≥ 0.05 | 공간자기상관이 있다고 보기 어려움 |
| I ≈ 0 | p ≥ 0.05 | 무작위 분포에 가까움 |

**왜 이게 중요한가?**: 만약 공간자기상관성이 있는데도 이를 무시하고 그냥 선형회귀를 돌리면, 회귀분석의 핵심 가정인 **"관측치들은 서로 독립적이다"**라는 가정이 깨집니다. 이웃한 관측치들이 서로 비슷하다는 건 사실상 "정보가 중복되어 있다"는 뜻이기 때문입니다. 그래서 공간자기상관이 확인되면, 이 공간 정보를 파생변수로 만들어 모델에 명시적으로 알려줘야 합니다.

### 5-3. 공간가중치행렬(Spatial Weights Matrix) — "누가 이웃인지"의 기준표

**개념**: 어느 지역이 어느 지역과 이웃인지를 정리해 둔 표. Moran's I는 "한 지역의 값이 이웃 지역의 값과 얼마나 비슷한지"를 계산하는데, 이때 **"누가 이웃인지"를 미리 정의**해줘야 합니다. 그 정의를 담은 표가 공간가중치행렬입니다.

구성 방식: N개의 지역이 있으면 N×N 크기의 표를 만들고, 두 지역이 이웃이면 큰 숫자(또는 1)를, 이웃이 아니면 0을 적습니다. 자기 자신과의 칸은 비워둡니다.

| 종류 | 이웃을 정하는 기준 | 사용되는 경우 |
|---|---|---|
| **Queen 인접성** | 경계선 또는 꼭짓점이 하나라도 맞닿으면 이웃 (체스 퀸처럼 상하좌우+대각선) | 행정구역·격자·폴리곤 자료에서 가장 넓게 인접 지역을 보고 싶을 때 |
| **Rook 인접성** | 경계선이 맞닿는 경우만 이웃 (체스 룩처럼 상하좌우만) | 행정구역 간 실제 접경 관계를 엄격하게 보고 싶을 때 |
| **KNN** | 가장 가까운 k개의 관측치를 이웃으로 지정 | 점 데이터(거래 데이터, 시설 위치 등)처럼 폴리곤 경계가 없을 때 |

> 이웃을 정의하는 기준에 따라 Moran's I의 해석이 달라질 수 있으므로, 결과를 보고할 때는 **어떤 기준으로 이웃을 정했는지 반드시 함께 명시**해야 합니다. (이번 실습에서는 Queen과 Rook 두 기준 모두 Moran's I가 0.790으로 일치 → 특정 이웃 정의에 기댄 결과가 아니라는 근거로 사용)

**행 표준화(transform) 옵션**

| 값 | 내용 |
|---|---|
| R | 이웃 수 차이를 완화함 (일반적인 Moran's I에 권장) |
| B | 이웃이면 동일하게 1로 처리 (인접 여부만 단순 반영) |
| V | 이웃 수 차이에 따른 분산 문제를 줄임 (특수한 분산 보정 목적) |

### 5-4. Moran's I 계산 코드 흐름

**절차**: pandas(일반 DataFrame) → geopandas(위경도를 공간 데이터로 변환) → pyproj(좌표계 지정) → libpysal(이웃 관계·가중치 정의) → esda(Moran's I 계산)

**좌표계**: 위·경도(도 단위, EPSG:4326)는 거리 계산에 그대로 쓸 수 없습니다. Moran's I를 계산하려면 **거리 계산이 가능한 좌표계(이번 실습은 한국 좌표계 EPSG:5186 사용)**로 변환해야 합니다. — California 데이터인데 한국 좌표계를 쓴 것은 실습 편의상이며, 실제로는 대상 지역에 맞는 투영좌표계(예: 미국이면 State Plane, Albers 등)를 써야 합니다.

```python
# 1. 포인트 좌표(지오메트리) 객체 생성 — 위경도를 점(Point) 객체로 변환
geometry = points_from_xy(x=origin["longitude"], y=origin["latitude"])

# 2. GeoDataFrame 생성 (원본 위경도 컬럼은 geometry로 대체되므로 제거)
df1 = origin.drop(columns=["longitude", "latitude"])
gdf = GeoDataFrame(df1, geometry=geometry, crs="EPSG:4326")
gdf = gdf.to_crs(epsg=5186)  # 거리 계산이 가능한 좌표계로 변환

# 3. 인접기반 공간가중치 행렬 생성
qw = Queen.from_dataframe(gdf, use_index=False)
qw.transform = "R"  # 행 표준화

rw = Rook.from_dataframe(gdf, use_index=False)
rw.transform = "R"

# 4. 종속변수에 대한 Moran's I 계산
y = gdf["median_house_value"]
moran_q = Moran(y, qw)   # Queen 기준
moran_r = Moran(y, rw)   # Rook 기준
# moran_q.I  → Moran's I 값
# moran_q.p_sim → 순열검정 기반 p-value
```

**결과 (이번 데이터셋)**

| 공간가중치행렬 | Moran's I | p-value |
|---|---|---|
| Queen 인접 | 0.790 | 0.001 |
| Rook 인접 | 0.790 | 0.001 |

→ 두 기준 모두 소수점 셋째 자리까지 일치. **매우 강한 양의 공간자기상관**이 유의하게(p<0.05) 확인됨. **결론: 인접한 주택끼리는 가격이 비슷하다.**

### 5-5. 공간자기상관을 파생변수로 만들기 — K-Means 공간 군집

Moran's I는 "공간자기상관이 있다/없다"만 알려줄 뿐, 그 자체로는 모델에 넣을 변수가 아닙니다. 그래서 위·경도 좌표를 **K-Means 군집분석**으로 몇 개의 지역 군집으로 나누고, 그 군집 번호를 범주형 파생변수(`special_cluster`)로 만들어 모델에 투입합니다.

**군집 수(k) 결정 절차**: 2~9 범위에서 k별로 군집을 만들어보고, 두 지표(엘보우, 실루엣)를 비교합니다.

```python
final_k, _ = my_cluster.best_k(df, klist=list(range(2, 10)),
                                columns=['latitude', 'longitude'],
                                plot_each=True, width=740, height=480)
```

- **엘보우(elbow) 포인트**: 군집 내 응집도(이너셔)가 급격히 줄어들다 완만해지는 지점 → 이번 데이터에서는 k=5
- **실루엣 계수**: 군집이 얼마나 잘 뭉치고(cohesion) 잘 분리되어(separation) 있는지의 균형지수 → 이번 데이터에서는 k=2가 최고점(0.755)

**두 지표가 다른 k를 가리킬 때 — 분석가의 판단**

이번 실습의 핵심 교훈: **지표는 후보를 좁혀줄 뿐, 최종 선택은 목적과 도메인 지식으로 한다.**

- k=2는 통계적으로는 가장 깔끔하지만 "고가지역 vs 저가지역" 이분화에 불과 → 캘리포니아 주택시장의 지역적 다양성을 반영하지 못함 → 파생변수로서 정보량이 너무 적음
- k=5는 엘보우와 일치하고, 실루엣 0.581로 기준선(0.5) 이상 → 5개의 지리·경제적 특성으로 시장을 나눌 수 있어 해석 가능성이 높음
- **최종 선택: k=5** — "통계 품질과 실무적 유용성의 절충점"

```python
final_k = 5
estimator, cdf, _ = my_cluster.kmeans(df, k=final_k, columns=['latitude', 'longitude'])

df["special_cluster"] = cdf["그룹번호"].astype("category")
```

**군집별 특성 (검정으로 확인)**

| 군집 | 건수 | 평균 집값 | 해당 권역 |
|---|---|---|---|
| 1 | 8,729 | 230,623$ | 남부 (LA 권역) |
| 2 | 6,736 | 224,716$ | 중북부 (베이 권역) |
| 3 | 2,211 | 177,072$ | 최남부 (샌디에이고 권역) |
| 4 | 1,778 | 121,984$ | 중부 내륙 (센트럴밸리) |
| 0 | 979 | 93,639$ | 북부 내륙 |

Welch ANOVA로 검정한 결과 F=2,299.2 (p<0.001), np2=0.126(Medium) — **위·경도 좌표 두 개만으로 만든 단일 변수가 집값 분산의 12.6%를 설명**합니다. 사후검정(Games-Howell) 10쌍 전부 유의해서, 5개 군집이 실제로 서로 다른 가격대를 형성하고 있음을 확인했습니다.

> Moran's I(0.790)라는 추상적 진단이, K-means를 거쳐 "5개의 구체적인 시장 권역"이라는 실체 있는 변수로 번역된 흐름입니다. **공간자기상관 확인 → 군집화 → 검정으로 검증**이라는 3단계 논리를 기억하세요.

## 6. 파생변수 검증 — "만들었다"와 "쓸 만하다"는 다른 문제

### 6-1. 검증 설계 원칙

새로 만든 변수라고 그냥 모델에 넣으면 안 됩니다. **원본 데이터와 똑같은 잣대로 재검증**한 후에 채택 여부를 결정합니다.

| 순서 | EDA 단계에서 했던 것 | 파생변수 검증 단계에서 할 것 |
|---|---|---|
| ① | 단변량 분석 — 분포·왜도·이상치 | 파생변수 분포 재점검 |
| ② | 이변량 분석 — 상관 / T-Test / ANOVA | 파생변수의 종속변수 설명력 검증 |
| ③ | 다변량 분석(필요시) | 파생변수 간 상관분석 (공선성 확인) |
| ④ | 종합 판단 | 채택 · 후보 · 보류 판정 |

> 새 변수에 검증을 생략하면, 검증 없는 변수로 모델을 만드는 셈입니다.

### 6-2. 검증 절차 코드 흐름

```python
# 1) 검증 대상 분류
derived_continuous = ['rooms_per_person', 'rooms_per_household',
                       'bedrooms_per_room', 'population_per_household', 'income_per_person']
derived_nominal = ['is_age_capped', 'is_income_capped', 'ocean_area', 'special_cluster']

# 2) 연속형 기술통계 (분포 재점검 — 왜도, 이상치, 로그 변환 필요 여부까지 자동 판정)
derived_num_desc = my_qtcheck.numerical_summary(df, columns=derived_continuous)

# 3) 범주형 기술통계 (category 타입으로 변환 후)
df = my_qtcheck.set_type(df, as_category=derived_nominal)
derived_cat_desc = my_qtcheck.categorical_summary(df, columns=derived_nominal, value_counts=False)

# 4) 단변량 분석 — 분포 시각화 반복
for f in derived_continuous:
    my_plot.histplot(data=df, x=f, kde=True, title=f"파생변수 {f}({column_means[f]})분포")

for n in derived_nominal:
    my_plot.countplot(data=df, x=n, title=f"파생변수 {n}({column_means[n]})분포")

# 5) 이변량 분석 — 연속형 파생변수 → 종속변수 (상관분석)
for f in derived_continuous:
    my_plot.scatterplot(data=df, x=f, y=target)
    display(my_stats.correlation(df, x=f, y=target, plot=False))

# 6) 이변량 분석 — 2집단 범주형 파생변수 → 종속변수 (T-Test류)
for n in derived_nominal:
    if len(df[n].unique()) == 2:
        wide_df = my_prep.long2wide(df, hue=n, values=target)
        display(my_stats.test_independent(wide_df, group1=wide_df.columns[0], group2=wide_df.columns[1]))

# 7) 이변량 분석 — 3집단 이상 범주형 파생변수 → 종속변수 (ANOVA류)
for n in derived_nominal:
    if len(df[n].unique()) >= 3:
        display(my_stats.anova_oneway(df, y=target, between=n))
        display(my_stats.posthoc_oneway(df, y=target, between=n, plot=False))

# 8) 다변량 분석 — 파생변수끼리 상관관계 (같은 원본 재료를 나눠 만들었으므로 중복 점검 필수)
corr = my_stats.multi_correlation(df, columns=derived_continuous, plot=False)
my_stats.correlation_summary(corr)
```

**패턴**: `for` 반복문으로 변수 목록을 순회하면서, "고유값 개수(unique 개수)"로 검정 방법을 자동 분기시키는 구조입니다 — 2개면 T-Test류, 3개 이상이면 ANOVA류. 이 구조를 그대로 재사용하면 다른 데이터셋에서도 검정 방법을 일일이 손으로 고르지 않아도 됩니다.

**범주형 파생 4종 — 검정은 유의해도 채택 여부는 표본 크기까지 봐야 한다**

| is_age_capped | 1: 6.2% / 0: 93.8% | T-Test | 평균차 73,051$ | 채택 |
| is_income_capped | 1: 0.2%(50건) / 0: 99.8% | T-Test | 평균차 281,451$(최대) | **보류** |

`is_income_capped`가 보류된 이유는 **효과크기가 아니라 표본 크기** 때문입니다. 평균차가 28만$로 가장 크지만, 그 차이를 단 50건(전체의 0.2%)으로 추정했다는 사실 자체가 위험합니다. EDA 때 `ISLAND` 5건을 신뢰하지 않았던 것과 같은 논리입니다. — **"효과크기가 크다"와 "그 추정을 믿을 수 있다"는 별개의 문제**임을 기억하세요.

## 9. 통계 개념 사전 (기호 대신 말로)

### 9-1. 가설검정의 기본 구조

모든 통계적 검정은 **"차이가 없다"는 기본 전제(귀무가설)를 세워두고, 데이터가 그 전제를 의심할 만큼 이상한지를 확인**하는 절차입니다.

- **귀무가설(H₀, null hypothesis)**: "아무 효과도, 차이도 없다"는 기본 전제. 예를 들어 두 그룹의 모평균(그룹 전체를 대표하는 참값의 평균, 기호로는 μ)을 비교한다면, 귀무가설은 "두 그룹의 모평균은 같다(μ₁ = μ₂)"입니다.
- **대립가설(H₁, alternative hypothesis)**: 우리가 실제로 보이고 싶은 주장. "두 그룹의 모평균은 다르다(μ₁ ≠ μ₂)"입니다.
- **p-value**: "귀무가설이 참이라고 가정했을 때, 지금 관측한 것만큼 극단적인 차이가 우연히 나올 확률". 이 값이 작다는 건 "귀무가설이 맞다면 이런 데이터가 나올 확률이 매우 낮다"는 뜻이므로, 귀무가설을 의심하고 기각합니다. 관례적으로 0.05를 기준으로 삼습니다(5% 미만이면 "유의하다"고 판단).
- **유의성(significant)**: p-value가 기준(보통 0.05)보다 작아서 귀무가설을 기각할 수 있는 상태.

**주의**: 유의하다는 건 "차이가 우연이 아니다"라는 뜻이지, "그 차이가 실질적으로 크다"는 뜻이 아닙니다. 표본이 크면 아주 작은 차이도 쉽게 유의해집니다. 그래서 항상 **효과크기(effect size)**를 같이 봐야 합니다.

### 9-2. Spearman 순위상관계수 (ρ, rho)

**직관**: 두 변수가 "같은 방향으로 함께 움직이는지"를 재는 지표인데, 값 자체가 아니라 **순위**로 계산합니다. 예를 들어 소득이 오를 때 집값도 대체로 함께 오르는 경향이 있는지를, "누가 몇 등인지"만 놓고 비교합니다.

**언제 Pearson 대신 Spearman을 쓰는가**: Pearson 상관계수는 두 변수가 "직선(선형)" 관계이고 정규분포를 따를 때 적합합니다. 이 데이터셋처럼 변수들이 정규분포를 따르지 않거나(정규성 위반), 이상치가 많거나, 관계가 곡선(단조적이지만 비선형)일 때는 순위 기반인 Spearman이 더 안정적입니다. 순위로 바꾸면 극단적인 이상치 하나가 전체 상관을 왜곡하는 영향이 줄어듭니다.

**값 해석**: −1 ~ +1 범위. 0에 가까울수록 관계 없음, ±1에 가까울수록 강한 단조 관계. 부호는 방향(+는 같은 방향, −는 반대 방향), 절댓값은 강도.

### 9-3. Mann-Whitney U 검정 (독립 2표본, 비모수)

**직관**: 독립된 두 그룹(예: 해안권 vs 내륙권)의 값을 비교할 때 쓰는 검정입니다. 원래 이런 비교에는 **독립표본 T-검정**을 쓰는데, T-검정은 "각 그룹의 데이터가 정규분포를 따른다"는 가정이 필요합니다. 이 가정이 깨지면(정규성 위반) 대신 순위를 기반으로 비교하는 Mann-Whitney U 검정을 씁니다.

**작동 방식**: 두 그룹의 값을 전부 하나로 합쳐서 순위를 매긴 다음, 각 그룹의 순위 합을 비교합니다. 한 그룹의 값들이 전체적으로 더 높은 순위에 몰려 있으면 두 그룹이 다르다고 판단합니다.

**귀무가설**: "두 그룹의 분포(중심 경향)는 같다." / **대립가설**: "두 그룹의 분포는 다르다."

### 9-4. 일원분산분석(ANOVA)과 Welch ANOVA

**직관**: 3개 이상 그룹의 평균을 한 번에 비교하는 검정입니다. "그룹 간 평균 차이"가 "그룹 내부의 자연스러운 흩어짐(분산)"에 비해 충분히 큰지를 F통계량으로 판단합니다.

**귀무가설**: "모든 그룹의 모평균이 같다(μ₁=μ₂=μ₃=…)." / **대립가설**: "적어도 한 그룹은 평균이 다르다."

**일반 ANOVA vs Welch ANOVA**: 일반적인 ANOVA는 "각 그룹의 분산이 서로 같다(등분산성)"는 가정이 필요합니다. `special_cluster`처럼 그룹별 표본 크기가 크게 다르고(979건 ~ 8,729건) 분산도 다를 가능성이 높은 경우, 이 가정이 깨지기 쉽습니다. **Welch ANOVA는 이 등분산 가정 없이도 쓸 수 있는 안전한 버전**이라 실무에서 기본으로 선호됩니다.

### 9-5. 사후검정(Post-hoc test) — Games-Howell

**왜 필요한가**: ANOVA는 "그룹 중 최소 하나는 다르다"까지만 말해줄 뿐, **어느 그룹과 어느 그룹이 다른지는 알려주지 않습니다.** 그래서 ANOVA가 유의하게 나오면, 모든 그룹 쌍을 하나하나 비교하는 사후검정을 추가로 합니다.

**Games-Howell을 쓰는 이유**: 여러 사후검정 방법 중 Games-Howell은 (Tukey HSD와 달리) **그룹별 표본 크기와 분산이 달라도** 쓸 수 있습니다. Welch ANOVA와 짝을 이루는 사후검정입니다.

**다중비교 문제**: 그룹이 5개면 짝은 10개(5×4÷2)가 생기는데, 비교를 10번 반복하면 우연히 유의한 결과가 나올 확률(1종 오류)이 누적됩니다. Games-Howell 같은 사후검정은 이 문제를 통계적으로 보정해줍니다.

### 9-6. 효과크기(Effect Size)

**왜 p-value만으로는 부족한가**: p-value는 표본 크기의 영향을 크게 받습니다. 표본이 20,000건이 넘는 이 데이터셋에서는 아주 사소한 차이도 거의 항상 유의(p<0.05)하게 나옵니다. 그래서 "차이가 통계적으로 존재하는가"(p-value)와 별개로 "그 차이가 실질적으로 얼마나 큰가"(효과크기)를 반드시 함께 봅니다.

- **np2 (partial eta squared, ηₚ²)**: ANOVA에서 쓰는 효과크기. "종속변수의 전체 분산 중 몇 %가 이 그룹 구분으로 설명되는가"를 뜻합니다. 예: special_cluster의 np2=0.126은 "집값 분산의 12.6%가 공간 군집 하나로 설명된다"는 뜻. 관례적 기준: 0.01=Small, 0.06=Medium, 0.14=Large (Cohen 기준).
- **Hedges' g**: 두 그룹 평균 차이를 표준편차 단위로 표준화한 값(Cohen's d의 소표본 보정판). "두 그룹 평균이 표준편차 몇 개만큼 떨어져 있는가"를 뜻합니다.
- **Cramér's V**: 범주형 변수 간(교차표) 연관성의 효과크기.

### 9-7. 정규성(Normality)

**정의**: 데이터가 정규분포(종 모양의 좌우대칭 분포)를 따르는 정도. 많은 통계 기법(Pearson 상관, T-검정, 일반 ANOVA)이 "데이터가 정규분포를 따른다"는 가정 위에서 만들어졌기 때문에, 정규성 위반 여부를 먼저 확인하고 위반 시 비모수 검정(Spearman, Mann-Whitney, Welch ANOVA 등)으로 갈아탑니다. 이번 데이터셋은 `normality_x`, `normality_y`가 대부분 False로 나와, 애초에 Spearman·Mann-Whitney를 쓴 근거가 됩니다.

### 9-8. 왜도(Skewness)와 로그 변환

**왜도**: 분포가 좌우로 얼마나 치우쳐 있는지를 나타내는 수치. 0이면 좌우대칭, 양수면 오른쪽으로 긴 꼬리(우편향, 극단적으로 큰 값들이 소수 존재), 음수면 왼쪽으로 긴 꼬리(좌편향)입니다.

**왜 로그를 씌우는가**: 우편향된 데이터는 큰 값들이 결과를 왜곡시키기 쉽고, 선형모델이 가정하는 정규성/등분산성과도 맞지 않습니다. 로그 변환은 큰 값의 간격을 압축하고 작은 값의 간격을 상대적으로 벌려서, 분포를 정규분포에 가깝게 만들어줍니다. `rooms_per_person`의 왜도가 17.76(극단적 우편향) → 로그 변환 후 −0.73(거의 대칭)으로 개선된 사례가 그 효과를 보여줍니다.

### 9-9. 다중공선성(Multicollinearity)

**정의**: 독립변수들끼리 서로 강하게 상관되어 있는 상태. 이번 랩에서는 상관계수(ρ)로 미리 점검했지만(예: bedrooms_per_room과 rooms_per_household가 −0.888로 매우 강한 음의 상관), 다음 랩에서 **VIF(분산팽창지수)**로 더 정밀하게 확인합니다. 다중공선성이 심하면 회귀계수의 해석이 불안정해지고, 어떤 변수가 진짜 설명력을 가지는지 구분하기 어려워집니다. — 지금 단계에서는 "같은 원본 재료를 나눠 만든 파생변수끼리는 서로 겹칠 수밖에 없다"는 것만 인지하고, 최종 채택은 VIF 확인 이후로 미룹니다.

### 9-10. 공간자기상관 / Moran's I (5장 참고, 요약)

Moran's I는 "한 관측치의 값이, 정의된 이웃들의 값과 얼마나 비슷한 방향으로 편차를 갖는지"를 측정합니다. 전체 관측치 각각에 대해 "내 값이 평균보다 높은가/낮은가"와 "내 이웃들의 값이 평균보다 높은가/낮은가"를 비교해서, 이 편차들이 전반적으로 같은 방향으로 움직이면 Moran's I는 양수(+)가 됩니다.
