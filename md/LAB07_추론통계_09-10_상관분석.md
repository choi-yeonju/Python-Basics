## 1. 통계 개념 완전 풀어쓰기 (면접 답변용)

### 1-1. 공분산 (Covariance)

- **정의**: 두 변수가 "같이 움직이는 방향과 정도"를 나타내는 지표. 한 변수가 평균보다 클 때 다른 변수도 평균보다 크면 양수, 반대로 움직이면 음수가 나온다.
- **문제점**: 공분산은 변수의 **단위(scale)에 영향을 받는다.** 예를 들어 키를 cm로 재느냐 m로 재느냐에 따라 공분산 값 자체가 확 달라진다. 그래서 공분산만 보고 "관계가 강하다/약하다"를 말할 수 없다.
- 이걸 해결하려고 표준화한 게 **상관계수**다. (공분산을 각 변수의 표준편차로 나눠서 -1~1 사이 값으로 만든 것)

```python
c = np.cov(origin['언어영역'], origin['수리영역'])
```
→ 대각선은 각 변수의 분산, 비대각선이 공분산. 이 자체는 해석에 잘 안 쓰고 "상관계수의 전 단계"라고 이해하면 됨.

### 1-2. 피어슨 상관계수 (Pearson's r) — 모수적(parametric) 방법

- **정의**: 두 연속형 변수 사이의 **직선(선형) 관계의 강도와 방향**을 -1~+1 사이 값으로 나타낸 지표.
  - +1에 가까움: 한 변수가 커지면 다른 변수도 커지는 완벽한 직선 관계
  - -1에 가까움: 한 변수가 커지면 다른 변수는 작아지는 완벽한 직선 관계
  - 0에 가까움: 직선 관계가 없음 (곡선 관계는 있을 수도 있음! 이건 나중에 "선형성" 항목에서 다시 나옴)

- **가설 설정 (말로 풀어서)**
  - 모수는 모상관계수 **ρ (rho)** 를 사용한다.
  - **귀무가설(H0)**: "모집단에서 두 변수의 상관계수는 0이다." (즉, 두 변수는 모집단 수준에서 아무 선형 관계가 없다 → ρ = 0)
  - **대립가설(H1)**: "모집단에서 두 변수의 상관계수는 0이 아니다." (즉, 어떤 형태로든 선형 관계가 존재한다 → ρ ≠ 0)
  - p-value가 유의수준(보통 0.05)보다 작으면 귀무가설을 기각 → "우연이라고 보기엔 관계가 뚜렷하다, 상관이 있다"고 결론.

- **전제 조건 (가정)**: 피어슨은 아무 데이터에나 쓸 수 있는 게 아니다. 아래 조건이 다 만족돼야 신뢰할 수 있음.
  1. 두 변수 모두 **정규분포**를 따를 것
  2. 두 변수의 관계가 **직선(선형)** 일 것
  3. **이상치(영향점)** 가 계수를 왜곡시키지 않을 것
  4. 데이터가 등간척도/비율척도(연속형)일 것

```python
pearson_r, pearson_p = pearsonr(origin["언어영역"], origin["수리영역"])
```

### 1-3. 스피어만 상관계수 (Spearman's ρ) — 비모수적(non-parametric) 방법

- **정의**: 원래 값이 아니라 **순위(rank)** 로 변환한 뒤 그 순위끼리의 상관관계를 보는 지표.
- **언제 쓰나**: 피어슨의 전제조건(정규성, 선형성, 이상치 없음)이 깨졌을 때 대체제로 쓴다. "값 자체"보다 "누가 몇 등인지 순서 경향"이 얼마나 일치하는지를 본다.
- **가설도 동일한 논리**: H0는 "두 변수의 순위 사이에 단조적(monotonic) 관계가 없다", H1은 "단조적 관계가 있다".
  - 참고: 피어슨은 "직선" 관계를 보지만, 스피어만은 "단조 증가/감소" 관계까지 잡아낼 수 있어서 더 유연함 (곡선이어도 계속 증가만 한다면 스피어만은 잡아낼 수 있음).

```python
spearman_r, spearman_p = spearmanr(origin["언어영역"], origin["수리영역"])
```

> **피어슨 vs 스피어만, 한 문장 암기**: "피어슨은 원래 숫자의 직선관계, 스피어만은 순위의 단조관계. 정규성·선형성·이상치 중 하나라도 깨지면 스피어만으로 갈아탄다."

### 1-4. 상관계수 강도 해석 기준

`my_stats.correlation()` 안에 하드코딩된 판정 기준:

| \|r\| 범위 | 라벨 | 의미 |
|---|---|---|
| r = 0 | None | 관계 없음 |
| 0 < \|r\| ≤ 0.3 | Weak | 약한 상관 |
| 0.3 < \|r\| ≤ 0.7 | Moderate | 중간 상관 |
| \|r\| > 0.7 | Strong | 강한 상관 |

이 숫자 자체는 절대적인 게 아니라 **관례적인 경험 규칙**이라는 점도 같이 알아두기 (분야마다 기준이 조금씩 다를 수 있음).

### 1-5. 정규성 검정 (Normality Test)

- 여기서 쓰는 함수는 `scipy.stats.normaltest` (D'Agostino and Pearson's test).
- **가설**
  - H0: "이 데이터는 정규분포를 따르는 모집단에서 나왔다."
  - H1: "정규분포를 따르지 않는다."
- p-value ≥ α(0.05) → 귀무가설 기각 못 함 → "정규성을 만족한다"고 판단(=`result: True`).
- 헷갈리기 쉬운 포인트: **p-value가 크다 = 정규성을 "증명"한 게 아니라 "위배된다고 볼 근거가 부족하다"** 는 뜻. 통계적 가설검정은 항상 "기각 못 함 = 인정"이 아니라 "기각할 증거 없음"이라는 걸 면접에서 강조하면 좋음.

```python
report = my_stats.test_assumptions(origin, columns=["언어영역", "수리영역"])
```

### 1-6. 선형성 검정 — Ramsey RESET Test

- **왜 필요한가**: 산점도를 눈으로 보는 것만으로는 "선형이다/아니다"를 객관적으로 판단하기 어렵다. 그래서 통계적 검정으로 보완한다.
- **아이디어**: 먼저 단순 선형회귀(직선 모델)를 적합시킨 뒤, 그 모델이 놓친 비선형 패턴(제곱항 등)이 남아있는지 검정한다.
- **가설**
  - H0: "지금의 선형 모형이 데이터를 올바르게 설명하고 있다." (=선형성 충족)
  - H1: "선형 모형이 놓치고 있는 비선형 패턴이 존재한다." (=선형성 위배, 원래는 곡선 관계일 수 있음)
- p-value ≥ α → 귀무가설 기각 못 함 → 선형성 충족(`linearity: True`)

```python
X = sm.add_constant(x)              # 상수항(절편) 추가 - 회귀분석에서 항상 하는 절차
model = sm.OLS(y, x).fit()          # 단순 선형회귀 적합
reset = linear_reset(model, power=2, use_f=True)
```
> `sm.add_constant(x)` 를 안 넣으면 절편이 0으로 고정된 모델이 되어버려서 왜곡될 수 있음. 나중에 회귀분석 LAB에서 자세히 다룰 예정이라고 강사님 코드에도 주석 있음 — 지금은 "선형성 검정할 때 항상 상수항을 붙인다" 정도로만 기억.

### 1-7. 이상치(Outlier) & 왜도(Skewness) & 영향점(Influential point)

세 개념을 구분하는 게 중요함. 다 다른 개념인데 묶여서 같이 판정됨.

- **이상치(Outlier)**: 다른 데이터들과 동떨어진 값. 여기서는 **IQR(사분위범위) 규칙**으로 판단.
  - `Q1 - 1.5×IQR` 보다 작거나 `Q3 + 1.5×IQR` 보다 크면 이상치.
- **왜도(Skewness)**: 분포가 좌우 대칭이 아니고 한쪽으로 얼마나 치우쳤는지 나타내는 지표.
  - 0에 가까움: 대칭
  - 양수: 오른쪽 꼬리가 긴 분포 (큰 값 쪽에 소수의 극단값)
  - 음수: 왼쪽 꼬리가 긴 분포
  - `|skew| > 1` 이면 "왜도가 크다"고 판정 (`high_skew`)
- **영향점(Influential outlier)**: 이상치가 "있다"는 사실 자체보다 중요한 건 **그 이상치가 실제로 상관계수를 크게 바꾸는가**이다.
  - 방법: 이상치를 뺀 데이터로 다시 피어슨 r을 구해서, 원래 r과 **0.1 이상 차이가 나면** "영향점이 있다"고 판단.
  - 즉 "이상치 존재 여부"와 "이상치가 결과를 왜곡하는지"는 별개의 판단이라는 게 이 실습의 핵심 포인트. 이상치가 있어도 결과에 큰 영향이 없으면 굳이 제거할 필요 없다는 뜻.

```python
q1 = temp.quantile(0.25)
q3 = temp.quantile(0.75)
iqr = q3 - q1
out_iqr = int(np.sum((temp < q1-1.5*iqr) | (temp > q3+1.5*iqr)))
```

### 1-8. 피어슨 vs 스피어만 최종 선택 로직 (`my_stats.correlation` 내부)

```
정규성 충족(x,y 둘 다) AND 선형성 충족 AND 영향점 없음 AND 왜도 크지 않음
        → 모두 True 이면 Pearson
        → 하나라도 False 이면 Spearman
```
이게 `correlation()` 함수가 자동으로 해주는 "가정 진단 → 방법 선택" 로직임. 이 순서를 외우면 나중에 손으로도 짤 수 있고, 다른 사람 코드를 봐도 바로 이해됨.

## 2. 분석 파이프라인 (처음부터 끝까지 순서)

새로운 데이터셋을 받았을 때 상관분석을 한다면 아래 순서를 그대로 따라가면 됨.

```
1. 데이터 로드 & 결측치 처리 (두 변수 함께 dropna)
        ↓
2. 산점도로 관계 눈으로 확인 (my_plot.lmplot / scatterplot)
        ↓
3. 정규성 검정 (normaltest, my_stats.test_assumptions)
        ↓
4. 선형성 검정 (Ramsey RESET Test)
        ↓
5. 이상치 탐지(IQR) + 영향점 판정(제거 전후 r 비교) + 왜도 확인
        ↓
6. 가정 충족 여부 종합 → Pearson 쓸지 Spearman 쓸지 결정
        ↓
7. 상관계수 + p-value 계산 → 귀무가설 기각 여부 판단
        ↓
8. 강도(Strong/Moderate/Weak) 라벨링 + 결과표 정리
        ↓
9. 시각화(산점도+회귀선) + 결론 문장 작성
```

**9차시**는 이 중 2, 3(공분산까지만), 7, 8단계를 손으로 짜본 것 (가정 검정은 아직 본격적으로 안 함).
**10차시**는 1~9 전체를 명시적으로 다 짜보고, 마지막에 이걸 `my_stats.correlation()` 함수 하나로 압축한 것.

## 3. 직접 코딩 버전 vs 모듈 호출 버전 — 왜 두 가지로 나눠서 배우는가

이 실습에서 계속 나오는 패턴인데, 이유를 정확히 알아야 함.

| | 직접 코딩 (raw) | 모듈 호출 (`my_stats.correlation`) |
|---|---|---|
| 예시 | `pearsonr()`, `sm.OLS()`, `normaltest()` 을 셀마다 따로 호출 | `my_stats.correlation(df, "x", "y")` 한 줄 |
| 목적 | **원리를 이해하기 위해** — 각 단계가 뭘 계산하는지, 어떤 가설을 세우는지 직접 봐야 함 | **실전에서 빠르고 일관되게 반복** 하기 위해 |
| 언제 쓰나 | 새로운 통계 기법을 처음 배울 때, 이상한 결과가 나왔을 때 원인 추적할 때 | 이미 원리를 아는 상태에서 데이터셋 여러 개를 반복 분석할 때 (baseball, product, study_time처럼) |

> **왜 순서가 "직접 코딩 → 모듈화"인가**: 모듈(`my_stats.py`)의 함수들은 결국 이 직접 코딩 셀들을 그대로 함수 안에 넣은 것뿐임 (실제로 `correlation()` 함수 코드를 열어보면 9,10차시에서 손으로 짠 코드와 거의 똑같은 로직이 순서대로 들어있음). **모듈을 먼저 외우려고 하지 말고, "내가 직접 짤 수 있는 코드를 함수로 포장한 것"이라는 관점으로 봐야** 나중에 함수가 이상하게 동작할 때 내부를 뜯어보고 고칠 수 있음.

10차시 코드에서 실제로 이 관계가 보임:
```python
# [손코딩 버전] - #02 섹션에서 직접 단계별로 실행
report = my_stats.test_assumptions(...)   # 이미 정규성만 재사용
...직선성 검정, 이상치 점검, r 비교를 셀 하나하나에 직접 작성...

# [모듈화 버전] - #03 섹션
my_stats.correlation(origin, "언어영역", "수리영역")   # 위 전체 과정을 한 줄로
```
→ 즉 **한 노트북 안에서 "이 로직을 함수로 만들면 이렇게 된다"를 보여주는 구조**로 짜여 있음. 이게 이 커리큘럼의 학습 설계 의도.

## 4. `helpers` 패키지 구조 & import 사고방식

```python
from jussam import load_data      # 강사님이 만든 실습용 데이터 로더 (외부 패키지)
from helpers import *             # 내가/우리 팀이 만든 통계·시각화 모듈 묶음
```

### 4-1. `helpers/__init__.py` 는 뭐하는 파일인가

- `helpers` 는 폴더(패키지)고, 그 안에 `my_stats.py`, `my_plot.py`, `my_prep.py` 같은 파일(모듈)들이 들어있음.
- `__init__.py` 는 **"이 폴더를 패키지로 취급해라"** 라고 파이썬에게 알려주는 파일이면서, 동시에 **"`from helpers import *` 했을 때 뭘 꺼내줄지"** 를 정의하는 파일.
- 보통 이 안에 아래처럼 적혀 있어서 `my_stats`, `my_plot` 이라는 이름을 바로 쓸 수 있게 해줌:
  ```python
  from . import my_stats
  from . import my_plot
  from . import my_prep
  ```
- 그래서 노트북에서 `from helpers import *` 한 줄만 써도 `my_stats.correlation(...)`, `my_plot.scatterplot(...)` 처럼 **모듈 이름을 그대로 붙여서** 쓸 수 있는 것.

### 4-2. `my_stats.py` 안에서도 다른 모듈을 가져다 씀 (내부 의존성)

```python
from . import my_plot     # 상단부
from . import my_prep
```
- 점(`.`)은 "같은 패키지 안의(helpers 폴더 안의)" 라는 뜻 → 상대 import(relative import).
- `correlation()` 함수 안에서 마지막에 `my_plot.scatterplot(...)` 을 호출해서 통계 계산과 시각화를 분리하되 필요할 때 서로 가져다 씀.
- **사고방식**: `my_stats.py`는 "숫자 계산(검정, 계수)" 담당, `my_plot.py`는 "그림 그리기" 담당, `my_prep.py`는 "데이터 전처리" 담당으로 **역할을 나눠서** 만든 것. 새 함수를 추가할 때도 "이건 계산이니까 my_stats에, 이건 그리는 거니까 my_plot에" 하는 식으로 분류해서 넣으면 됨.

### 4-3. 앞으로 이 구조를 어떻게 확장할 것인가

- 새로운 통계 기법(회귀분석, 카이제곱 등)을 배울 때마다 `my_stats.py`에 함수를 하나씩 추가하는 방식으로 커리큘럼이 짜여 있을 가능성이 높음 (실제로 파일 안에 `test_1sample`, `test_paired`, `anova_oneway`, `posthoc_oneway`, `anova_twoway`, `correlation` 등이 이미 순서대로 쌓여있는 걸 확인함).
- 이 함수들은 전부 **같은 패턴**으로 만들어져 있음:
  1. 데이터 정제(dropna 등)
  2. 가정 검정 (재사용 가능한 `test_assumptions` 같은 헬퍼를 다시 호출)
  3. 가정에 따라 방법(모수/비모수) 자동 선택
  4. 결과표(DataFrame) 로 정리해서 반환
  5. 옵션에 따라 시각화
  → **이 5단계 패턴을 외워두면**, 새 통계 기법이 추가돼도 "아 이것도 이 패턴이구나" 하고 빠르게 읽을 수 있음.
- **모듈 수정 시 필수 워크플로우** (예전에 이미 학습한 내용, 잊지 않기):
  ```python
  import importlib
  import helpers.my_stats
  importlib.reload(helpers.my_stats)
  ```
  `.py` 파일을 고친 뒤에는 Jupyter 커널이 이미 메모리에 올려놓은 예전 버전을 쓰고 있기 때문에 `reload()` 안 하면 수정사항이 반영 안 됨.

## 7. 면접 예상 답변 스크립트 (짧은 버전)

**Q. 상관분석을 할 때 어떤 순서로 진행하시나요?**

> "먼저 산점도로 대략적인 관계를 눈으로 확인하고, 정규성과 선형성 같은 가정을 검정합니다. 정규성은 D'Agostino 검정으로, 선형성은 Ramsey RESET Test로 확인하고, IQR 기준으로 이상치를 찾은 뒤 그 이상치를 제거했을 때 상관계수가 실제로 크게 바뀌는지를 봐서 '영향점'인지 판단합니다. 이 가정들이 모두 충족되면 피어슨 상관계수를, 하나라도 위배되면 스피어만 상관계수를 사용합니다. 마지막으로 p-value를 유의수준과 비교해서 상관관계가 통계적으로 유의한지 판단하고, 계수 크기로 강도를 해석합니다."

**Q. 피어슨과 스피어만의 차이는요?**

> "피어슨은 두 변수의 실제 값 사이의 직선(선형) 관계를 측정하는 모수적 방법이고, 정규성·선형성 같은 가정이 필요합니다. 스피어만은 값을 순위로 바꿔서 그 순위끼리의 단조적 관계를 보는 비모수적 방법이라 가정이 깨졌을 때 대안으로 씁니다."
