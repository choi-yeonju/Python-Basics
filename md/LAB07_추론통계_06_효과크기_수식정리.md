# 효과크기(Effect Size) 수식 총정리

> ANOVA 계열(η², η²ₚ, ω², ω²ₚ, ε²)부터 t-test 계열(Cohen's d), 카이제곱 계열(Cramér's V, φ), 비모수검정 계열(rank-biserial r), 회귀분석 계열(R², f²)까지 — "유의성과 별개로 효과의 크기를 수식으로 어떻게 표현하는가"만 모은 문서.

---

## 0. 효과크기가 필요한 이유 (복습)

- **가설검정(p-value)** → "차이가 존재하는가?"에 대한 답
- **효과크기** → "그 차이가 실질적으로 얼마나 큰가?"에 대한 답
- 표본이 매우 크면 아주 미세한 차이도 p<0.05로 나올 수 있음 → p-value 단독으로는 실무적 의미 판단이 어려움 → 항상 효과크기를 같이 보고함.

---

## 1. 표기법(기호) 정리 — 과목·교재마다 이름이 다른 이유 [추가]

같은 개념인데 **회귀분석 교재**와 **ANOVA 교재**가 서로 다른 기호를 쓰는 경우가 많다. 아래 표부터 확인하고, 이후 모든 절에서 어떤 기호로 바꿔 써도 값은 동일하다고 이해하면 된다.

### 1-1. 기호 대응표

| 기호                  | 의미                                  | 자주 쓰는 분야                                |
| --------------------- | ------------------------------------- | --------------------------------------------- |
| **SST (= TSS)** | Total Sum of Squares (전체 제곱합)    | 회귀, ANOVA                                   |
| **SSR**         | Regression(=Explained) Sum of Squares | 회귀                                          |
| **SSE**         | Error Sum of Squares                  | 회귀, ANOVA (※ 4번 참고, 분야마다 뜻이 갈림) |
| **SSB**         | Between Sum of Squares                | ANOVA                                         |
| **SSW**         | Within Sum of Squares                 | ANOVA                                         |
| **MST**         | Mean Square Total (= SST/(N−1))      | 이론에서만 가끔, 실무에서는 거의 안 씀        |
| **MSR**         | Mean Square Regression                | 회귀                                          |
| **MSE**         | Mean Square Error                     | 회귀, ANOVA                                   |
| **MSB**         | Mean Square Between                   | ANOVA                                         |
| **MSW**         | Mean Square Within                    | ANOVA                                         |

이 문서 3장 이후에서 쓴 표기와 매핑하면:

```
SS_Total  = SST = TSS
SS_Between (SS_Effect) = SSB (ANOVA) / SSR (회귀)
SS_Within  (SS_Error)  = SSW (ANOVA) / SSE (회귀·ANOVA 공용으로도 씀)
MS_Between = MSB (ANOVA) / MSR (회귀)
MS_Within  = MSW (ANOVA) / MSE (회귀·ANOVA 공용)
```

### 1-2. 분야별 분해식과 F 공식

**회귀분석**

```
SST = SSR + SSE

MSR = SSR / df_R
MSE = SSE / df_E

F = MSR / MSE
```

**ANOVA**

```
SST = SSB + SSW

MSB = SSB / (k − 1)
MSW = SSW / (N − k)

F = MSB / MSW
```

두 식은 이름만 다를 뿐 구조가 완전히 동일하다 — "전체변동 = 설명되는 변동 + 설명 안 되는(오차) 변동"이라는 하나의 틀을 회귀는 SSR/SSE로, ANOVA는 SSB/SSW로 부르는 것뿐.

### 1-3. 주의: SSE는 분야마다 반대 의미로 쓰이기도 한다 ⚠️

- **ANOVA·일반 실험설계**: SSE = Sum of Squares **Error** → 오차(잔차) 변동. 이 문서에서 SS_Within과 동일하게 쓴 것이 이 뜻.
- **일부 회귀분석 교재**: SSE = Sum of Squares **Explained** → 오히려 "회귀로 설명되는 변동"(SSR과 같은 뜻)을 가리키기도 함.
- 그래서 처음 보는 자료에서 SSE를 만나면, **그 문서가 SST = X + Y로 어떻게 분해하는지부터 확인**하고 SSE가 오차 쪽인지 설명 쪽인지 판단하는 습관이 필요하다. 헷갈릴 때는 아래 외국 교재 표기(RSS/ESS)가 이름 자체에 뜻이 들어있어 더 명확하다.

### 1-4. 외국 교재 표기 — TSS / ESS / RSS

```
TSS = ESS + RSS
```

| 기호 | 의미                     | 이 문서 대응       |
| ---- | ------------------------ | ------------------ |
| TSS  | Total Sum of Squares     | SS_Total           |
| ESS  | Explained Sum of Squares | SS_Between (= SSR) |
| RSS  | Residual Sum of Squares  | SS_Within (= SSE)  |

- 이 표기는 이름 자체가 "설명된(Explained)"/"잔차(Residual)"라서 1-3의 SSE 혼동 문제가 애초에 생기지 않는다는 장점이 있음. 해외 계량경제학·회귀분석 교재에서 특히 선호됨.

### 1-5. MST는 왜 실무에서 거의 안 쓰나

```
MST = SST / (N − 1)
```

- 존재는 하지만 ANOVA의 관심사는 "집단 간 변동(MSB)이 오차(MSW)보다 얼마나 큰가"이지, 전체 변동을 표본크기로 나눈 MST 자체는 F검정 계산에 들어가지 않는다.
- F검정은 항상 `F = MSB / MSW` (또는 회귀에서 `F = MSR / MSE`)이며, MST가 분자·분모 어디에도 등장하지 않는다.

### 1-6. 배경에 따라 헷갈리는 이유

- **회귀분석을 먼저 배운 경우**: SST(TSS) / SSR / SSE / MSR / MSE 표기가 익숙함.
- **ANOVA를 나중에 배우면**: 같은 개념인데 SSB / SSW / MSB / MSW라는 새 이름이 등장해서 혼란스러움.
- 실제로는 이름만 다른 같은 구조(전체=설명+오차)이므로, **어떤 시험·교재를 보고 있는지에 따라 그 교재의 표기를 기준으로 암기**하는 것이 가장 실용적이다. 이 문서 3장부터는 풀어쓴 이름(SS_Total 등)을 기본으로 쓰되, 필요할 때 이 표를 참고해 변환하면 된다.

## 2. ANOVA의 제곱합(SS) 분해 구조 — 모든 효과크기 공식의 출발점

```
SS_Total = SS_Between + SS_Within
         (= SS_Effect + SS_Error, 표기만 다를 뿐 동일한 개념)
```

| 기호                   | 의미                                                                        |
| ---------------------- | --------------------------------------------------------------------------- |
| SS_Total               | 전체 데이터가 전체평균으로부터 얼마나 퍼져있는지 (전체 변동)                |
| SS_Between (SS_Effect) | 각 집단평균이 전체평균으로부터 얼마나 떨어져 있는지 (집단 때문에 생긴 변동) |
| SS_Within (SS_Error)   | 각 데이터가 자기 집단평균으로부터 얼마나 떨어져 있는지 (집단 내부 오차)     |
| df_effect (df1)        | k − 1 (k = 집단 수)                                                        |
| df_error (df2)         | N − k (N = 전체 표본 수)                                                   |
| MS_Between             | SS_Between / df_effect                                                      |
| MS_Within              | SS_Within / df_error                                                        |
| F                      | MS_Between / MS_Within                                                      |

이 표의 SS/df/MS 값 6개(SS_Total, SS_Between, SS_Within, df1, df2, F)만 있으면 아래 모든 효과크기를 계산할 수 있다.

## 3. ANOVA 계열 효과크기

### 2-1. η² (Eta Squared) — 가장 기본형

```
η² = SS_Effect / SS_Total
```

- "전체 변동 중 집단(요인)이 설명하는 비율"을 가장 직관적으로 나타낸 값.
- 표본에 특정적으로(sample-specific) 계산되기 때문에, 요인이 여러 개인 설계에서는 다른 요인들의 변동까지 분모(SS_Total)에 다 포함되어 있어서 **같은 요인이라도 다른 요인이 몇 개 더 들어가느냐에 따라 η² 값이 흔들린다**는 단점이 있음.

### 2-2. η²ₚ (Partial Eta Squared) — 실무·SPSS·pingouin 표준

```
η²ₚ = SS_Effect / (SS_Effect + SS_Error)
```

- 분모에서 "다른 요인들의 변동"을 애초에 빼버리고, **오직 이 효과와 오차만 놓고** 비율을 계산 → 다요인 설계에서도 값이 안정적으로 유지됨.
- **일원분산분석(요인이 1개)일 때는 SS_Total = SS_Effect + SS_Error 이므로 η² = η²ₚ, 완전히 같은 값이 된다.** (요인이 2개 이상인 이원/삼원분산분석부터 두 값이 갈라짐)

### 2-3. ω² (Omega Squared) — 모집단 효과크기의 더 보수적인 추정치

```
ω² = (SS_Effect − df_effect × MS_Error) / (SS_Total + MS_Error)
```

- η²는 "표본" 안에서의 설명 비율이라 **표본이 작을수록 실제(모집단) 효과보다 부풀려지는 양의 편향(positive bias)**이 있음.
- ω²는 분자에서 `df_effect × MS_Error`만큼을 빼줌으로써 이 편향을 보정 → 우연히 생긴 집단 간 차이(오차로 설명 가능한 부분)를 효과에서 제외하는 구조.
- 그래서 항상 **ω² ≤ η²** 관계가 성립하고, 표본이 작을수록 두 값의 차이가 더 크게 벌어진다.
- 논문에서는 η²보다 ω²를 "더 보수적이고 편향이 적은" 지표로 추천하는 경우가 많음.

### 2-4. ω²ₚ (Partial Omega Squared) — 다요인 설계용

- 다요인 ANOVA(이원/삼원분산분석)에서 η²ₚ와 같은 논리로, ω²를 "해당 효과 + 오차"만 놓고 계산하도록 확장한 버전.
- 계산식이 설계 구조(요인 수, 반복측정 여부 등)에 따라 여러 형태로 달라지기 때문에 단일 공식으로 정리하기보다, 통계 패키지(R의 `effectsize`, `afex` 등)에 맡기는 것이 일반적.

### 2-5. ε² (Epsilon Squared)

```
ε² = (SS_Effect − df_effect × MS_Error) / SS_Total
```

- ω²와 목적(편향 보정)은 동일하지만 분모가 SS_Total이라는 점이 다름 (ω²는 분모가 SS_Total + MS_Error).
- η² : ε² 관계는 η² : ω² 관계와 거의 유사한 위치 — "기본형(η²) vs 편향보정형(ω² 또는 ε²)"의 짝으로 이해하면 됨.

### 2-6. 기호 계층 정리

```
SS
 ├─ SS_Total
 ├─ SS_Between (= SS_Effect)
 └─ SS_Within (= SS_Error)

MS
 ├─ MS_Between (= SS_Between / df1)
 └─ MS_Within  (= SS_Within / df2)

효과크기
 ├─ η²    = SS_Effect / SS_Total                                  (기본형, 편향 있음)
 ├─ η²ₚ   = SS_Effect / (SS_Effect + SS_Error)                     (다요인에서도 안정적)
 ├─ ω²    = (SS_Effect − df1×MS_Error) / (SS_Total + MS_Error)     (편향 보정)
 ├─ ω²ₚ   = 위 논리를 다요인 설계로 확장 (패키지 계산 권장)
 └─ ε²    = (SS_Effect − df1×MS_Error) / SS_Total                  (편향 보정, 분모만 다름)
```

## 4. F값만으로 효과크기를 계산하는 공식 (SS를 몰라도 됨)

논문·리포트에는 SS 값이 아니라 F(df1, df2) 형태만 제시되는 경우가 많다. 이럴 때는 F와 자유도만으로 역산이 가능하다.

### 3-1. Partial Eta Squared

```
η²ₚ = (F × df1) / (F × df1 + df2)
```

**검증 예시** (F=4.846, df1=2, df2=27):

```
η²ₚ = (4.846 × 2) / (4.846 × 2 + 27)
    = 9.692 / 36.692
    = 0.264
```

### 3-2. Eta Squared (일원분산분석 한정)

```
η² = F(k−1) / (F(k−1) + (N−k))
```

- 여기서 k=집단 수, N=전체 표본 수이며 df1=k−1, df2=N−k이므로, **일원분산분석에서는 이 식이 3-1의 η²ₚ 공식과 완전히 동일한 값을 준다.** (2-2에서 설명한 "일원분산분석에서 η²=η²ₚ" 사실의 계산적 근거)

### 3-3. Omega Squared (F 기반)

```
ω² = (df1 × (F − 1)) / (df1 × (F − 1) + N)
```

- SS 없이 F, df1, N만으로 계산 가능한 근사식. (정확한 값은 SS 기반 공식과 미세하게 다를 수 있으나 논문에서 널리 쓰이는 근사형)

### 3-4. F와 효과크기의 관계 방향성

```
집단 간 차이 커짐 → MS_Between 커짐 → F 커짐 → SS_Effect 비중 커짐 → η², ω² 모두 커짐
```

- F와 효과크기는 대체로 같은 방향으로 움직이지만, **자유도(df1, df2) 구성에 따라 항상 정비례하는 것은 아니다.** 같은 F값이라도 표본 크기(N, df2)가 다르면 효과크기 값은 달라진다.

## 5. t-test 계열 효과크기 — Cohen's d [추가]

t-test에서 가장 널리 쓰이는 효과크기는 ANOVA의 η² 계열이 아니라 **Cohen's d**다.

### 4-1. 독립표본 t-test (등분산 가정, pooled SD 기준)

```
d = (M1 − M2) / SD_pooled

SD_pooled = sqrt( ((n1−1)×SD1² + (n2−1)×SD2²) / (n1+n2−2) )
```

- 두 그룹 평균 차이를 "표준편차 단위"로 표준화한 값. "몇 cm 차이"가 아니라 "표준편차 몇 개만큼 차이나는가"로 해석.

### 4-2. 대응표본 t-test

```
d = (M_diff) / SD_diff
```

- diff(전−후)의 평균을 diff의 표준편차로 나눈 값.

### 4-3. t값만으로 계산 (독립표본, 등분산)

```
d = 2t / sqrt(df)          (df = n1 + n2 − 2)
```

### 4-4. 해석 기준 (Cohen, 1988)

| d        | 해석      |
| -------- | --------- |
| 0.2      | 작은 효과 |
| 0.5      | 중간 효과 |
| 0.8 이상 | 큰 효과   |

### 4-5. Cohen's d와 η²의 관계

같은 두 그룹 비교(t-test)를 ANOVA(그룹 2개)로 돌려도 F = t² 관계가 성립하기 때문에, d와 η²는 서로 변환 가능하다.

```
η² = d² / (d² + 4)     (n1=n2일 때 근사)
```

## 6. 카이제곱 계열 효과크기 — Cramér's V, φ (phi) [추가]

### 5-1. φ (Phi coefficient) — 2×2 표에서만 사용

```
φ = sqrt(χ² / N)
```

### 5-2. Cramér's V — 행/열이 2보다 큰 표에도 일반적으로 사용

```
V = sqrt( χ² / (N × min(r−1, c−1)) )
```

- r = 행(row) 개수, c = 열(column) 개수, N = 전체 표본 수.
- 자유도가 큰 표(칸이 많은 교차표)일수록 같은 V값이라도 관련성 해석 기준이 달라질 수 있어, 자유도 구간별 기준표를 참고하는 경우도 있음.

### 5-3. 해석 기준 (df=min(r−1,c−1)=1 기준, Cohen)

| V        | 해석      |
| -------- | --------- |
| 0.1      | 작은 효과 |
| 0.3      | 중간 효과 |
| 0.5 이상 | 큰 효과   |

## 7. 비모수검정 계열 효과크기 — rank-biserial correlation r [추가]

Mann-Whitney U test, Wilcoxon signed-rank test처럼 순위 기반 비모수검정에는 Z(표준화된 검정통계량)를 이용한 효과크기가 쓰인다.

```
r = Z / sqrt(N)
```

- N = 전체 관측치 수 (Wilcoxon은 짝의 수, Mann-Whitney는 두 그룹 합산 수)
- 해석 기준은 상관계수 r과 동일하게 0.1(작음) / 0.3(중간) / 0.5(큼)를 관행적으로 사용.

## 8. 회귀분석 계열 효과크기 — R², f² [추가]

### 7-1. 결정계수 R²

```
R² = SS_Regression / SS_Total = 1 − (SS_Residual / SS_Total)
```

- 독립변수들이 종속변수의 분산을 얼마나 설명하는지. ANOVA의 η²와 개념적으로 동일한 위치(전체 변동 대비 설명된 변동의 비율).

### 7-2. 수정된 결정계수 (Adjusted R²)

```
Adjusted R² = 1 − (1 − R²) × (N − 1) / (N − p − 1)
```

- p = 독립변수 개수. 변수가 늘어나면 R²는 기계적으로 증가하는 경향이 있어, 변수 수를 벌점(penalty)으로 반영해 보정한 값. ω²가 η²를 보정하는 것과 같은 취지.

### 7-3. Cohen's f² — 회귀계수의 효과크기

```
f² = R² / (1 − R²)
```

또는 변수 추가 전/후 모델 비교 시:

```
f² = (R²_full − R²_reduced) / (1 − R²_full)
```

| f²       | 해석      |
| --------- | --------- |
| 0.02      | 작은 효과 |
| 0.15      | 중간 효과 |
| 0.35 이상 | 큰 효과   |

---

## 9. 효과크기 종합 비교표

| 검정 계열             | 대표 효과크기   | 공식(핵심형)                                   | 작음      | 중간      | 큼        |
| --------------------- | --------------- | ---------------------------------------------- | --------- | --------- | --------- |
| 일원/다원 ANOVA       | η²ₚ          | SS_Effect / (SS_Effect+SS_Error)               | 0.01      | 0.06      | 0.14      |
| ANOVA(편향보정)       | ω²            | (SS_Effect−df1·MS_Error)/(SS_Total+MS_Error) | 0.01      | 0.06      | 0.14      |
| 독립/대응 t-test      | Cohen's d       | (M1−M2)/SD_pooled                             | 0.2       | 0.5       | 0.8       |
| 카이제곱(2×2)        | φ              | sqrt(χ²/N)                                   | 0.1       | 0.3       | 0.5       |
| 카이제곱(r×c)        | Cramér's V     | sqrt(χ²/(N·min(r-1,c-1)))                   | 0.1       | 0.3       | 0.5       |
| Mann-Whitney/Wilcoxon | rank-biserial r | Z/sqrt(N)                                      | 0.1       | 0.3       | 0.5       |
| 회귀분석              | R² / f²       | SS_Reg/SS_Total, R²/(1−R²)                  | 0.02(f²) | 0.15(f²) | 0.35(f²) |

> 기준값(0.01/0.06/0.14 등)은 모두 Cohen(1988)이 제안한 관행적 경험 기준이지 절대 법칙은 아니다. 분야·연구맥락에 따라 "중간 효과"의 실질적 의미가 달라질 수 있으므로 숫자만 보고 자동 판정하지 말고 도메인 지식과 함께 해석해야 한다.

## 10. F값 → η²ₚ 계산 검증 예시 (재확인용)

```
F = 4.846, df1 = 2, df2 = 27

η²ₚ = (F × df1) / (F × df1 + df2)
    = (4.846 × 2) / (4.846 × 2 + 27)
    = 9.692 / 36.692
    ≈ 0.264   → Cohen 기준 0.14 이상이므로 "큰 효과"
```

**보고서 문장 예시**:

> 일원분산분석 결과, 품종에 따른 평균 무게의 차이는 통계적으로 유의하였다 (F(2, 27) = 4.846, p = .016). 부분 에타제곱(η²ₚ = .264)은 품종이 무게 변동의 약 26.4%를 설명하는 큰 효과를 나타냈다.
