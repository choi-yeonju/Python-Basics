## 0. 큰 그림: 전체 흐름부터 보기

NumPy는 크게 두 단계로 배웁니다. 이 문서도 그 순서를 그대로 따릅니다.

```
[PART A] 배열 다루는 법 (1~3편)          [PART B] 배열을 요약/해석하는 법 (4~5편)
① 배열 만들기                             ⑧ 위치(중심) 통계 - 평균/중앙값/사분위수
② 배열 들여다보기(shape/dtype/ndim)        ⑨ 산포(퍼짐) 통계 - range/IQR/분산/표준편차
③ 원소 꺼내기/거르기(인덱싱, 불리언)        ⑩ 도수분포 - histogram, 절대/상대/누적도수
④ 조건으로 가공하기(where, select)         ⑪ 2차원 배열 통계 - axis 개념
⑤ 원소별 연산(사칙연산)
⑥ 틀 만들기(zeros/ones/full/eye, random)
⑦ 형태 바꾸기(astype, reshape)
```

**왜 이 순서인가?**: 데이터를 "담고(A) → 요약해서 해석하는(B)" 것이 분석의 본질이기 때문입니다.
PART A 없이는 데이터를 다룰 수조차 없고, PART B 없이는 다뤄봤자 "숫자 뭉치"에 머무릅니다.
**낯선 데이터셋을 만나면 "지금 나는 A 단계인가, B 단계인가?"를 먼저 자문하는 습관**을 들이세요.

# PART A. 배열 다루는 법 (1~3편)

## 1. 배열 생성하기 (ndarray의 시작)

### 핵심 개념
- `ndarray`(N-dimensional array)는 파이썬 리스트의 "업그레이드 버전"
- 리스트처럼 인덱싱, 슬라이싱, 반복문(enumerate)이 그대로 됨
- 하지만 리스트와 결정적으로 다른 점: **원소가 모두 같은 데이터 타입(dtype)**이어야 함

```python
import numpy as np
arr = np.array([1, 3, 5, 7, 9])
print(type(arr))   # <class 'numpy.ndarray'>
```

### 타입 자동 통일(업캐스팅) 규칙 ⭐ 중요
서로 다른 타입을 섞어서 배열을 만들면, numpy가 **하나의 공통 타입으로 자동 변환**합니다.

| 섞인 타입 | 결과 | 이유 |
|---|---|---|
| `[100, 3.14, True]` | 전부 float | int·bool은 float로 표현 가능 |
| `[1.2, 3, True, '4']` | 전부 문자열(`<U32`) | 문자열이 섞이면 전부 문자열로 |

> 💡 **사고 포인트**: 새 데이터셋을 불러왔는데 숫자 컬럼의 dtype이 `object`나 `str`로 나온다면, "혹시 중간에 문자/결측치(NaN, '-' 등)가 하나라도 섞여서 전체가 업캐스팅된 게 아닌가?"를 의심하세요. 실무에서 매우 자주 만나는 버그 원인입니다.

### 리스트 ↔ ndarray 상호 변환
```python
mylist3   = [10, 20, 30]
myarr3    = np.array(mylist3)       # list → ndarray
mylist3_1 = list(myarr3)            # ndarray → list (원소는 np.int64 등으로 남음)
```

## 2. 배열 들여다보기 (구조 파악)

새로운 배열/데이터셋을 받으면 **가장 먼저** 아래 3가지를 확인하는 습관을 들이세요.

```python
print("차원 수:", myarray.ndim)     # 1차원? 2차원?

print("타입:", myarray.dtype)       # int64, float64, <U21 등
```

> 💡 **분석 순서 팁**: 실제 CSV/데이터프레임을 numpy 배열로 바꿔서 쓸 때도 제일 먼저 `.shape`와 `.dtype`부터 찍어보는 게 사고의 출발점입니다. 크기와 타입을 모르고 연산부터 하면 에러의 8할이 여기서 납니다.

## 3. 원소 꺼내기 / 걸러내기

### 3-1. 인덱싱 & 슬라이싱 (리스트와 동일)
```python
mydata = np.array([5, 10, 15, 20, 25])
mydata[0]      # 5      (첫 원소)
mydata[1:4]    # [10 15 20]  (구간 슬라이싱)
mydata[-4:-1]  # [10 15 20]  (뒤에서부터)
```

### 3-2. 불리언(Boolean) 인덱싱 ⭐ NumPy의 핵심 무기
> "원본과 같은 크기의 True/False 배열을 만들어서, True인 자리만 뽑아낸다"

```python
grade = np.array([82, 77, 91, 88])
bool_array = np.array([True, False, True, False])
grade[bool_array]        # array([82, 91])
```

실무에서는 bool_array를 직접 만들지 않고, **조건식 자체가 bool_array를 만들어주는** 방식을 훨씬 많이 씁니다:
```python
mypoint = np.array([82, 77, 91, 88])
mypoint[mypoint >= 80]                              # 단일 조건
mypoint[np.logical_and(mypoint>=80, mypoint<=90)]   # AND (양쪽 다 만족)
mypoint[np.logical_or(mypoint<80, mypoint>90)]      # OR (둘 중 하나)
```

> ⚠️ 파이썬 기본 `and`/`or`는 배열에 못 씁니다. 배열끼리 조건을 합칠 땐 반드시 `np.logical_and`, `np.logical_or` (또는 `&`, `|`)를 사용하세요.

### 3-3. 2차원 배열에서의 불리언 인덱싱
2차원이어도 조건에 맞는 원소를 뽑으면 결과는 **항상 1차원**으로 나옵니다 (몇 행 몇 열인지가 사라지고 "값의 목록"만 남기 때문).
```python
myarray[myarray >= 80]   # 2차원 배열이어도 결과는 1차원
```

## 4. 조건으로 값 가공하기 (where / select)

### 4-1. 이분법 조건 → `np.where`
```python
exam = np.array([60, 83, 75, 92, 86])
result = np.where(exam >= 80, '합격', '불합격')
```
읽는 법: "조건이 참이면 A, 거짓이면 B" → **if-else 한 줄 버전**

여러 단계를 표현하려면 `np.where`를 중첩할 수도 있습니다:
```python
grades = np.where(score>=90, 'A',
          np.where(score>=80, 'B',
          np.where(score>=70, 'C', 'F')))
```

### 4-2. 다중 조건 분기 → `np.select` (권장, 가독성 좋음)
```python
conditions = [(exam>=90), (exam>=80), (exam>=70)]  # 조건 리스트 (위에서부터 우선순위)
value = ['A', 'B', 'C']                             # 각 조건에 대응하는 값
result = np.select(conditions, value, default='F')  # 다 해당 안 되면 'F'
```

> 💡 **where vs select 선택 기준**: 조건이 2개(참/거짓)뿐이면 `where`, 3개 이상 등급/구간을 나눠야 하면 `select`가 코드가 훨씬 깔끔합니다. `where`를 3단 중첩하면 읽기 어려워지니 이 경우 `select`를 쓰세요.

## 5. 원소별 연산 (Element-wise 연산)

NumPy 배열끼리의 연산은 **같은 위치(인덱스)의 원소끼리** 계산됩니다 (리스트의 `+`처럼 이어붙이기가 아님!).

```python
arr1 = np.array([10,15,20,25,30])
arr2 = np.array([2,3,4,5,6])

arr1 + arr2   # == np.add(arr1, arr2)       위치별 덧셈
arr1 - arr2   # == np.subtract(arr1, arr2)  위치별 뺄셈
arr1 * arr2   # == np.multiply(arr1, arr2)  위치별 곱셈
arr1 / arr2   # == np.divide(arr1, arr2)    위치별 나눗셈
```

> ⚠️ 파이썬 리스트라면 `[1,2] + [3,4]` → `[1,2,3,4]` (이어붙이기)지만, ndarray는 `[4, 6]` (원소별 덧셈)입니다. 이 차이를 헷갈리면 안 됩니다.

## 6. 정형화된(틀이 정해진) 배열 만들기

데이터가 없을 때 "틀"부터 만들어야 하는 경우(초기화, 마스크, 단위행렬 등) 사용합니다.

```python
np.zeros([3,4])   # 3행4열, 전부 0    → 초기값 세팅용
np.ones([3,4])    # 3행4열, 전부 1    → 가중치 초기화 등

np.eye(4)         # 4행4열 단위행렬   → 대각선만 1, 나머지 0 (선형대수용)
```

## 7. 랜덤 배열 (실험/시뮬레이션/테스트 데이터 만들기)

| 함수 | 분포 | 용도 |
|---|---|---|
| `np.random.rand(n)` | 0~1 균등분포 | 단순 확률값, 비율 테스트 |
| `np.random.randint(low, high, size)` | 정수 균등분포 | 테스트용 정수 데이터(주사위, 점수 등) |
| `np.random.randn(n)` | 표준정규분포(평균0,표준편차1) | 표준화된 노이즈 생성 |
| `np.random.normal(mean, std, size)` | 임의 정규분포 | 평균/표준편차를 직접 지정한 현실적 데이터 시뮬레이션 |

### 랜덤 시드(seed) — 재현성의 핵심
```python
np.random.seed(1234)
np.random.normal(0, 1, (4,3))
```
- 시드를 고정하면 **몇 번을 실행해도 항상 같은 "랜덤" 값**이 나옵니다.
- 실습/보고서/디버깅에서 "재현 가능한 결과"가 필요할 때 반드시 시드를 고정하세요.

> 💡 **분석 순서 팁**: 랜덤 데이터로 실험할 땐 항상 **시드 고정 → 데이터 생성 → 분석**의 순서를 지키세요. 시드 없이 하면 어제 잘 됐던 결과가 오늘 재현이 안 되는 상황이 생깁니다.

## 8. 형태(타입/차원) 변환하기

### 8-1. 데이터 타입 변환 — `astype()` vs `asarray()`

| 방법 | 사용법 | 특징 |
|---|---|---|
| `astype()` | `arr.astype('float')` | 배열의 **메서드**. 이미 있는 배열의 타입을 바꿀 때 |
| `asarray()` | `np.asarray(arr, dtype='float')` | numpy의 **함수**. 원본 배열을 새 타입으로 다시 만들 때 (원본이 이미 같은 타입/배열이면 복사 없이 재사용) |

```python
arr1 = np.arange(10)                 # [0 1 2 ... 9], dtype: int64
arr2 = arr1.astype('float')          # [0. 1. 2. ...], dtype: float64
arr3 = arr1.astype('str')            # ['0' '1' ...],  dtype: <U21
```

> ⚠️ **float → int 변환은 반올림이 아니라 "버림(truncate)"**입니다.
> `np.array([72.5, 88.0, 91.5]).astype(int)` → `[72, 88, 91]` (72.5가 72로, 즉 소수점 이하가 그냥 잘려나감. 반올림 아님!)
> 이 부분은 실무에서 성적/금액 계산 시 자주 실수하는 지점이니 꼭 기억하세요.

### 8-2. 차원 변환 — `reshape()`
`reshape()`은 **원소의 총 개수(행×열)가 변환 전후 동일해야만** 동작합니다.

```python
origin = np.arange(20)      # 1차원, 원소 20개
x = origin.reshape(4, 5)    # 4행 5열 (4*5=20 → OK)
# origin.reshape(3, 7)      # 에러! 3*7=21 ≠ 20
```

차원 축소(2차원 → 1차원):
```python
y = origin.reshape(20)          # 정확한 개수를 직접 입력
z = origin.reshape(rows*cols)   # shape에서 원소 수를 계산해서 입력
```

### 8-3. reshape의 `-1` 활용법 ⭐ 실무에서 제일 많이 씀
`-1`은 "**이 자리 숫자는 너(numpy)가 알아서 계산해**"라는 뜻입니다. (나머지 차원을 지정하면 남은 하나는 자동 계산)

```python
origin.reshape(-1, 1)   # 행 개수 몰라도 됨 → "무조건 1열"짜리 2차원으로 (세로로 쭉 세우기)
origin.reshape(-1, 2)   # "무조건 2열"짜리 2차원으로
origin.reshape(1, -1)   # "무조건 1행"짜리 2차원으로 (가로로 쭉 눕히기)
origin.reshape(2, -1)   # "무조건 2행"짜리 2차원으로
origin.reshape(-1)      # 통째로 1차원으로 펴기 (flatten과 유사)
```

> 💡 **실무 활용**: 머신러닝에서 `X.reshape(-1, 1)`은 "1차원 배열을 sklearn이 요구하는 2차원(샘플수, 피처수=1) 형태로 바꿀 때" 정말 많이 등장하는 패턴입니다. 지금 이 개념을 확실히 잡아두면 나중에 큰 도움이 됩니다.

# PART B. 배열을 요약/해석하는 법 — 기술통계량 (4~5편)

## 9. 기술통계량이란?

**기술통계(Descriptive Statistics)** = 데이터를 요약해서 "한눈에 파악 가능한 숫자"로 표현하는 것.

데이터를 보면 두 가지 질문을 던져야 합니다.

| 질문 | 알고 싶은 것 | 관련 통계량 |
|---|---|---|
| ① 데이터는 **어디에** 몰려있나? | 위치/중심 | 최대·최소·합계·평균·중앙값·사분위수 |
| ② 데이터는 **얼마나 퍼져** 있나? | 분포/산포 | Range, IQR, 분산, 표준편차 |

→ 앞으로 어떤 데이터를 받든, **"① 중심이 어딘지 → ② 얼마나 퍼졌는지"** 순서로 접근하면 됩니다.
(PART A에서 배열을 다룰 수 있게 됐다면, PART B는 그 배열을 "해석"하는 단계입니다.)

---

## 10. ① 위치(중심)를 나타내는 통계량

### 10-1. 기본 정보 먼저 확인 (감 잡기)

```python
len(data)      # 총 도수(개수) - 데이터가 몇 개인지
np.max(data)   # 최대값
np.min(data)   # 최소값
np.sum(data)   # 합계
```

> **사고 순서**: 데이터를 받으면 가장 먼저 "몇 개인지, 범위(최대~최소)가 어느 정도인지"부터 훑어봅니다. 감을 잡는 단계입니다.

### 10-2. 평균 (average / mean)

```python
np.average(data)
np.mean(data)
```
- 두 함수는 (가중치를 안 쓰면) 결과가 같음. `mean`이 더 일반적으로 쓰임.
- **단점**: 극단값(이상치)에 민감함 → 그래서 중앙값도 같이 봐야 함.

### 10-3. 중앙값 (median)

데이터를 정렬한 후 정 가운데 위치한 값.

```python
# 직접 구하는 원리 (개념 이해용)
sorted_arr = np.sort(data)
size = len(data)

if size % 2 == 0:              # 짝수개면 가운데 두 값의 평균
    p = (size // 2) - 1        # 인덱스는 0부터 시작하므로 -1
    q = p + 1
    median = (sorted_arr[p] + sorted_arr[q]) / 2
else:                          # 홀수개면 정가운데 값
    p = size // 2
    median = sorted_arr[p]

# 실전에서는 그냥 이걸로 끝
np.median(data)
```

> 💡 **평균 vs 중앙값 비교하는 습관을 들이자**
> - 두 값이 **비슷하다** → 데이터가 대체로 대칭적, 극단값 영향 적음
> - 두 값이 **크게 다르다** → 이상치나 한쪽으로 치우친(skewed) 분포일 가능성

### 10-4. 사분위수 (Quartile) - Q1, Q3

데이터를 4등분 했을 때의 경계값. Q1(25% 지점), Q2=중앙값(50%), Q3(75% 지점).

```python
# 직접 구하는 원리 (보간법, interpolation)
x = np.sort(data)
n = len(x)

q1_pos = (n - 1) * 0.25     # 위치(연속값, 정수가 아닐 수 있음)
i = int(np.floor(q1_pos))   # 아래쪽 정수 인덱스
f = q1_pos - i               # 보간 비율(소수점 부분)
Q1 = x[i] + f * (x[i+1] - x[i])

# 실전에서는 numpy 내장 함수 사용
np.quantile(data, 0.25)   # Q1
np.quantile(data, 0.75)   # Q3
```

> **왜 보간을 하는가?** 위치(`q1_pos`)가 정수로 딱 떨어지지 않을 때, 앞뒤 두 값을 비율대로 섞어서(보간) 더 정밀한 값을 추정하기 위함입니다. 원리만 이해하고 실전에서는 `np.quantile`을 쓰면 됩니다.

## 11. ② 산포(퍼짐 정도)를 나타내는 통계량

### 11-1. Range (범위)

```python
np.max(data) - np.min(data)
```
- 가장 단순하지만, 이상치 하나에 크게 흔들리는 단점이 있음.

### 11-2. IQR (사분위수 범위, Interquartile Range)

```python
q1 = np.quantile(data, 0.25)
q3 = np.quantile(data, 0.75)
IQR = q3 - q1
```
- 데이터의 **가운데 50%**가 퍼진 정도. 이상치의 영향을 덜 받아서 Range보다 안정적.

### 11-3. 분산(Variance) & 표준편차(Standard Deviation)

```python
np.var(data)   # 분산: 평균에서 각 값이 떨어진 정도의 제곱의 평균
np.std(data)   # 표준편차: 분산의 제곱근 (원래 데이터와 같은 단위로 해석 가능)
```

> **분산 vs 표준편차**: 분산은 제곱을 했기 때문에 단위 해석이 어려움 (예: 점수² ). 표준편차는 제곱근을 취해서 원래 단위로 돌아오므로 **실제 해석은 표준편차를 사용**.

### 11-4. 산포 통계량 요약 정리

| 통계량 | 의미 | 이상치에 강한가 |
|---|---|---|
| Range | 최대-최소 | 약함 |
| IQR | Q3-Q1 (중간 50%) | 강함 |
| 분산/표준편차 | 평균으로부터 퍼진 정도 | 중간 |

## 12. 도수분포 (Histogram) - 데이터를 구간으로 나눠보기

숫자 하나(평균 등)로 요약하는 것을 넘어서, **데이터가 구간별로 어떻게 분포하는지** 보는 방법입니다.

### 12-1. `np.histogram` 기본 사용법

```python
# 방법 1: 구간 개수를 지정 (numpy가 자동으로 균등하게 나눔)
hist, bins = np.histogram(data, 5)     # 5개 구간으로 균등 분할

# 방법 2: 구간 경계를 직접 지정
hist, bins = np.histogram(data, [0, 10, 20, 30, 40, 50])
```
- `hist`: 각 구간에 몇 개의 데이터가 들어있는지 (절대도수)
- `bins`: 구간의 경계값들 (구간 개수 + 1개가 반환됨)

> ⚠️ **구간 해석 주의**: numpy histogram은 기본적으로 **[이상, 미만)** 구간이며, **마지막 구간만 [이상, 이하]** 로 양끝을 포함합니다.

### 12-2. 도수분포표 출력 패턴 (마지막 구간만 다르게 처리)

```python
s = len(hist)
for i in range(0, s):
    if i + 1 < s:
        tpl = "%d이상 %d미만 : %d개"
    else:
        tpl = "%d이상 %d이하 : %d개"   # 마지막 구간은 '이하'
    print(tpl % (bins[i], bins[i+1], hist[i]))
```

> 💡 **이 패턴을 외워두면 좋습니다.** "마지막 구간만 다르게 처리한다"는 로직은 도수분포표를 출력할 때마다 반복적으로 등장합니다.

### 12-3. 도수의 3가지 종류

| 종류 | 의미 | 계산 방법 |
|---|---|---|
| **절대도수** | 구간별 실제 개수 | `hist` (histogram 결과 그대로) |
| **상대도수** | 전체에서 차지하는 비율 | `hist / np.sum(hist)` |
| **누적도수** | 앞 구간까지 누적된 개수 | 아래 반복문 참고 |

```python
# 상대도수
relative_freq = hist / np.sum(hist)

# 누적도수
cum_freq = []
previous = 0
for i in hist:
    previous += i
    cum_freq.append(previous)
```

> **왜 세 가지를 다 보는가?**
> - 절대도수: "몇 개인지" 확인
> - 상대도수: 규모가 다른 데이터끼리 **비교**할 때 유용 (%로 비교 가능)
> - 누적도수: "여기까지 몇 % 왔는지" → 중앙값/사분위수 위치를 감각적으로 파악할 때 유용

## 13. 2차원 배열의 기술통계량 - `axis` 개념

데이터가 표(행렬) 형태일 때는 **어느 방향으로 계산할지(axis)** 를 정해줘야 합니다.

```python
mydata = np.array([[98, 72, 80, 64, 88],
                    [65, 79, 59, 81, 74]])

np.sum(mydata, axis=0)   # 열끼리(세로) 연산 → 각 열의 합
np.sum(mydata, axis=1)   # 행끼리(가로) 연산 → 각 행의 합
```

> 💡 **axis 외우는 팁**
> - `axis=0` → **위아래(세로)**로 방향을 따라 계산 (결과: 열의 개수만큼 나옴)
> - `axis=1` → **좌우(가로)**로 방향을 따라 계산 (결과: 행의 개수만큼 나옴)
> - 헷갈리면 "axis=0은 행 인덱스가 없어지는 방향(즉 행끼리 합쳐짐=열별 결과)"라고 생각하기

## 14. 🔑 통합 체크리스트 — 새 데이터셋을 받으면 이 순서로 사고하기

PART A(다루기)와 PART B(해석하기)를 하나로 합친, **실제로 써먹는 순서**입니다.

```
[PART A: 배열로 담기]
1. np.array()로 변환 → 원소 타입이 섞여서 업캐스팅되지 않았는지 확인
2. shape / ndim / dtype 확인 (제일 먼저 하는 습관)
3. 필요하면 불리언 인덱싱으로 원하는 조건의 데이터만 추출
4. 등급/카테고리화가 필요하면 where(2분기) 또는 select(다분기)
5. 다른 배열과 연산할 때는 "위치별 계산"임을 기억
6. 빈 틀/테스트 데이터가 필요하면 zeros/ones/full 또는 random(+seed 고정)
7. 최종적으로 필요한 dtype/shape으로 astype/reshape 정리

[PART B: 통계로 해석하기]
8. [감 잡기] len, max, min, sum
9. [중심 파악] mean과 median 같이 확인 → 비슷한지 비교 (다르면 이상치/치우침 의심)
10. [분포 파악] Q1, Q3 → IQR 계산
11. [퍼짐 파악] range, 분산, 표준편차
12. [구간별 분포] 필요하면 histogram → 절대·상대·누적도수 표
13. [2차원이면] axis=0(세로/열별) vs axis=1(가로/행별) 구분해서 계산
14. [인사이트 도출]
    - 평균≈중앙값, IQR·표준편차 작음 → 안정적/고른 분포
    - 평균≠중앙값 크게 차이 → 이상치 또는 치우친(skewed) 분포 의심
    - 표준편차 큼 → 변동성 큰 데이터 (예측 어려움)
```

### 실전 코드 템플릿 (그대로 복붙해서 시작하기)

```python
import numpy as np

# --- PART A: 배열 준비 ---
data = np.array([...])        # ← 데이터만 바꿔 넣기
print("차원:", data.ndim, "| 형태:", data.shape, "| 타입:", data.dtype)

# --- PART B: 기술통계 ---
print("도수:", len(data))
print("최대값:", np.max(data))
print("최소값:", np.min(data))
print("평균:", np.mean(data))
print("중앙값:", np.median(data))
print("Q1:", np.quantile(data, 0.25))
print("Q3:", np.quantile(data, 0.75))
print("IQR:", np.quantile(data, 0.75) - np.quantile(data, 0.25))
print("분산:", np.var(data))
print("표준편차:", np.std(data))

# 구간별 도수분포가 필요할 때
hist, bins = np.histogram(data, 5)
relative_freq = hist / np.sum(hist)

cum_freq = []
previous = 0
for h in hist:
    previous += h
    cum_freq.append(previous)

s = len(hist)
print("--- 도수분포표 ---")
for i in range(s):
    label = f"{bins[i]} 이상 {bins[i+1]} " + ("미만" if i+1 < s else "이하")
    print(f"{label} | 절대도수: {hist[i]} | 상대도수: {relative_freq[i]:.3f} | 누적도수: {cum_freq[i]}")
```

## 15. 실습 문제로 개념 복습 (원본 기반)

### PART A 문제 — 형태 변환 종합
> 0~11 정수 배열 생성 → float 변환 → 2행6열로 reshape → 열 상관없이 3행으로 reshape(자동 열 계산) → 1차원으로 축소

```python
arr = np.arange(12).astype('float')   # 1. 정수 생성 + float 변환
arr = arr.reshape(2, 6)               # 2. 2행 6열
arr = arr.reshape(3, -1)              # 3. 3행, 열은 자동 계산
arr = arr.reshape(-1)                 # 4. 1차원으로 축소
print(arr)
```
*(참고: `np.ndarray([...])`는 잘못된 코드입니다 — `ndarray()`는 생성자가 아니라 빈 배열의 크기를 지정하는 저수준 클래스라서 리스트를 그대로 넣으면 의도한 값이 나오지 않습니다. 배열 생성은 항상 `np.array()`를 쓰세요.)*

### PART A 문제 — 성적 처리 시스템
> float 점수 배열 → int 변환(버림) → 80점 이상 추출 → A/B/C/F 학점 부여
핵심: `astype(int)`는 반올림이 아니라 버림, `select`로 다중 등급 분기.

### PART A 문제 — AI 교육생 점수 점검
> 정규분포(평균75, 표준편차5) 3행4열 생성(시드=100 고정) → 80점 이상 추출 → ndim/shape/dtype 출력
핵심: 시드 고정으로 재현성 확보, 생성 직후 구조 파악(ndim/shape/dtype) 습관화.

### PART B 예제들

| 예제 | 배운 포인트 |
|---|---|
| 시험 점수(`myarr`, `point`) | 평균/중앙값/사분위수/분산/표준편차 기본 계산 |
| 게임 점수 (Alpha, Bravo 팀) | 두 그룹을 같은 통계량으로 **비교**하는 법 |
