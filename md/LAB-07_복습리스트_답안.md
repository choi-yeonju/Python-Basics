## Pass 1. 개념 이해 체크 — 답

**모집단 vs 표본**
모집단은 알고 싶은 대상 전체 (예: 대한민국 성인 전체의 키), 표본은 그중 실제로 수집한 일부 데이터 (예: 실습에 쓰인 `origin['키']` 데이터). 모집단 전체를 다 조사하는 건 현실적으로 불가능하니까, 표본으로 모집단을 "추정"하는 것이 추론통계의 목적.

**신뢰구간이 필요한 이유**
표본평균은 표본을 다시 뽑을 때마다 매번 조금씩 달라짐(표본 변동성). 하나의 숫자(점 추정치)만 믿으면 "이 표본이 우연히 평균보다 크게/작게 나온 표본이면 어떡하지?"라는 문제가 생김. 그래서 "이 범위 안에 모평균이 있을 것"이라는 폭(구간)으로 추정해서 불확실성을 함께 표현하는 것.

**표준편차 vs 표준오차**
- 표준편차(std): 개별 데이터들이 평균에서 얼마나 흩어져 있는가 (데이터 자체의 퍼짐)
- 표준오차(SE): 표본평균이라는 값 자체가 표본을 다시 뽑을 때마다 얼마나 흔들리는가
- 계산식: `SE = 표준편차 / sqrt(n)` → n이 커질수록 SE는 작아짐 (표본이 많을수록 평균 추정이 안정적)

**자유도(dof)가 `n-1`인 이유**
표본표준편차를 계산할 때 이미 표본평균을 사용했기 때문에, n개의 데이터 중 하나는 나머지 값들에 의해 자동으로 결정됨(자유롭게 값이 정해지지 않음). 그래서 "자유롭게 값이 정해질 수 있는" 데이터 개수는 `n-1`.

**신뢰수준 95%의 정확한 의미**
"이 표본에서 구한 신뢰구간이 모평균을 포함할 확률이 95%다"가 아니라(모평균은 고정된 값이라 확률 개념이 아님), **"같은 방식으로 표본을 반복해서 뽑아 신뢰구간을 100번 만들면, 그중 약 95번은 진짜 모평균을 포함하게 되는 방법론"**이라는 뜻. 즉 "구간을 만드는 절차"에 대한 신뢰도이지, 특정 구간 하나에 대한 확률이 아님.

**정규분포 대신 t분포를 쓰는 이유**
모집단의 실제 표준편차(σ)를 모르기 때문에 표본표준편차로 "추정"해서 대신 씀. 이 추정 과정에서 생기는 불확실성을 반영하기 위해 정규분포보다 꼬리가 두꺼운(극단값 가능성을 더 크게 보는) t분포를 사용. 표본 크기가 커질수록 표본표준편차가 실제 σ에 가까워지므로 t분포도 정규분포에 가까워짐.

**표본 크기 n과 신뢰구간 폭의 관계**
n이 커지면 → 표준오차(`std/sqrt(n)`)가 작아짐 → 신뢰구간이 좁아짐 (추정이 더 정밀해짐). 반대로 n이 작으면 구간이 넓어짐 (불확실성이 큼).

## Pass 2. 코드 복원 — 답

**9단계 직접 계산**
```python
from math import sqrt
from scipy.stats import t

data = origin['키']          # 1) 대상 데이터
clevel = 0.95                # 2) 신뢰수준
n = len(data)                # 3) 표본 크기
dof = n - 1                  # 4) 자유도
sample_mean = data.mean()    # 5) 표본평균
sample_std = data.std()      # 6) 표본표준편차
sample_std_error = sample_std / sqrt(n)  # 7) 표준오차
cmin, cmax = t.interval(clevel, dof, loc=sample_mean, scale=sample_std_error)  # 8) 신뢰구간
```

**`t.interval()` 인자 순서**
`t.interval(신뢰수준, 자유도, loc=표본평균, scale=표준오차)`
- `clevel` → 몇 % 신뢰수준인지
- `dof` → 자유도 (t분포 모양 결정)
- `loc` → 구간의 중심 (표본평균)
- `scale` → 구간이 퍼지는 정도 (표준오차, **표준편차 아님**)

**`my_stats.ci()` 시그니처**
```python
def ci(data, column=None, clevel=0.95):
```
- `data`: Series/list/ndarray/DataFrame
- `column`: DataFrame일 때 대상 컬럼명 (기본값 None)
- `clevel`: 신뢰수준 (기본값 0.95)

**호출 두 가지 방식**
```python
my_stats.ci(data, clevel=0.95)                       # 방식 A: 이미 뽑은 Series 전달
my_stats.ci(origin, column='키', clevel=0.95)        # 방식 B: DataFrame + 컬럼명
```

**`kdeplot`에서 신뢰구간 자동 표시 파라미터**
`clevel` 파라미터. 0이 아닌 값을 주면 내부에서 `my_stats.ci()`를 호출해서 세로 점선을 그려줌. (`clevel=0`이면 신뢰구간 표시 안 함)

**`hue` 유무에 따른 내부 동작 차이**
- `hue=None`: 전체 데이터로 `my_stats.ci(data, column=x, clevel=clevel)` 한 번만 호출
- `hue='그룹컬럼'`: `data[hue].unique()`로 범주 목록을 뽑고, **범주마다 반복문을 돌면서** 각 그룹의 서브데이터로 `my_stats.ci()`를 각각 호출 → 그룹별로 신뢰구간 선이 다른 색으로 여러 개 그려짐

## Pass 3. 실수 포인트 자가진단 — 답

**`t.interval(scale=...)`에 뭘 넣어야 하나**
표준오차(`sample_std_error`)를 넣어야 함. 표준편차(`sample_std`)를 그대로 넣으면 구간이 실제보다 훨씬 넓게(잘못) 계산됨 — 표준편차는 "개별 데이터의 퍼짐"이지 "평균 추정치의 불확실성"이 아니기 때문.

**`melt` 후 `variable`/`value` 구분**
```python
df = pd.melt(origin, id_vars='월', var_name='구분', value_name='금액')
```
- `구분`(variable 역할): 원래 컬럼 이름이 값으로 들어감 → 예: '광고비(백만원)', '매출액(억원)' → **범주형(카테고리)** → `hue`로 사용
- `금액`(value 역할): 실제 숫자 데이터 → **연속형** → `x`로 사용

**`kdeplot`의 x에 범주형을 넣으면 안 되는 이유**
KDE(커널 밀도)는 연속형 숫자 데이터의 분포를 부드러운 곡선으로 그리는 방법이라, x축이 숫자여야 함. 범주형 컬럼(문자열/카테고리)을 넣으면 밀도 추정 자체가 성립하지 않거나 의미 없는 결과가 나옴. 범주 구분은 `hue`로 넘겨야 함.

**`ax=None` vs `ax=ax`**
- `ax=None` (기본값): 함수 내부에서 `my_plot.init()`으로 **새 Figure/Axes를 생성**해서 그 위에 그림. 함수가 끝나면 자동으로 `show()`까지 호출됨 (독립적인 그래프 하나 완성)
- `ax=ax`: 이미 만들어둔 Axes 객체를 넘겨받아서 **그 위에 이어서** 그림. 함수가 새 캔버스를 만들지 않으므로, 이후 `ax.axvline(...)` 같은 코드로 같은 그래프에 요소를 계속 추가할 수 있음 (여러 그래프 요소를 겹쳐 그릴 때 필수)

**docstring vs 실제 동작 확인 습관**
`kdeplot`의 docstring에는 "meanline은 hue가 설정된 경우 지원하지 않는다"고 적혀 있지만, 실제 코드를 보면 `hue`가 있을 때도 범주별 평균선을 그리는 분기(`else` 블록)가 존재함. 즉 **문서가 코드 수정 이후 갱신 안 됐을 가능성**이 있으므로, 애매하면 소스 코드를 직접 열어보거나 실행 결과로 확인하는 습관이 필요.
