# LAB-10 다중로지스틱회귀 — 케이스별 로직 정리

> 원칙: 모든 전처리를 무조건 다 하는 게 아니라, **이 데이터에 그 문제가 실제로 있는지 확인 후 필요한 것만** 한다.

---

## 0단계 — 데이터 상태 점검 (`my_qtcheck`)
목적: 다음 단계에서 뭘 해야 할지 "진단"하는 단계. 이 단계 자체는 항상 함.

| 순서 | 함수 | 확인하는 것 |
|---|---|---|
| 1 | `set_type` | 자료형이 의도대로 잡혔는지 (범주형이 문자열/숫자로 잘못 인식돼 있는지) |
| 2 | `check_missing_values` | 결측치 있는지 |
| 3 | `check_duplicates` | 중복 행 있는지 → 있으면 제거 |
| 4 | `numerical_summary` | 연속형 변수 기초통계 (평균/분산/이상치 감 잡기) |
| 5 | `categorical_summary` | 범주형 변수 값 분포 (종속변수 범주가 몇 개인지 여기서 확인) |

**주의:** `compute_vif`는 이 단계 아님. VIF는 다중공선성 "점검"이지 기초 기술통계가 아니라서 3단계(모델링 직전 전처리)로 가야 함.

---

## 1단계 — 분석 대상 정리 (케이스 판단)

**케이스 A — 종속변수 범주가 3개 이상일 때만**
→ 로지스틱은 이항(0/1)만 허용하므로, 확정되지 않은/애매한 범주(이번엔 '보류') 행을 제거
```
df3 = df2[df2['합격여부'] != '보류'].reset_index(drop=True)
```
- 범주가 처음부터 2개면 이 케이스는 스킵

**케이스 B — 설명력 없는 식별자 컬럼이 있을 때만**
→ 접수코드, 이름처럼 모델에 넣을 이유가 없는 컬럼 drop
```
df3 = df3.drop(columns=['접수코드', '이름'])
```
- 식별자 컬럼이 없으면 스킵

---

## 2단계 — 전처리 (`my_prep`) — "필요한 것만 선택적으로"

이 표가 너가 적어둔 "전처리 항목" 4개인데, **매번 4개 다 하는 게 아니라 케이스별로 판단**해야 함.

| 전처리 | 필요한 케이스 | 이번 문제는? |
|---|---|---|
| 범주형 라벨링/더미변수 | 범주형 독립변수가 있을 때 (2개 범주면 라벨링, 3개 이상이면 더미) | ✅ 성별, 합격여부 → `my_prep.labeling` |
| 이상치 대체 | 연속형 변수에 극단값이 확인됐을 때 | 이번 문제엔 해당 언급 없음 → 스킵 |
| 로그변환 | 분포가 심하게 치우쳤을 때(왜도) | 스킵 |
| 0값 → 결측치 변환 | **측정상 0이 "값이 없다"를 의미하는 변수가 있을 때만** (예: 혈당 0 = 측정 안 됨, pima_indians_diabetes 케이스) | ❌ nursing_grades엔 해당 없음 — 이건 다른 실습에서 섞여 들어온 메모임, 여기 적용 안 함 |
| 다중공선성 점검(VIF) | 독립변수가 2개 이상이고 상관 가능성 있을 때 → 사실상 다중회귀면 거의 항상 함 | ✅ `my_stats.compute_vif` → `my_prep.reduce_vif` |

**순서 안에서도 순서가 있음:** 라벨링을 먼저 해야 VIF 계산이 됨(문자열 상태로는 VIF 계산 불가) → `labeling` → `compute_vif`/`reduce_vif`

---

## 3단계 — 모형 적합 (`my_logit`)

여기 순서가 원래 헷갈리기 쉬운 지점:

1. `my_logit.auto_logit(df5, y='합격여부', backward=True)` — **적합 + 후진소거를 한 번에 실행**하는 함수. 이게 먼저.
2. 결과 보고는 `auto_logit` 안에서 이미 처리되거나, 별도로 `report_variables`/`report_fitness` 호출 — **적합이 끝난 뒤에** 결과표를 보는 거지, 결과 보고 함수가 먼저 오는 게 아님

→ 너가 적어둔 순서(`report_variables` 먼저, `auto_logit` 나중)는 반대로 되어 있었음.

---

## 4단계 — 예측
```
my_logit.predict(fit, new_data)
```
- **케이스 주의:** `new_data`에는 최종 모형에 "남아 있는" 변수만 넣음. 후진소거로 탈락한 변수(성별, 필기점수)는 넣지 않음.

---

## 전체 순서 한눈에 (조건부 스킵 표시)

```
자료형 점검 → 결측치 확인 → 중복 제거 → 기초통계
  ↓
[케이스A] 종속변수 범주 정리 (보류 제거)
[케이스B] 식별자 컬럼 제거
  ↓
라벨링 (필수, 범주형 있으면)
[조건부] 더미/이상치대체/로그변환 (이번엔 해당 없어 스킵)
  ↓
VIF 확인 → 다중공선성 변수 제거
  ↓
auto_logit (적합 + 후진소거) → 결과표 해석
  ↓
predict (최종 모형에 남은 변수만)
```
