## 1. 공통 전제: 3대 가정 확인이 먼저다

모든 t-test / ANOVA(모수검정)는 아래 가정을 먼저 확인한 뒤에야 "어떤 검정을 쓸지"가 정해진다. 이 순서를 건너뛰고 바로 t-test/ANOVA를 돌리면 p-value 자체를 신뢰할 수 없다.

```
① 정규성 (Normality)
② 등분산성 (Homoscedasticity)   ← 그룹이 2개 이상일 때만 확인
③ 독립성 (Independence)          ← 검정통계량이 아니라 연구 설계 단계에서 확보
```

- **정규성**: Shapiro-Wilk, D'Agostino-Pearson(`normaltest`) — H0: "정규분포를 따른다". p≥0.05면 충족.
- **등분산성**: 정규성 충족 시 Bartlett, 하나라도 위배 시 Levene — H0: "분산이 같다". p≥0.05면 등분산.
  - Levene은 그룹 수 제한이 없어서(2개든 5개든) ANOVA 사전검정에서도 그대로 쓰인다.
- **독립성**: 별도 검정통계량 없이 무작위 표집·독립적 관측으로 설계 단계에서 확보. 회귀분석 맥락에서는 잔차의 독립성으로 재등장하며 Durbin-Watson 검정으로 확인한다.

## 2. 연속형 종속변수 — 그룹 구조별 검정 선택

### 2-1. 그룹 1개 (일표본, One-sample)

**질문**: 하나의 집단 평균이 특정 기준값과 다른가?

```
정규성 검정
 ├─ 충족 → One-sample t-test (ttest_1samp)
 └─ 위배 → Wilcoxon signed-rank test (기준값을 뺀 뒤 부호·순위로 검정)
```

- 등분산성 검정은 그룹이 1개라 자동 스킵된다.
- 양측/좌측단측/우측단측 세 방향을 모두 계산해두고, 연구 질문 방향에 맞는 결과 하나만 결론에 쓴다.

### 2-2. 그룹 2개, 대응(Paired) — 같은 대상의 전/후 비교

**질문**: 같은 대상에서 측정한 두 시점(혹은 두 조건)의 값이 다른가?

```
diff = A − B 계산
 ↓
diff의 정규성 검정
 ├─ 충족 → Paired t-test (ttest_rel)
 └─ 위배 → Wilcoxon signed-rank test
```

- 대응표본은 "차이(diff) 하나"로 환원되기 때문에 **등분산성 검정 자체가 존재하지 않는다.** (독립표본과의 핵심 차이)
- diff를 만드는 방향(A−B vs B−A)과 `alternative`(greater/less) 방향은 항상 세트로 맞춰야 한다. 방향을 반대로 빼면 우측/좌측 판정이 뒤집힌다.
- 같은 대상을 반복 측정했는지(대응) vs 서로 다른 대상을 비교했는지(독립)가 검정법을 가르는 기준이지, 주제(예: "신약 효과")가 기준이 아니다.

### 2-3. 그룹 2개, 독립(Independent) — 서로 다른 대상 간 비교

**질문**: 서로 독립적인 두 집단의 평균이 다른가?

```
두 그룹 모두 정규성 검정
 ├─ 하나라도 정규성 위배 → Mann-Whitney U test (비모수)
 └─ 둘 다 정규성 충족
        ↓
     등분산성 검정 (Levene 권장)
        ├─ 등분산 O → Student's t-test (equal_var=True, pooled variance)
        └─ 등분산 X → Welch's t-test (equal_var=False, 분산을 각각 반영)
```

- 독립표본에서는 대응표본에 없던 **등분산성 검정이 하나 더 필요**하다 — 두 집단을 "나란히 놓고 비교"하는 구조이기 때문.
- 실무에서는 등분산 여부가 애매하면 처음부터 Welch를 쓰는 경우도 많다(등분산일 때도 결과가 Student와 거의 비슷하기 때문). 다만 학습 단계에서는 절차대로 등분산성부터 확인하는 것이 원칙.
- Mann-Whitney U는 "두 집단을 합쳐서 전체 순위를 매긴 뒤 순위 합을 비교"하는 방식. Wilcoxon(대응표본)이 "짝의 차이"에 순위를 매기는 것과 원리는 비슷하지만 대상이 다르다.

### 2-4. 그룹 3개 이상, 독립 — 분산분석 (ANOVA / F검정)

아래 4장에서 상세히 다룬다.

### 2-5. 그룹 3개 이상, 대응(반복측정) [추가]

- **Repeated Measures ANOVA**: 같은 대상을 3번 이상 반복 측정했을 때(예: 복용 전/1주 후/4주 후) 사용. 일반 ANOVA와 달리 개체 간 편차를 제거하고 개체 내 변화만 본다.
- **Friedman test**: 정규성이 깨졌을 때의 비모수 대안. Wilcoxon signed-rank test를 3개 이상 그룹으로 확장한 개념.
- 판단 흐름은 2-2(대응표본)와 동일하게, "정규성 충족 → 모수(Repeated ANOVA) / 위배 → 비모수(Friedman)"로 갈라진다.

## 3. 범주형 vs 범주형 — 카이제곱검정

**질문**: 두 범주형 변수 사이에 관련성(독립성)이 있는가?

- H0: 두 변수는 독립이다 (관련 없다) / H1: 독립이 아니다 (관련 있다)
- `chi2_contingency(pd.crosstab(...))`
- 유의성만 보지 말고 **효과크기(Cramér's V)**로 관련성의 강도까지 같이 봐야 한다 — 통계적으로 유의해도 V가 매우 작으면(예: 0.02 미만) 실질적 의미는 거의 없다고 해석하는 경우가 많다.

### 3-1. 카이제곱도 전제조건이 있다 — 기대빈도 [수정, 원본에 누락되어 있던 전제조건]

카이제곱검정은 "아무 교차표에나 써도 되는" 검정이 아니다. t-test/ANOVA에 정규성·등분산성 가정이 있듯, 카이제곱에도 전제조건이 있다.

- **기대빈도(expected frequency)가 5 미만인 셀이 전체 셀의 20%를 넘으면** 카이제곱 통계량의 근사가 부정확해진다. (기대빈도는 실제 관측값이 아니라 "두 변수가 독립이라면 이 칸에 나왔어야 할 이론적 빈도"를 뜻한다.)
- 이 조건이 깨지면(표본이 작거나 범주가 세분화되어 특정 칸의 빈도가 매우 낮을 때), 카이제곱 대신 **Fisher's exact test**를 대안으로 쓴다.
  - 2×2 표에서 가장 흔히 쓰이며, `scipy.stats.fisher_exact`로 계산한다.
  - 표본이 작을 때(설문 응답자가 적은 경우, 희귀 이벤트를 다루는 경우 등) 실무에서 자주 마주치는 상황이므로 "카이제곱이 안 되면 끝"이 아니라 이 대안이 있다는 것을 기억해두어야 한다.
- 판단 흐름:

```
교차표(crosstab) 작성
 ↓
기대빈도 확인 (chi2_contingency 결과의 expected 배열)
 ├─ 기대빈도 5 미만 셀이 20% 이하 → 카이제곱검정 (chi2_contingency)
 └─ 기대빈도 5 미만 셀이 20% 초과 (주로 2×2 표) → Fisher's exact test (fisher_exact)
```

## 4. 분산분석(ANOVA) / F검정 — 상세 정리

### 4-1. 왜 필요한가

t-test는 2개 집단 비교까지만 가능하다. 그룹이 3개 이상인데 t-test를 짝지어 여러 번 반복하면, 검정을 반복할수록 어딘가에서 우연히 유의하게 나올 확률(1종 오류, false positive)이 누적되어 커진다. ANOVA는 여러 그룹의 평균을 **한 번의 검정으로 동시에** 비교해서 이 문제를 피한다.

### 4-2. 핵심 아이디어: F값

ANOVA의 검정통계량은 F값이며, 다음 비율로 정의된다.

```
F = 집단 간 분산(between-group variance) / 집단 내 분산(within-group variance)
```

- 집단 간 분산이 집단 내 분산보다 훨씬 크다 → 그룹 간 차이가 우연이라 보기 어렵다 → F값이 커지고 p-value가 작아진다.
- F분포는 자유도가 두 개(분자 자유도 = 그룹수−1, 분모 자유도 = 전체표본수−그룹수)이며, 이 자유도 쌍에 따라 분포 모양이 달라진다. [추가]

### 4-3. 가설

- H0: 모든 그룹의 평균이 같다 (μ1 = μ2 = μ3 = ... )
- H1: 적어도 한 그룹은 평균이 다르다

**주의**: ANOVA가 유의하다고 나와도 "어느 그룹과 어느 그룹이 다른지"는 알려주지 않는다. 반드시 사후검정(post-hoc test)으로 이어가야 한다.

### 4-4. ANOVA도 3대 가정을 먼저 확인한다

```
각 그룹의 정규성 검정 (Shapiro-Wilk / normaltest)
 ├─ 하나라도 그룹에서 정규성 위배 → Kruskal-Wallis test (비모수 대안) [추가]
 └─ 모든 그룹 정규성 충족
        ↓
     등분산성 검정 (Bartlett 또는 Levene)
        ├─ 등분산 O → 일반 One-way ANOVA (f_oneway)
        └─ 등분산 X → Welch's ANOVA (등분산 가정 없이 F값 보정) [추가]
```

- **[수정]** 판단 기준은 "하나라도 위배되면 비모수로 간다"이다. "모든 그룹이 위배될 때만 비모수"로 잘못 쓰면, 3그룹 중 1~2그룹만 정규성이 깨진 경우(실무에서 흔함)를 놓치고 잘못된 모수검정을 진행하게 된다. 2-3장(독립표본 t-test)의 "하나라도 정규성 위배 → Mann-Whitney U" 기준과 동일한 논리이며, 그룹 수만 2개에서 3개 이상으로 늘어난 것뿐이다.
- t-test의 "정규성→등분산성" 판단 흐름이 그룹 수만 3개 이상으로 늘어난 것과 구조적으로 동일하다. 독립표본 t-test의 3방향 분기(Student/Welch/Mann-Whitney)와 정확히 대응되는 개념이 ANOVA에도 있다고 이해하면 쉽다. [추가]

### 4-5. 사후검정(Post-hoc test) [추가로 상세 보강]

ANOVA가 유의(H0 기각)로 나왔을 때만 진행한다.

| 사후검정     | 언제 쓰나                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------- |
| Tukey HSD    | 등분산 가정을 만족하고 표본 크기가 비슷할 때 가장 널리 쓰는 표준 방법                             |
| Bonferroni   | 비교 횟수가 적을 때 보수적으로 1종 오류를 통제하고 싶을 때 (비교 수가 많아지면 지나치게 엄격해짐) |
| Games-Howell | 등분산 가정이 깨졌을 때(Welch's ANOVA와 짝을 이룸) 쓰는 대안                                      |
| Scheffé     | 그룹 크기가 불균형하거나 복잡한 대비(contrast)를 비교할 때                                        |
| Dunn's test  | Kruskal-Wallis(비모수 ANOVA) 이후에 쓰는 비모수 사후검정                                          |

```python
from scipy import stats
stats.f_oneway(group1, group2, group3)

from statsmodels.stats.multicomp import pairwise_tukeyhsd
pairwise_tukeyhsd(endog=data['value'], groups=data['group'], alpha=0.05)
```

### 4-6. 효과크기 — eta squared (η²) [추가]

- 유의성(p-value)과 별개로 "그룹 차이가 전체 분산 중 얼마를 설명하는가"를 나타내는 지표.
- **[수정] 실무·실습에서 실제로 보는 값은 η²가 아니라 η²ₚ(partial eta squared, pingouin 결과표의 `np2` 컬럼)이다.** 두 지표는 정의가 다르다.
  - η² = SS_Between / SS_Total (전체 제곱합 대비)
  - η²ₚ (np2) = SS_Between / (SS_Between + SS_Within) (해당 효과 + 오차만 놓고 계산)
  - **일원분산분석(요인이 1개)에서는 SS_Total = SS_Between + SS_Within이 성립하므로 η² = η²ₚ로 같은 값이 나온다.** 지금까지 LAB07 실습(tree_weight, reading, commercial 등)이 전부 일원분산분석이었기 때문에 두 지표를 구분하지 않고 써도 실질적으로 문제가 없었던 것이다.
  - 다만 **이원분산분석(4-7 참고)처럼 요인이 2개 이상으로 늘어나면 η²와 η²ₚ 값이 서로 달라진다.** pingouin·SPSS 등 실무 도구가 기본으로 보고하는 지표는 η²ₚ(np2) 쪽이므로, "np2"라는 이름을 볼 때마다 이게 partial eta squared라는 것을 기억해두는 것이 안전하다.
- 해석 기준(np2 기준으로도 동일하게 적용): 대략 0.01=작음, 0.06=중간, 0.14=큰 효과로 해석하는 관행이 있다(절대 기준은 아님).
- t-test의 Cohen's d, 카이제곱의 Cramér's V와 같은 위치의 지표 — "유의함"과 "실질적으로 의미 있는 차이"는 다르다는 점을 늘 같이 봐야 한다.
- 더 상세한 수식(ω², ε², F값만으로 역산하는 공식 등)은 `LAB07_효과크기_수식정리.md` 참고.

### 4-7. 일원(One-way) vs 이원(Two-way) ANOVA

- **일원분산분석**: 독립변수(그룹을 나누는 기준)가 1개일 때. 예: "매장(A/B/C)에 따라 매출이 다른가?"
- **이원분산분석**: 독립변수가 2개일 때(예: 매장 × 요일). 각 변수의 주효과(main effect)뿐 아니라 두 변수의 **상호작용효과(interaction effect)**까지 볼 수 있다는 점이 일원분산분석과의 핵심 차이. Olist 프로젝트에서 다뤘던 OLS 회귀분석·VIF 체크와 개념적으로 이어지는 확장 지점.

## 5. 연속형 vs 연속형 — 상관분석 / 회귀분석 [추가, 원본 md에 없던 내용]

원본 5개 파일은 "그룹 비교" 계열(t-test/ANOVA/카이제곱) 위주라 다루지 않았지만, 종속변수와 독립변수가 모두 연속형인 경우도 실무에서 자주 마주치므로 위치를 정리해둔다.

| 상황                                                    | 방법                            |
| ------------------------------------------------------- | ------------------------------- |
| 두 연속형 변수의 선형 관계 강도 (정규성 충족)           | Pearson 상관계수                |
| 두 연속형 변수의 관계 강도 (정규성 위배 또는 순위 관계) | Spearman 순위상관계수           |
| 하나의 연속형 결과를 여러 변수로 설명·예측             | 회귀분석 (OLS 등)               |
| 회귀분석의 독립변수 간 다중공선성 확인                  | VIF (Variance Inflation Factor) |

- 상관분석은 "관계가 있는가"만 보고, 회귀분석은 "그 관계로 값을 얼마나 설명·예측할 수 있는가"까지 본다는 점이 핵심 차이.
- 회귀분석도 잔차의 정규성·등분산성(등분산성이 깨지면 이분산성, heteroscedasticity)·독립성을 가정하므로, 결국 이 문서 1장의 3대 가정과 같은 틀 위에 있다.

## 6. 전체 판단 플로우차트 (최종 요약)

```
종속변수가 연속형인가?
├─ No (범주형) → 독립변수도 범주형? → 카이제곱검정
│                → 독립변수가 연속형? → 로지스틱 회귀 등 (본 LAB 범위 밖)
└─ Yes → 독립변수(그룹)가 범주형인가?
          ├─ No (독립변수도 연속형) → 상관분석 / 회귀분석
          └─ Yes → 그룹이 몇 개, 어떤 구조인가?
                    ├─ 1개
                    │    └─ 정규성? ─ 충족→t-test / 위배→Wilcoxon
                    ├─ 2개, 대응
                    │    └─ 정규성? ─ 충족→Paired t-test / 위배→Wilcoxon signed-rank
                    ├─ 2개, 독립
                    │    └─ 정규성? ─ 위배(하나라도)→Mann-Whitney U
                    │                └─ 충족(모두)→등분산성? ─ O→Student's t / X→Welch's t
                    ├─ 3개 이상, 독립
                    │    └─ 정규성? ─ 위배(하나라도)→Kruskal-Wallis
                    │                └─ 충족(모두)→등분산성? ─ O→One-way ANOVA / X→Welch's ANOVA
                    ├─ 3개 이상, 대응
                    │    └─ 정규성? ─ 충족→Repeated Measures ANOVA / 위배→Friedman
                    └─ 독립변수 2개 이상 → Two-way ANOVA (상호작용효과 포함)
```

**[수정]** 이전 버전은 "정규성 → 등분산성"을 한 줄로 나란히 써서 마치 항상 순서대로 둘 다 확인하는 것처럼 보였다. 실제로는 **정규성이 먼저 오는 갈림길**이며, 정규성이 위배되면(2개 독립/3개 이상 독립 케이스에서 하나라도 위배되면) 등분산성 확인 자체를 건너뛰고 곧바로 비모수 검정(Mann-Whitney U / Kruskal-Wallis)으로 간다. 등분산성 검정은 "정규성이 모든 그룹에서 충족된 경우"에만 의미가 있는 그 다음 단계 질문이다.
