## ⚠️ 0-0. 새 데이터셋 적용 전 체크리스트

**이 문서는 "그릴 컬럼이 정해지고 데이터가 깨끗한 상태"부터 시작함.**
새 데이터셋 받으면 아래부터 확인하고 와야 함. 안 그러면 중간에 에러 나거나, 에러는 안 나는데 결과가 의미 없게 나옴.

| 체크 | 확인할 것 | 왜 필요한가 | 어디서 하나 |
|---|---|---|---|
| ① 결측치 | 쓸 컬럼에 NaN 있는가? | 대부분 차트는 NaN 있어도 조용히 넘어가지만, **ConvexHull은 NaN 있으면 에러남**. `pivot_table`도 NaN 처리(`fill_value=0`) 안 해두면 스택 계산이 틀어짐 | LAB05 워크플로우 (타입변환→중복제거→**결측치체크**→...) |
| ② x, y의 dtype | scatter라면 둘 다 연속형인가? | 연속형-연속형 관계를 보는 차트에 범주형 넣으면 그림이 이상해짐 (그땐 boxplot/violin이 맞음) | LAB04 dtype 변환 파트 |
| ③ hue의 dtype | 범주형인가? | `hue`로 나누는 모든 로직(`unique()` 기반)이 범주형 전제. 연속형을 hue로 그대로 쓰면 값 하나하나가 다 다른 군집 취급돼서 의미 없는 결과가 나옴 | LAB04 구간화(cut/qcut) |
| ④ hue/범주 개수 | 군집·카테고리가 몇 개인가? (6~8개 초과인가) | `sb.color_palette(palette)[i]`가 팔레트 기본 색상 수를 넘어가면 색이 겹침. 많으면 `n_colors=len(classes)` 명시 필요 | `origin[hue].nunique()`로 먼저 확인 |

→ 전체 그림: **LAB05 데이터 품질 체크 → 이 문서 (시각화)** 순서. 이 문서는 "그리기" 단계만 커버함.

## 0. 공통 구조

모든 그래프 함수는 동일한 패턴:

|---|---|---|

## 1. 어떤 상황에 어떤 차트를 쓰나 (선택 가이드)

| 목적 | 추천 차트 | 함수 |
|---|---|---|
| 시간 흐름/추세 보기 | 선 그래프 | `lineplot` |
| 값의 분포 모양 보기 (연속형) | 히스토그램, 커널밀도 | `histplot`, `kdeplot` |
| 그룹 간 분포 비교 (이상치, 사분위) | 박스플롯 | `boxplot` |
| 그룹 간 분포 비교 (전체 모양까지) | 바이올린플롯 | `violinPlot` |
| 그룹별 평균/합계 등 대표값 비교 | 막대그래프 | `barplot` |
| 그룹별 개수(빈도) 비교 | 카운트플롯 | `countplot` |
| 전체 대비 구성비 (한 시점) | 파이/도넛 | `pieplot` |
| 카테고리별 합계 + 세부 구성 동시에 | 누적 막대 | `stackplot` |
| 카테고리별 구성 "비율"만 비교 (합계 다를 때도) | 100% 누적 막대 | `stackplot(ratio=True)` |
| 두 범주 교차 값 비교 (표 형태) | 히트맵 | `heatmap` |
| **두 연속형 변수의 관계 보기** | **산점도** | **`scatterplot`** |
| **군집(hue)의 "영역"이 서로 겹치는지 분리되는지 보기** | **산점도 + 외곽선** | **`scatterplot(outline=True)`** |

### ⚠️ Stacked bar의 한계
- Stacked bar는 **첫 세그먼트만 0 기준선**이고 나머지는 떠 있어서, **"카테고리를 가로질러 특정 hue의 값 비교"**엔 부적합.
- 이런 질문("Color별로 어느 Cut에서 제일 비싼가")엔 **heatmap**이나 **grouped bar**, **lineplot**이 더 적합.
- → "합계 비교"는 stacked bar가 좋고, "개별 항목 간 비교"는 다른 차트가 좋다.

### ⚠️ Scatter vs 나머지 차트의 근본적 차이
- scatter는 유일하게 **집계 없이 원본 데이터 포인트를 그대로 찍는** 차트. 나머지(bar, box, violin, line)는 내부적으로 집계/요약이 들어감.
- Convex Hull은 독립적인 차트가 아니라 **scatter 위에 얹는 확장 레이어**임 (단독으로 안 씀).

## 2. 차트별 핵심 옵션

### 2-1. `lineplot` — 추세/시계열
```python
my_plot.lineplot(data=df, x="날짜", y="매출", hue="지역",
                  linewidth=2.0, linestyle="-", marker="o", markersize=6)
```
- `linestyle`: `"-"` 실선, `"--"` 점선, `":"` 점점선
- `marker`: `"o"`, `"s"`, `"^"` 등 (데이터 포인트 표시)

### 2-2. `kdeplot` — 커널 밀도 (분포 모양)
```python
my_plot.kdeplot(data=df, x="가격", hue="등급", fill=True, meanline=True)
```
- `fill=True`: 곡선 아래 면적 채움
- `meanline=True`: 평균선 자동 표시 (단, `hue` 있으면 범주별 평균선, 조합 제약 있음)

### 2-3. `histplot` — 히스토그램
```python
my_plot.histplot(data=df, x="가격", bins=20, hue="등급", kde=True)
```
- `bins`: 정수(구간 개수) 또는 리스트(직접 경계 지정)
- `kde=True`: 히스토그램 위에 밀도곡선 겹쳐 표시

### 2-4. `boxplot` / `violinPlot` — 그룹별 분포 비교
```python
my_plot.boxplot(data=df, x="등급", y="가격", hue="색상", orient='v')
my_plot.violinPlot(data=df, x="등급", y="가격", orient='v')
```
- `orient`: `'v'`(세로) / `'h'`(가로)
- boxplot: 중앙값, 사분위, 이상치를 정확한 값으로 보고 싶을 때
- violin: 분포의 전체 모양(다봉/단봉 등)까지 보고 싶을 때

### 2-5. `heatmap` — 교차표 값 비교
```python
my_plot.heatmap(data=pivot_df, annot=True, fmt="0.2f", linewidths=0.5, palette="Blues")
```
- `data`는 2차원 형태(보통 `pivot_table` 결과)여야 함
- `annot=True`: 셀 안에 숫자 표시
- `fmt`: 표시 형식 (`"0.2f"` = 소수 2자리 등)

### 2-6. `barplot` — 그룹별 대표값(평균 등)
```python
my_plot.barplot(data=df, x="등급", y="가격", hue="색상", estimator=np.mean)
```
- `estimator`: 막대 높이 계산 방식 (`np.mean`, `np.sum`, `np.median` 등)
- `order`: 막대 순서 직접 지정 (리스트)

### 2-7. `countplot` — 개수(빈도) 세기
```python
my_plot.countplot(data=df, x="등급", hue="색상")
```
- `barplot`과 달리 `y`에 집계할 값 컬럼 필요 없음 (그냥 행 개수를 셈)

### 2-8. `pieplot` — 구성비 (파이/도넛)
```python
my_plot.pieplot(x=df['비율'], labels=df.index, autopct="%0.1f%%",
                 donutchart=True, wedge_width=0.7)
```
- `donutchart=True`: 도넛 형태로 변경
- `explode`: 특정 조각만 떨어뜨려 강조 (리스트, 강조할 위치만 값 부여)
- `counterclock=False`: 시계방향으로 그리기 (기본값)

### 2-9. `stackplot` — 누적 막대 / 100% 누적 막대
```python
my_plot.stackplot(data=df, x="지역", y="종사자 수", hue="산업",
                   aggfunc=np.sum, orient='h', ratio=False,
                   text=True, text_format="{:.1f}", palette="tab20")
```
- `orient`: `'v'`(세로, `bottom=` 사용) / `'h'`(가로, `left=` 사용)
- `ratio=True`: 절대값 대신 **비율(%)로 자동 변환**, `text_format` 없으면 `"{:.1f}%"`로 강제 지정됨
- `aggfunc`: 누적 전 집계 방식 (합계면 `np.sum`, 평균이면 `np.mean`)
- `text_format`: 막대 안 숫자 표시 형식

### 2-10. `scatterplot` — 관계 + 군집 영역
```python
my_plot.scatterplot(data=df, x="Petal.Length", y="Petal.Width", hue="Species",
                     size=100, edgecolor="#000000", linewidth=1.5,
                     palette="Set2", outline=True)
```
- `hue` 있으면 `color` 무시됨 (hue가 색상 결정권을 가짐)
- `outline=True`: 군집별 Convex Hull 외곽선 + 영역 채우기 자동 추가 (단, `hue` 없으면 무시됨)
- 옵션 세부는 6장 참고

## 3. `bar` vs `barh` — 세로/가로 막대 파라미터 대응표

같은 "누적"이라도 방향에 따라 파라미터 이름이 다름. 헷갈려서 에러 자주 남.

| | 세로 막대 (`bar`, `orient='v'`) | 가로 막대 (`barh`, `orient='h'`) |
|---|---|---|
| 누적 시작점 | `bottom=` | `left=` |
| 범주 축 | x | y |
| 값 축 | y | x |
| `ax.text()` 좌표 | `x=범주, y=누적값` | `x=누적값, y=범주` |

```python
# 세로
ax.bar(df.index, df['A'], label='A')
ax.bar(df.index, df['B'], bottom=df['A'], label='B')   # bottom!

# 가로
ax.barh(df.index, df['A'], label='A')
ax.barh(df.index, df['B'], left=df['A'], label='B')    # left!
```

**주의**: `barh`에 `bottom=`을 넣으면 `TypeError: got multiple values for keyword argument 'bottom'` 발생 (barh 내부가 `bottom`을 이미 y로 자동 매핑하기 때문).

## 4. 누적값 계산 패턴 (반복문 안에서 자주 틀리는 부분)

n번째 세그먼트의 텍스트 y(또는 x) 위치 = **그 전까지 쌓인 값의 합 + 현재 값의 절반**

```python
for i in df.index:
    ax.text(x=i, y=df['A'][i]/2, s=..., ...)                              # 1번째: 0 + A/2
    ax.text(x=i, y=df['A'][i] + df['B'][i]/2, s=..., ...)                 # 2번째: A + B/2
    ax.text(x=i, y=df['A'][i] + df['B'][i] + df['C'][i]/2, s=..., ...)    # 3번째: A+B + C/2
```

`stackplot` 함수 내부처럼 컬럼 수가 유동적이면 `.iloc[:, :i].sum(axis=1)`로 일반화:
```python
df.iloc[j, :i].sum() + val/2   # i번째 컬럼까지의 누적합 + 현재값 절반
```

**흔한 실수**: 반복문 안에서 `df['컬럼']`처럼 `[i]` 인덱싱을 빼먹으면 스칼라가 아니라 시리즈 전체가 계산에 섞여 들어감 → 항상 "이번 반복에서 쓰는 값은 스칼라인가?" 체크.

**패턴 확장**: 이 "인덱스로 반복하면서 팔레트에서 색 뽑아쓰는" 구조는 `kdeplot`의 hue별 평균선(`for i, cat in enumerate(categories)`), `plot_hull`의 군집별 외곽선(`for i, v in enumerate(classes)`)에서도 **동일하게 반복됨**. `enumerate` + 팔레트 인덱싱은 hue 기반 시각화 전체를 관통하는 공식.

## 5. 모듈화 함수 만들 때 체크리스트 (지난 디버깅에서 나온 패턴들)

- [ ] 함수 시그니처 끝에 `:` 빠뜨리지 않기
- [ ] 색상 hex 코드 자릿수 확인 (`#ffffff` = 6자리)
- [ ] `if text:` 같은 "옵션 실행 블록"이 `if orient=='v': / else:` 분기 **안에** 잘못 갇혀있지 않은지 확인 → orient 상관없이 실행돼야 하는 코드는 분기 **밖**에

- [ ] `outline=True` 같이 다른 옵션(`hue`)의 존재를 전제로 하는 옵션은, 전제 조건이 없을 때 자동 무시되는 방어 로직이 있는지 확인 (`if outline and hue is not None:`)

## 7. Scatter Plot 상세

### 7-1. 기본 사용법 — 3가지 패턴 (반드시 패턴3만 쓸 것)

```python
# 패턴 1 - 자동인식 패턴 (data=origin만 넘김) → 비권장
sb.scatterplot(data=origin)

# 패턴 2 - 개별 데이터 직접 지정 패턴 → 재사용성 떨어짐
sb.scatterplot(x=origin['flipper_length_mm'], y=origin['body_mass_g'])

# 패턴 3 - DataFrame + 컬럼명 패턴 ✅ 가장 권장
sb.scatterplot(data=origin, x='flipper_length_mm', y='body_mass_g')
```

### 7-2. 기본 마커 스타일링 (hue 없을 때)

```python
sb.scatterplot(data=origin, x='flipper_length_mm', y='body_mass_g',
               markers="^", color="red", s=150,
               edgecolor="black", linewidth=2, alpha=0.7)
```

| 파라미터 | 의미 | 주의 |
|---|---|---|
| `markers` | 마커 모양 (`"o"`, `"^"`, `"s"` 등) | raw seaborn에선 `markers`(복수형) |
| `s` | 마커 크기 | 기본 100 |
| `color` | 마커 색상 | **hue가 있으면 무시됨** |
| `alpha` | 투명도 | 점 많이 겹칠 때(overplotting) 낮춰서 밀도 표현 |

### 7-3. 군집별 분류 (hue 있을 때)

```python
sb.scatterplot(data=origin, x='bill_length_mm', y='bill_depth_mm',
               hue="species", palette="tab10", markers="o", s=100,
               edgecolor="black", linewidth=2, alpha=0.7)
```

**핵심 원리**: `hue`와 `color`는 동시에 의미 있게 작동하지 않는다. (kdeplot의 meanline이 hue 있을 때 로직 갈라지는 것과 같은 맥락 — "옵션 간 상호배타" 패턴은 여러 함수에서 반복됨)

## 8. Convex Hull 상세

### 8-1. ConvexHull이란?
`scipy.spatial.ConvexHull`은 여러 점들 중 **가장 바깥쪽 점들(꼭짓점)만 뽑아서**, 그 점들을 잇는 다각형(볼록 껍질)을 계산해주는 알고리즘. "이 군집 데이터를 다 감싸는 가장 작은 다각형"을 구하는 것.

### 8-2. 필수 전제조건
```python
if len(df_c) < 3:
    print("데이터 포인트가 3개 미만이므로 ConvexHull을 그릴 수 없습니다.")
```
- 다각형을 만들려면 **최소 3개의 점** 필요
- 군집별 반복 적용 시 `if len(df_c) < 3: continue`로 스킵 처리 필수

### 8-3. 단일 군집에 적용하는 순서 (원리 이해용)

```python
# 1) 특정 군집만 필터링
df_c = origin.loc[origin['Species'] == 'setosa', ['Sepal.Length', 'Sepal.Width']]

# 2) ConvexHull 계산 → 외곽 점들의 "인덱스" 반환
hull = ConvexHull(df_c)
out_index = hull.vertices

# 3) 다각형을 "닫기" 위해 첫 인덱스를 마지막에 한 번 더 추가
points = np.append(out_index, out_index[0])

# 4) 선(외곽선) + 면(내부 채우기)으로 표시
ax.plot(df_c.iloc[points, 0], df_c.iloc[points, 1], linewidth=1, linestyle=":", color=color)
ax.fill(df_c.iloc[points, 0], df_c.iloc[points, 1], alpha=0.1, color=color)
```

**암기 포인트**:
- `hull.vertices`는 "인덱스"만 줌 → `.iloc[points]`로 좌표 뽑아서 직접 `plot`/`fill` 해야 함
- `np.append(vertices, vertices[0])` — **다각형을 닫는 필수 스텝**. 빠뜨리면 도형이 한쪽 뚫린 채로 그려짐
- `plot`(선) + `fill`(면) 둘 다 해야 "영역"처럼 보임

### 8-4. 모든 군집에 일괄 적용하는 함수화 패턴

```python
def plot_hull(data, x, y, hue, palette, ax):
    classes = list(data[hue].unique())
    for i, v in enumerate(classes):
        df_c = data.loc[data[hue] == v, [x, y]]
        if len(df_c) < 3:
            continue
        hull = ConvexHull(df_c)
        points = np.append(hull.vertices, hull.vertices[0])
        color = sb.color_palette(palette)[i]
        ax.plot(df_c.iloc[points, 0], df_c.iloc[points, 1], linewidth=1, linestyle=":", color=color)
        ax.fill(df_c.iloc[points, 0], df_c.iloc[points, 1], alpha=0.1, color=color)
```

### 8-5. 모듈화 함수 — `my_plot.scatterplot(outline=True)` 내부 로직

```python
if hue == None:
```

## 11. 통합 비교 — 지금까지 배운 차트 함수

| 함수 | data,x,y 패턴 | hue 지원 | color/palette 상호작용 | 특이사항 |
|---|---|---|---|---|
| `lineplot` | O | O | palette가 hue별 색상 결정 | 집계/추세 |
| `barplot` | O | O | palette가 hue별 색상 결정 | 집계값(estimator) |
| `boxplot`/`violinPlot` | O | O | palette가 hue별 색상 결정 | 분포 요약 |
| `stackplot` | O | O(필수) | 반복문에서 `color_list[i]` 수동 지정 | 누적/100% 누적, `orient`별 파라미터명 다름(`bottom`/`left`) |
| `scatterplot` | O | O | hue 있으면 color 무효화 | 개별 관측치 그대로, `outline`으로 군집 영역 표시 가능 |

## 12. 오늘까지 헷갈렸던/틀렸던 부분 체크리스트

- [ ] `barh`에 `bottom=` 넣으면 에러 (barh는 `left=` 사용)
- [ ] 누적 텍스트 위치 계산 시 `[i]` 인덱싱 빼먹지 않기 (스칼라 vs 시리즈)
- [ ] `ratio=True` 옵션 켰을 때 축 범위(`set_ylim`/`set_xlim`)도 같이 맞췄는지
- [ ] `markers`(raw seaborn, 복수형) vs `marker`(모듈화 함수, 단수형)
- [ ] `hue` 있는데 `color`도 같이 넘기면 → `color` 무시됨
- [ ] ConvexHull 계산 전 **데이터 포인트 3개 이상**인지 반드시 체크
- [ ] `hull.vertices`는 인덱스만 줌 → 좌표로 변환해서 직접 plot/fill
- [ ] 다각형 "닫기" 위해 `np.append(vertices, vertices[0])` 빠뜨리지 않기
- [ ] `outline=True`여도 `hue`가 없으면 자동으로 그려지지 않음
- [ ] 새 데이터셋이면 그리기 전에 **0-0 체크리스트**(결측치/dtype/hue 범주 개수)부터 확인했는지
