# [LAB 06] Scatter Plot & Convex Hull 학습 정리 (최종본)

> 오늘 배운 것 2가지
> 1. **Scatter Plot** — 두 연속형 변수 간의 "관계"를 점으로 찍어서 보는 그래프
> 2. **Convex Hull** — 산점도 위에서 같은 군집(hue)끼리 "가장 바깥 경계선"을 그려서 군집 영역을 시각화하는 기법
>
> 이 둘은 사실 하나로 이어짐: scatter로 군집을 색깔로 나눠 찍은 다음, Convex Hull로 "이 군집의 영역은 여기까지야"를 선으로 감싸주는 것.

## ⚠️ 0-0. 적용 전 체크리스트 — 새 데이터셋 받았을 때 이 가이드 쓰기 전에

**이 문서는 "그릴 컬럼이 정해지고 데이터가 깨끗한 상태"부터 시작함.**
새 데이터셋 받으면 아래 4개부터 확인하고 와야 함. 안 그러면 중간에 에러 나거나, 에러는 안 나는데 결과가 의미 없게 나옴.

| 체크 | 확인할 것 | 왜 필요한가 | 어디서 하나 |
|---|---|---|---|
| ① 결측치 | x, y로 쓸 컬럼에 NaN 있는가? | scatter는 NaN 있어도 조용히 그냥 점을 안 찍고 넘어가지만, **ConvexHull은 NaN 있으면 에러남** | LAB05 워크플로우 (타입변환→중복제거→**결측치체크**→...) |
| ② x, y의 dtype | 둘 다 연속형(숫자)인가? | scatter는 연속형-연속형 관계를 보는 차트. 범주형을 x나 y에 넣으면 그림이 이상해짐 (그때는 boxplot/violin이 맞음) | LAB04 dtype 변환 파트 |
| ③ hue의 dtype | 범주형인가? | `plot_hull`/`outline` 로직이 `data[hue].unique()`로 군집을 나누는 구조라, hue가 연속형(나이, 가격 등 그대로)이면 값 하나하나가 다 다른 군집 취급돼서 의미 없는 결과가 나옴. 연속형을 hue로 쓰고 싶으면 구간화(binning)부터 하고 와야 함 | LAB04 구간화(cut/qcut) |
| ④ hue 범주 개수 | 군집이 몇 개인가? (대략 6~8개 넘는가) | `sb.color_palette(palette)[i]`가 팔레트 기본 색상 수를 넘어가면 색이 겹치거나 꼬임. `n_colors=len(classes)`를 명시적으로 넘겨야 하는데 현재 `plot_hull` 내부엔 이 처리가 없음 → 범주 많으면 팔레트 호출부에 `n_colors` 직접 추가해서 써야 함 | `origin[hue].nunique()`로 먼저 확인 |

→ 이 4개가 통과된 다음에야 아래 섹션들(scatter 그리기, convex hull 적용)이 "컬럼명만 바꿔서 그대로 재사용" 가능해짐.
→ 즉 전체 그림은: **LAB05 데이터 품질 체크 워크플로우 (결측치/타입/이상치) → 이 문서 (시각화)** 순서로 이어지는 것. 이 문서 혼자서는 "그리기" 단계만 커버함.

## 0. 개념부터 — 언제 무엇을 쓰나

| 질문 | 예시 | 왜 이 차트인가 |
|---|---|---|
| 두 연속형 변수가 같이 움직이는가? | 날개 길이 ↑ → 몸무게 ↑? | scatter: 점들의 우상향/우하향 패턴 확인 |
| 관계의 강도/형태는? | 선형인가, 곡선인가, 관계 없음인가 | scatter: 점들이 직선에 가깝게 모였는지 흩어졌는지 |
| 군집(그룹)별로 관계가 다른가? | 종(species)별로 부리 길이-두께 관계가 다른가 | scatter + hue: 그룹별 색으로 나눠 겹쳐 찍기 |
| **군집의 "영역"이 서로 겹치는가, 분리되는가?** | setosa vs versicolor 종이 공간적으로 겹치는 구역이 있는가 | **Convex Hull**: 각 군집의 최외곽 점들을 이어서 "이 구역 안에 이 군집이 있다"는 걸 면으로 보여줌 |

**핵심 차이**: scatter는 점 하나하나(개별 관측치)를 보여주고, Convex Hull은 그 점들의 집합이 "차지하는 영역"을 보여줌. 즉 Convex Hull은 scatter 위에 얹는 **추가 레이어**지, 단독으로 쓰는 차트가 아님.

## 2. Scatter 옵션 정리

```python
sb.scatterplot(data=origin, x='flipper_length_mm', y='body_mass_g',

               color="red",         # 마커 색상 (hue 없을 때만 의미 있음)
               s=150,               # 마커 크기 (기본값 100)
               edgecolor="black",   # 마커 테두리 색상
               linewidth=2,         # 마커 테두리 두께

```

| 파라미터 | 의미 | 주의 |
|---|---|---|
| `markers` | 마커 모양 (`"o"`, `"^"`, `"s"` 등) | raw seaborn에선 `markers`(복수형) |
| `s` | 마커 크기 | 기본 100. 이름이 헷갈리는 파라미터니 암기 |
| `color` | 마커 색상 | **hue가 있으면 무시됨** (hue가 색상을 결정하니까) |
| `alpha` | 투명도 | 점이 많이 겹칠 때(overplotting) 낮춰서 밀도 표현 |

### 2-2. 군집별 분류 (hue 있을 때)

```python
sb.scatterplot(data=origin, x='bill_length_mm', y='bill_depth_mm',
               hue="species",       # 색상을 종(species)별로 다르게
               palette="tab10",     # 색상 팔레트
               markers="o",
               s=100,
               edgecolor="black",
               linewidth=2,
               alpha=0.7
               )
```

**핵심 원리 (모듈화 함수에도 그대로 반영됨)**:
> `hue`가 있으면 `color`는 무의미해짐 → `hue`가 색상을 결정하는 주체가 되기 때문.
> `hue`와 `color`는 **동시에 의미 있게 작동하지 않는다.** (kdeplot의 meanline이 hue 있을 때 로직 갈라지는 것과 같은 맥락 — "옵션 간 상호배타" 패턴은 여러 함수에서 반복됨)

## 3. Convex Hull — 개념 및 원리

### 3-1. ConvexHull이란?
`scipy.spatial.ConvexHull`은 여러 점들 중에서 **가장 바깥쪽에 있는 점들(꼭짓점)만 뽑아서**, 그 점들을 잇는 다각형(볼록 껍질)을 계산해주는 알고리즘.
→ 즉 "이 군집 데이터를 다 감싸는 가장 작은 다각형"을 구하는 것.

### 3-2. 필수 전제조건
```python
if len(df_c) < 3:
    print("데이터 포인트가 3개 미만이므로 ConvexHull을 그릴 수 없습니다.")
```
- 다각형을 만들려면 **최소 3개의 점**이 필요함 (2개면 선, 1개면 점이라 "영역"이 안 나옴)
- 군집별로 반복 적용할 때는 `if len(df_c) < 3: continue`로 스킵 처리 필수 (안 하면 에러남)

### 3-3. 단일 군집에 적용하는 순서 (원리 이해용)

```python
# 1) 특정 군집(setosa)만 필터링
df_c = origin.loc[origin['Species'] == 'setosa', ['Sepal.Length', 'Sepal.Width']]

# 2) ConvexHull 계산 → 외곽 점들의 "인덱스"를 반환
hull = ConvexHull(df_c)
out_index = hull.vertices     # 외곽 꼭짓점들의 인덱스 배열

# 3) 다각형을 "닫기" 위해 첫 인덱스를 마지막에 한 번 더 추가
#    (안 하면 마지막 점과 처음 점 사이가 안 이어져서 다각형이 열린 채로 그려짐)
points = np.append(out_index, out_index[0])

# 4) 선(외곽선) + 면(내부 채우기)으로 표시
ax.plot(df_c.iloc[points, 0], df_c.iloc[points, 1],
        linewidth=1, linestyle=":", color=color)
ax.fill(df_c.iloc[points, 0], df_c.iloc[points, 1],
        alpha=0.1, color=color)
```

**암기 포인트 (제일 헷갈리는 부분)**:
- `hull.vertices`는 "꼭짓점 인덱스"만 주지, 선으로 안 이어줌 → 직접 `.iloc[points]`로 좌표 뽑아서 `ax.plot`/`ax.fill`을 해줘야 함
- `np.append(out_index, out_index[0])` — **다각형을 닫는 필수 스텝**. 이거 빠뜨리면 도형이 한쪽이 뚫린 채로 그려짐
- `plot`은 테두리선, `fill`은 내부 색 채우기 — 둘 다 해야 "영역"처럼 보임 (하나만 하면 선만 있거나 색만 있음)

### 3-4. 모든 군집에 일괄 적용하는 함수화 패턴

```python
def plot_hull(data, x, y, hue, palette, ax):
    # 데이터의 군집 종류 얻기
    classes = list(data[hue].unique())

    # 각 클래스에 대하여 반복 수행
    for i, v in enumerate(classes):
        # 현재 클래스에 해당하는 데이터 포인트 추출
        df_c = data.loc[data[hue] == v, [x, y]]

        # 3개 미만이면 스킵
        if len(df_c) < 3:
            continue

        hull = ConvexHull(df_c)
        points = np.append(hull.vertices, hull.vertices[0])

        # 현재 클래스에 적용될 색상값 생성 (군집 순서 i번째 색 = scatter의 hue 색상과 맞춤)
        color = sb.color_palette(palette)[i]

        ax.plot(df_c.iloc[points, 0], df_c.iloc[points, 1],
                linewidth=1, linestyle=":", color=color)
        ax.fill(df_c.iloc[points, 0], df_c.iloc[points, 1],
                alpha=0.1, color=color)
```

**일반화 패턴 체크**: "군집별로 반복해서 뭔가 그리는" 로직은 `stackplot`의 `for i, col in enumerate(df.columns)`, `kdeplot`의 `for i, cat in enumerate(categories)`랑 **완전히 같은 구조**.
→ `enumerate`로 인덱스와 값을 같이 받아서, 그 인덱스로 팔레트에서 색상 뽑아 쓰는 패턴은 hue 기반 시각화 전체를 관통하는 공식임. 앞으로 새 함수 만들 때도 이 틀 그대로 재사용.

## 4. 모듈화 함수 — `my_plot.scatterplot()` (outline 옵션 추가된 최신 버전)

```python
def scatterplot(data, x, y, hue=None, marker='o', color=None, size=100,
                edgecolor='#ffffff', linewidth=1.5, alpha=1, palette=None,
                outline=True, title=None, xlabel=None, ylabel=None,
                width=1280, height=640, save_path=None):
```

### 내부 로직 — hue/color/palette 스위칭 + outline 연동

```python
# 군집을 구분할 분류값이 없다면 palette 옵션이 무의미하므로 None으로 설정
if hue == None:
    if color is None and palette is not None:
        color = sb.color_palette(palette)[0]
        palette = None
else:
    color = None

# ... scatterplot 그리기 ...

# 외곽선 그리기 — hue가 있을 때만 의미 있음 (군집이 있어야 외곽선을 나눠 그릴 수 있으니까)
if outline and hue is not None:
    plot_hull(data=data, x=x, y=y, hue=hue, palette=palette, ax=ax)
```

**암기 포인트**:
> `outline=True`가 기본값이지만, **`hue`가 없으면 자동으로 무시됨** (`hue is not None` 조건).
> → "군집이 없는데 외곽선을 어떻게 나눠 그리겠어" 라는 당연한 전제가 조건문으로 명시된 것.
> 이런 식으로 옵션 하나가 다른 옵션의 존재를 전제로 하는 경우, 함수 내부에서 방어 조건을 걸어두는 게 좋은 설계 패턴.

### 사용 예시

```python
# 1) 기본 (hue 있으면 outline 기본 True로 자동 그려짐)
my_plot.scatterplot(data=origin, x='Petal.Length', y='Petal.Width', hue='Species',
                    size=100, edgecolor="#000000", linewidth=1.5, palette='Set2')

# 2) outline 끄고 싶으면 명시적으로 False
my_plot.scatterplot(data=origin, x='Petal.Length', y='Petal.Width', hue='Species',
                    palette='Set2', outline=False)
```

## 5. 분석 진행 순서 (오늘 실습 전체 흐름)

```
1. 패키지 참조 (jussam, helpers, seaborn, numpy, scipy.spatial.ConvexHull)
2. 데이터셋 로드 (load_data)
3. raw seaborn으로 기본 산점도 먼저 그려서 군집 분포 눈으로 확인
4. 군집 하나만 떼어내서 ConvexHull 원리 손으로 확인
   - 3개 미만 예외처리 → hull.vertices → 다각형 닫기 → plot+fill
5. 위 로직을 모든 군집에 반복 적용하는 함수(plot_hull)로 일반화
6. 산점도 + plot_hull을 합쳐서 최종 시각화
7. 모듈화 함수(my_plot.scatterplot)에 outline 옵션으로 통합 확인
8. 연습문제로 다른 데이터셋에 그대로 적용 (컬럼명만 바꿔서 바로 동작해야 정상)
```

→ **"raw로 원리 확인 → 함수로 일반화 → 모듈에 통합 → 새 데이터로 재검증"** 이 4단계는 LAB06 전체(stacked bar, 100% stacked bar, scatter, convex hull)에서 계속 반복된 패턴. Olist 프로젝트 적용할 때도 이 순서 그대로 따라가면 됨.

## 6. 지금까지 배운 차트 함수 통합 비교

| 함수 | data,x,y 패턴 | hue 지원 | color/palette 상호작용 | 특이사항 |
|---|---|---|---|---|
| `lineplot` | O | O | palette가 hue별 색상 결정 | 집계/추세 |
| `barplot` | O | O | palette가 hue별 색상 결정 | 집계값(estimator) |
| `boxplot`/`violinPlot` | O | O | palette가 hue별 색상 결정 | 분포 요약 |
| `scatterplot` | O | O | hue 있으면 color 무효화 | 개별 관측치 그대로, `outline`으로 군집 영역 표시 가능 |

**scatter만의 특징**: 유일하게 "집계 없이 원본 데이터 포인트를 그대로 찍는" 차트. 나머지는 내부적으로 집계/요약이 들어감.
**Convex Hull은 별도 차트가 아니라 scatter의 "확장 레이어"**라는 점 다시 한번 암기.

## 7. 오늘 헷갈렸던/틀렸던 부분 체크리스트

- [ ] `markers`(raw seaborn, 복수형) vs `marker`(모듈화 함수, 단수형) — 파라미터명 함수마다 다를 수 있음
- [ ] `hue` 있는데 `color`도 같이 넘기면 → `color` 무시됨
- [ ] ConvexHull 계산 전 **데이터 포인트 3개 이상**인지 반드시 체크 (`len(df_c) < 3`)
- [ ] `hull.vertices`는 인덱스만 줌 → 좌표로 변환(`.iloc[points]`)해서 직접 plot/fill 해야 함
- [ ] 다각형 "닫기" 위해 `np.append(vertices, vertices[0])` 빠뜨리지 않기
- [ ] `plot`(선)과 `fill`(면) 둘 다 그려야 "영역"처럼 보임
- [ ] `outline=True`여도 `hue`가 없으면 자동으로 그려지지 않음 (전제 조건 확인)
- [ ] 새 데이터셋이면 그리기 전에 **0-0 체크리스트**(결측치/dtype/hue 범주 개수)부터 확인했는지

### 8-3. raw로 직접 짤 때 (모듈 함수 없이 원리부터 재현하고 싶을 때)
```python
from scipy.spatial import ConvexHull
import numpy as np

def plot_hull(data, x, y, hue, palette, ax):
    classes = list(data[hue].unique())
    for i, v in enumerate(classes):
        df_c = data.loc[data[hue] == v, [x, y]]
        if len(df_c) < 3:
            continue
        hull = ConvexHull(df_c)
        points = np.append(hull.vertices, hull.vertices[0])
        color = sb.color_palette(palette)[i]
        ax.plot(df_c.iloc[points, 0], df_c.iloc[points, 1], linewidth=1, linestyle=":", color=color)
        ax.fill(df_c.iloc[points, 0], df_c.iloc[points, 1], alpha=0.1, color=color)

fig, ax = my_plot.init()
sb.scatterplot(data=origin, x='X컬럼', y='Y컬럼', hue='그룹컬럼', s=100, palette='Set2')
plot_hull(origin, x='X컬럼', y='Y컬럼', hue='그룹컬럼', palette='Set2', ax=ax)
my_plot.show()
```
