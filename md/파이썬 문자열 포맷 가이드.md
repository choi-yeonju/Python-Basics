# 파이썬 문자열 포맷 가이드 (Format Spec Mini-Language)

`.format()` / f-string 안에서 `{:포맷}` 형태로 숫자·문자열을 원하는 모양으로 출력하는 문법 정리.
주로 `ax.text()`, `print()`, 그래프 라벨, 리포트 텍스트 만들 때 사용.

---

## 1. 기본 구조

```
{필드:타입지정자}
```

- `:` 앞 = 어떤 값을 넣을지 (필드 인덱스, 이름, 혹은 비워둠)
- `:` 뒤 = 어떻게 표시할지 (정렬, 자릿수, 콤마, 퍼센트 등)
- `{}` 밖에 있는 글자는 그대로 출력됨 → `{:d}명` → `3874명`

```python
"{:.1f}".format(3874.234)      # '3874.2'
f"{3874.234:.1f}"              # '3874.2'   (f-string도 동일하게 동작)
```

---

## 2. 자주 쓰는 포맷 표

| 포맷 | 의미 | 입력 | 결과 |
|---|---|---|---|
| `{:.1f}` | 소수점 1자리 (반올림) | `3874.234` | `3874.2` |
| `{:.2f}` | 소수점 2자리 | `3874.234` | `3874.23` |
| `{:.0f}` | 소수점 0자리 (여전히 float 취급) | `3874.234` | `3874` |
| `{:d}` | 정수 (소수점 없음, **float 넣으면 에러**) | `3874` | `3874` |
| `{:,}` | 천 단위 콤마 | `3874234` | `3,874,234` |
| `{:,.1f}` | 콤마 + 소수 1자리 | `3874234.5` | `3,874,234.5` |
| `{:.1%}` | 퍼센트 자동 변환 (×100 + %) | `0.4291` | `42.9%` |
| `{:+.1f}` | 부호 항상 표시 | `3874.2` | `+3874.2` |
| `{:>10}` | 오른쪽 정렬, 폭 10 | `123` | `       123` |
| `{:<10}` | 왼쪽 정렬, 폭 10 | `123` | `123       ` |
| `{:^10}` | 가운데 정렬, 폭 10 | `123` | `   123    ` |
| `{:05d}` | 0으로 채워 폭 5 맞춤 | `42` | `00042` |
| `{:.2e}` | 지수(과학적) 표기 | `1234567` | `1.23e+06` |

---

## 3. 텍스트/단위 붙이기

`{}` 밖의 문자는 그대로 출력되므로, 단위/기호를 자유롭게 붙일 수 있음.

```python
"{:d}명".format(3874)          # '3874명'
"{:.1f}%".format(42.9)         # '42.9%'
"${:,.0f}".format(3874234)     # '$3,874,234'
"{:,.0f}원".format(3874234)     # '3,874,234원'
```

---

## 4. 실전에서 자주 쓰는 조합 (그래프 라벨용)

```python
"{:.1f}$"       # 3874.2$    - 가격(소수)
"{:d}명"         # 3874명      - 인원수(정수)
"{:.1f}%"       # 42.9%      - 비율
"{:,}"          # 3,874,234  - 큰 숫자 가독성
"{:,.0f}원"      # 3,874,234원 - 통화 + 콤마
```

matplotlib `ax.text()`, `text_format.format(value)` 패턴으로 재사용:

```python
text_format = "{:.1f}%"
ax.text(x=i, y=..., s=text_format.format(df['비율'][i]), ...)
```

## 5. 주의사항

### 5-1. `{:d}`는 float을 못 받는다

```python
"{:d}".format(3874.0)   # ❌ ValueError!
"{:d}".format(3874)     # ✅ '3874'
```

pandas 컬럼이 float 타입이면 `int()`로 변환하거나 `{:.0f}`로 대체.

```python
"{:d}명".format(int(df['IT산업'][i]))   # 안전
"{:.0f}명".format(df['IT산업'][i])      # 이것도 안전 (float 허용)
```

### 5-2. `.format()` vs f-string

| 방식 | 특징 | 언제 쓰나 |
|---|---|---|
| `"{:.1f}".format(x)` | 포맷 문자열을 변수로 저장 후 **나중에 재사용** 가능 | 함수 파라미터로 포맷을 넘길 때 (`text_format="{:.1f}"` 같은 경우) |
| `f"{x:.1f}"` | 그 자리에서 즉시 평가, 더 간결 | 한 번 쓰고 말 때, 코드 가독성 우선일 때 |

동작 원리는 동일. `stackplot()` 함수처럼 `text_format`을 파라미터로 받아 여러 번 재사용하는 구조라면 `.format()` 방식이 필수적.

---

## 6. 빠른 참고: 상황별 추천 포맷

| 상황 | 추천 포맷 |
|---|---|
| 종사자 수, 인원 (정수) | `{:d}명` 또는 `{:,.0f}명` |
| 가격, 금액 | `{:,.0f}원` / `{:.1f}$` |
| 비율, 퍼센트 | `{:.1f}%` (값이 이미 0~100) 또는 `{:.1%}` (값이 0~1) |
| 큰 숫자 가독성 | `{:,}` |
| 소수 데이터 (통계값 등) | `{:.2f}` |
