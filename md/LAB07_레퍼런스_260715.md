## 1. 공통 전제: 3대 가정

모든 t-test/ANOVA(모수검정)는 이 순서로 가정을 먼저 깬다.

```
① 정규성 (Normality)        — Shapiro-Wilk / normaltest, H0: 정규분포다
② 등분산성 (Homoscedasticity) — 그룹 2개 이상일 때만. Bartlett(정규성 충족 시) / Levene(위배 시)
③ 독립성 (Independence)      — 연구설계 단계에서 확보. 회귀에선 Durbin-Watson으로 확인
```

- 판단 기준 공통: **p ≥ 0.05 → 가정 충족 / p < 0.05 → 위배**
- **정규성이 먼저 갈라지는 갈림길이다.** 정규성이 위배되면 등분산성 검정 자체를 스킵하고 바로 비모수검정으로 간다 (등분산성은 "모든 그룹이 정규성 충족했을 때"만 의미 있는 다음 질문).
- 그룹이 **하나라도** 정규성 위배 → 전체를 비모수로 전환 (그룹 일부만 위배돼도 동일하게 적용, "전부 위배될 때만 비모수"가 아님에 주의).

```python
from scipy.stats import normaltest, shapiro, bartlett, levene
```

## 2. 연속형 종속변수 — 그룹 구조별 기법

### 2-1. 일표본 (그룹 1개)

**질문**: 하나의 집단 평균이 특정 기준값(모평균)과 다른가?

```
정규성 검정
 ├─ 충족 → One-sample t-test
 └─ 위배 → Wilcoxon signed-rank test (기준값을 뺀 뒤 부호·순위로 검정)
```

- 등분산성은 그룹이 1개라 자동 스킵.
- `alternative` 세 방향(two-sided / less / greater) 다 계산해두고, 연구 질문 방향에 맞는 것만 결론에 씀.

```python
from scipy.stats import ttest_1samp, wilcoxon

# 직접 호출
s, p = ttest_1samp(data, popmean=70, alternative='two-sided')
s, p = wilcoxon(data - popmean, alternative='two-sided')  # 정규성 위배 시, popmean 빼는 거 필수

# helpers 모듈 (정규성 검정 → 검정법 자동선택 → 3방향 자동 실행)
from helpers import my_stats
my_stats.test_1sample(df, column='체온', popmean=24.3)
```

### 2-2. 대응표본 (그룹 2개, 같은 대상 전/후)

**질문**: 같은 대상에서 측정한 두 시점(조건)의 값이 다른가?

```
diff = A - B
diff의 정규성 검정
 ├─ 충족 → Paired t-test (ttest_rel)
 └─ 위배 → Wilcoxon signed-rank test
```

- diff 하나로 환원되므로 **등분산성 검정 자체가 없음** (독립표본과의 핵심 차이).
- diff 방향(A-B vs B-A)과 `alternative`(greater/less) 방향은 항상 세트로 맞출 것 — 반대로 빼면 좌/우측 판정이 뒤집힘.
- 판단 기준은 "같은 대상을 반복 측정했는가"이지 주제가 아님.

```python
from scipy.stats import ttest_rel

# 직접 호출
diff = df['뒷다리'] - df['앞다리']
my_stats.test_assumptions(data=df, columns='diff')  # 정규성만 확인 (그룹 1개 취급)
s, p = ttest_rel(df['뒷다리'], df['앞다리'], alternative='two-sided')

# helpers 모듈
my_stats.test_paired(data=df, before='앞다리', after='뒷다리')
# 컬럼명 대신 Series를 직접 넘겨도 됨: before=df_1['sales_amount'], after=df_2['sales_amount']
```

### 2-3. 독립표본 (그룹 2개, 서로 다른 대상)

**질문**: 서로 독립적인 두 집단의 평균이 다른가?

```
두 집단 각각 정규성 검정
 ├─ 하나라도 위배 → Mann-Whitney U test
 └─ 둘 다 충족
     → 등분산성 검정 (Levene 권장)
        ├─ 등분산 O → Student's t-test (equal_var=True)
        └─ 등분산 X → Welch's t-test (equal_var=False)
```

- 독립표본에만 있는 단계: **등분산성 검정** — 두 집단을 나란히 놓고 비교하기 때문.
- 두 컬럼을 wide로 만들 때 실제 짝이 없어도 `groupby('group').cumcount()`로 임시 순번을 매겨 pivot해도 통계적으로 문제없음 (독립표본은 행 대응이 필요 없는 검정이라서).

```python
from scipy.stats import ttest_ind, mannwhitneyu

# 직접 호출
my_stats.test_assumptions(df, columns=['B', 'G'])
s, p = ttest_ind(df['B'], df['G'], equal_var=True, alternative='two-sided')
s, p = mannwhitneyu(df['B'], df['G'], alternative='two-sided')  # 정규성 위배 시

# helpers 모듈 (가정확인 → 3가지 검정 자동선택 → 3방향 → 시각화까지)
my_stats.test_independent(df, "B", "G")
```

⚠️ 실수 포인트: `ttest_ind(a, a, ...)`처럼 같은 컬럼 두 번 넣는 복붙 실수 조심 — 결과가 statistic≈0, p≈1로 "너무 뻔하게" 나오면 이것부터 의심. 시각화 Annotator의 `test=` 문자열도 실제 수행한 검정과 반드시 일치시킬 것.

### 2-4. 일원분산분석 (그룹 3개 이상, 독립)

**왜 필요한가**: t-test를 3번 이상 반복하면 1종 오류가 누적됨 → ANOVA로 한 번에 검정.

```
각 그룹 정규성 검정
 ├─ 하나라도 위배 → Kruskal-Wallis test (비모수)
 └─ 모두 충족
     → 등분산성 검정
        ├─ 등분산 O → One-way ANOVA
        └─ 등분산 X → Welch's ANOVA
```

- ANOVA가 유의해도 "어느 그룹끼리 다른지"는 안 알려줌 → **사후검정(post-hoc) 필수**.

```python
from scipy.stats import f_oneway
from statsmodels.formula.api import ols
from statsmodels.stats.anova import anova_lm
from pingouin import anova, welch_anova, pairwise_tukey, pairwise_gameshowell

# 직접 호출 - 4가지 방식
s, p = f_oneway(df_wide['A'], df_wide['B'], df_wide['C'])          # scipy
lm = ols('weight ~ C(group)', data=origin).fit(); anova_lm(lm)      # statsmodels
anova(data=origin, dv='weight', between='group')                    # pingouin (등분산)
welch_anova(data=origin, dv='weight', between='group')              # pingouin (이분산)

# helpers 모듈
my_stats.anova_oneway(origin, y='weight', between='group')

# 사후검정 (ANOVA 유의할 때만)
tukey_df = pairwise_tukey(data=origin, dv='weight', between='group')       # 등분산
gh_df = pairwise_gameshowell(origin, dv='weight', between='group')          # 이분산

my_stats.posthoc_oneway(origin, y='weight', between='group')  # helpers 모듈 버전
```

**사후검정 종류 정리**

| 사후검정 | 언제 쓰나 |
|---|---|
| Tukey HSD | 등분산 만족, 표본 크기 비슷할 때 (표준) |
| Games-Howell | 등분산 위배 (Welch's ANOVA 짝) |
| Bonferroni | 비교 횟수 적을 때, 보수적으로 |
| Scheffé | 그룹 크기 불균형/복잡한 대비 비교 |
| Dunn's test | Kruskal-Wallis 이후 비모수 사후검정 |

**공통 패턴** (실습에서 항상 이 순서):
```python
origin = load_data("데이터명")
my_stats.anova_oneway(origin, y='종속변수', between='그룹변수')      # 1) 전체 차이 여부
my_stats.posthoc_oneway(origin, y='종속변수', between='그룹변수')    # 2) 어느 쌍이 다른지
```

### 2-5. 이원분산분석 (독립변수 2개 이상)

- 일원분산분석과 다른 점: 주효과 2개 + **상호작용효과(interaction)**까지 동시에 봄.
- 상호작용 있음 = "A의 효과가 B 수준에 따라 달라진다" (그래프에서 선이 교차).
- 가설 3쌍(요인A 주효과, 요인B 주효과, 상호작용)을 한 번의 분석에서 얻음.

```
정규성 검정 (조합별)
 ↓
등분산성 검정
 ├─ 충족 → 일반 이원분산분석 (pingouin.anova)
 └─ 위배 → OLS(HC3) 기반 Type-II ANOVA
```

```python
import statsmodels.api as sm
from statsmodels.formula.api import ols
from pingouin import anova

# 직접 호출
aov = anova(data=data, dv=yname, between=[xname1, xname2])          # 등분산 충족

model = ols(f"{yname} ~ C({xname1}) * C({xname2})", data=data)      # 등분산 위배
fit = model.fit(cov_type="HC3")
aov = sm.stats.anova_lm(fit, typ=2, robust="hc3")

# helpers 모듈
aov = my_stats.anova_twoway(origin, y='height', between=['water', 'sun'])
post = my_stats.posthoc_twoway(df2, y='time', between=['poison', 'treat'])
```

상호작용 시각화는 `sb.pointplot(data=origin, x='요인B', y='종속변수', hue='요인A', errorbar='se')` 로 확인 (선이 평행하면 상호작용 없음, 교차하면 있음).

### 2-6. 그룹 3개 이상, 대응 (반복측정)

```
정규성? ─ 충족 → Repeated Measures ANOVA / 위배 → Friedman test
```
- Repeated Measures ANOVA: 같은 대상 3회 이상 반복측정(복용 전/1주/4주 등), 개체 간 편차 제거하고 개체 내 변화만 봄.
- Friedman: Wilcoxon signed-rank를 3개 이상 그룹으로 확장한 비모수 버전.

## 3. 범주형 vs 범주형 — 카이제곱검정

**질문**: 두 범주형 변수 사이에 관련성(독립성)이 있는가?

- H0: 두 변수는 독립이다 / H1: 독립이 아니다
- **전제조건**: 기대빈도(expected frequency) 5 미만인 셀이 전체의 20% 넘으면 근사가 부정확해짐 → 이땐 Fisher's exact test 사용 (주로 2×2표)

```
교차표 작성 → 기대빈도 확인
 ├─ 5 미만 셀 20% 이하 → 카이제곱검정 (chi2_contingency)
 └─ 5 미만 셀 20% 초과 → Fisher's exact test (fisher_exact)
```

```python
import pandas as pd
from scipy.stats import chi2_contingency, fisher_exact

cross_tab = pd.crosstab(df['성별'], df['구매여부'])
chi2, p, dof, expected = chi2_contingency(cross_tab)   # expected로 기대빈도 확인

odds, p = fisher_exact(cross_tab)  # 2x2, 기대빈도 조건 위배 시
```

효과크기는 반드시 같이 봄 → **Cramér's V** (통계적으로 유의해도 V < 0.1이면 실질적 의미는 거의 없음, Olist 프로젝트에서 V<0.02로 판단한 것과 같은 맥락).

## 4. 연속형 vs 연속형 — 상관/회귀 (개념 위치만)

| 상황 | 방법 |
|---|---|
| 두 연속형 변수 관계 강도 (정규성 충족) | Pearson 상관계수 |
| 두 연속형 변수 관계 강도 (정규성 위배/순위) | Spearman 순위상관계수 |
| 연속형 결과를 여러 변수로 설명·예측 | 회귀분석 (OLS) |
| 독립변수 간 다중공선성 확인 | VIF |

상관은 "관계가 있는가"만, 회귀는 "그 관계로 얼마나 설명·예측 가능한가"까지 본다는 게 핵심 차이. 회귀도 잔차의 정규성·등분산성·독립성을 가정하므로 결국 1장의 3대 가정과 같은 틀.

## 5. 효과크기 — 유의성과 별개로 꼭 같이 볼 것

| 검정 계열 | 효과크기 | 작음 | 중간 | 큼 |
|---|---|---|---|---|
| 독립/대응 t-test | Cohen's d | 0.2 | 0.5 | 0.8 |
| 카이제곱 (2×2) | φ | 0.1 | 0.3 | 0.5 |
| 카이제곱 (r×c) | Cramér's V | 0.1 | 0.3 | 0.5 |
| Mann-Whitney/Wilcoxon | rank-biserial r | 0.1 | 0.3 | 0.5 |
| ANOVA (일원) | η² = η²ₚ | 0.01 | 0.06 | 0.14 |
| ANOVA (이원 이상) | η²ₚ (partial, np2) | 0.01 | 0.06 | 0.14 |
| 회귀 | Cohen's f² | 0.02 | 0.15 | 0.35 |

- 일원분산분석에서는 SS_Total = SS_Between + SS_Within이라 η² = η²ₚ지만, **이원분산분석부터는 둘이 달라짐** → pingouin/SPSS가 기본 보고하는 건 η²ₚ(np2) 쪽.
- 기준값(0.2/0.5/0.8 등)은 Cohen(1988)의 관행적 경험 기준이지 절대 법칙 아님 — 도메인 지식과 같이 해석.

```
1. 데이터 로드 (load_data) → head(), isna().sum()으로 구조/결측 확인
2. 그룹 구조 판단 (독립? 대응? 몇 개?) — 여기서 기법이 정해짐
3. 필요시 wide↔long 변환 (melt / pivot_table) — hue로 겹쳐그리거나 짝짓기 위함
4. 분포 시각화로 먼저 감 잡기 (my_plot.kdeplot 등)
5. 가정 확인 (test_assumptions) — 정규성 → (충족시만) 등분산성
6. 가정 결과에 따라 기법 자동/수동 분기
7. 필요한 방향(양측/좌측/우측)으로 검정 실행
8. 유의하면 사후검정 (그룹 3개 이상) + 효과크기 같이 확인
9. boxplot + Annotator로 시각화, test= 문자열이 실제 검정과 일치하는지 재확인
10. 통계적 유의성 → 비즈니스/현실적 결론 문장으로 번역
```

## 8. 자주 하는 실수 체크리스트

- [ ] 정규성 확인 안 하고 바로 t-test/ANOVA 돌리기 (p-value 신뢰 불가)
- [ ] 그룹 일부만 정규성 위배됐는데 "전부 위배될 때만 비모수"로 잘못 판단
- [ ] Wilcoxon signed-rank 할 때 popmean/기준값 빼는 거 깜빡 (`data - popmean` 안 하면 엉뚱한 걸 검정)
- [ ] 대응표본 diff 방향과 `alternative` 방향 불일치 → 좌/우측 판정 뒤집힘
- [ ] `ttest_ind(a, a, ...)` 처럼 같은 컬럼 실수로 중복 입력
- [ ] Annotator `test=` 문자열과 실제 수행한 검정 불일치
- [ ] ANOVA 유의 → 사후검정 없이 바로 결론 내리기 (어느 그룹끼리 다른지 안 봄)
- [ ] 일원 vs 이원 ANOVA에서 η² / η²ₚ 구분 안 하고 아무거나 보고 (이원부터는 값이 달라짐)
- [ ] 유의성만 보고 효과크기 안 보기 (p<0.05인데 실질 효과는 미미할 수 있음)
- [ ] 카이제곱 전 기대빈도 확인 안 하고 바로 chi2_contingency (Fisher's exact 필요한 경우 놓침)

## 9. 면접용 한 줄 요약 모음

> **일표본**: "표본 평균이 특정 기준값과 다른지 봅니다. 정규성 검정 먼저 하고, 충족하면 t-검정, 위배되면 Wilcoxon 부호순위검정을 씁니다."

> **독립표본**: "서로 다른 두 집단을 비교할 때 씁니다. 각 집단 정규성을 먼저 보고, 하나라도 위배되면 Mann-Whitney U, 둘 다 충족하면 등분산성까지 봐서 Student's t 또는 Welch's t를 선택합니다."

> **ANOVA**: "세 집단 이상 비교할 때 t-test를 반복하면 1종 오류가 누적돼서, 한 번에 검정하는 F-검정을 씁니다. 유의하면 어느 집단끼리 다른지 보려고 사후검정을 추가로 진행합니다."

> **카이제곱**: "두 범주형 변수가 서로 관련 있는지 볼 때 씁니다. 유의성뿐 아니라 Cramér's V로 관련성의 실질적 강도까지 같이 봅니다."
