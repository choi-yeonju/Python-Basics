## 1. LinePlot

### 1-1. 기본 3가지 호출 패턴 (seaborn 공통 패턴)

모든 seaborn plot 함수는 동일한 3가지 방식으로 호출 가능하다.

| 패턴               | 코드 예시                                    | 설명                                                    |
| ------------------ | -------------------------------------------- | ------------------------------------------------------- |
| 자동인식           | `sb.lineplot([10,20,30,40,50])`            | 리스트 하나만 넘기면 y값으로 인식, x는 인덱스(0,1,2...) |
| 개별 데이터 지정   | `sb.lineplot(x=[...], y=[...])`            | x, y를 따로 지정                                        |
| DataFrame + 컬럼명 | `sb.lineplot(data=df, x='col1', y='col2')` | 실무에서 가장 많이 쓰는 방식                            |

### 1-2. hue, palette

- `hue='Flavor'` → 범주별로 선을 나눠서 그림 (자동으로 색상도 구분됨)
- `palette="PuRd"` → 색상 팔레트 지정 (hue와 함께 써야 의미 있음)

### 1-3. 선/마커 스타일 옵션

```python
sb.lineplot(data=origin, x='Date', y='Quantity',
            c="#1D84C3",            # 선 색상
            linestyle=':',          # 선 스타일 (점선)
            linewidth=5,            # 선 굵기
            marker="o",             # 마커 모양
            markersize=20,          # 마커 크기
            markeredgewidth=3,      # 마커 테두리 굵기
            markerfacecolor="#00ff00",  # 마커 안쪽 색
            markeredgecolor="#ff0000")  # 마커 테두리 색
```

### 1-4. 축 범위/눈금 설정

- `ax.set_ylim(18, 28)` : y축 표시 범위 제한 (x축은 `set_xlim`)
- `ax.set_yticks(눈금위치리스트, 눈금에표시할값리스트, fontsize=6, rotation=-45)`
  - **두 리스트는 보통 같은 값을 쓰지만, "실제 위치"와 "표시할 텍스트"를 분리할 수 있다는 의미**

### 1-5. 다중 선 그래프 (같은 좌표축에 여러 선)

```python
sb.lineplot(x=[1,2,3,4], y=[10,20,35,40], label="A변화량")
sb.lineplot(x=[1,2,3,4], y=[10,15,30,35], label="B변화량")
ax.legend(loc='upper left')
```

→ `lineplot`을 두 번 호출하면 같은 ax 위에 겹쳐 그려진다. `label`을 지정해야 범례(legend)가 의미 있게 표시됨.

## 2. Long-format ↔ Wide-format 변환 (melt) — 오늘 가장 중요한 개념

### 2-1. 왜 필요한가

seaborn은 **hue로 범주를 나누려면 "긴 형식(long format)" 데이터**가 필요하다.

- Wide format: `서울시 일일 확진`, `전국 일일 확진`처럼 변수가 **컬럼**으로 따로 존재
- Long format: `구분`(변수명), `확진자 수`(값) 컬럼 단 2개로 합쳐진 형태

이렇게 바꿔야 `hue='구분'` 하나로 두 선을 자동으로 나눠 그릴 수 있다.

### 2-2. melt 사용법

```python
df2 = melt(df, id_vars='기준일',
           value_vars=['서울시 일일 확진', '전국 일일 확진'],
           var_name='구분', value_name='확진자 수')
```

- `id_vars` : 고정시킬 기준 컬럼 (날짜처럼 펼치지 않을 컬럼)
- `value_vars` : 세로로 풀어낼(녹일) 컬럼들
- `var_name` : 원래 컬럼명이 들어갈 새 컬럼 이름
- `value_name` : 원래 값이 들어갈 새 컬럼 이름

melt 전후 shape 변화: `(N행, 3열)` → `(N×2행, 3열)` (컬럼 2개가 행으로 풀리면서 행 수가 2배가 됨)

## 3. KDE Plot (커널밀도추정)

### 3-1. 개념

히스토그램을 부드러운 곡선으로 추정한 것. 막대 대신 연속적인 확률밀도 곡선으로 분포를 표현.

### 3-2. 일변량 vs 다변량

- `sb.kdeplot(data=df, x='컬럼')` : 변수 하나의 분포
- `sb.kdeplot(data=df)` (x, y 미지정) : **데이터프레임의 모든 연속형 변수**에 대한 밀도 곡선을 한 번에 그림
- `x` 대신 `y`를 지정하면 세로 방향으로 그려짐

### 3-3. 이변량 KDE

```python
sb.kdeplot(data=origin, x="Petal.Width", y="Sepal.Width", hue="Species")
```

→ 두 변수의 결합분포(등고선 형태)를 그림

### 3-4. 평균선 추가하는 법

```python
mean_val = origin["Sepal.Width"].mean()
ax.axvline(x=mean_val, linestyle='-', color='#ff2200')   # 세로선
ax.text(x=mean_val+0.05, y=ax.get_ylim()[1]*0.95,
        s=f'Mean: {mean_val:.2f}', color='#ff2200', fontsize=14)
```

- `axvline` : x좌표에 수직선
- `text(x, y, s=...)` : 임의 좌표에 텍스트 표시. `ax.get_ylim()[1]`은 현재 y축 최댓값이므로 그래프 높이에 비례한 위치에 텍스트를 자동 배치하는 트릭

## 4. Histogram

### 4-1. 구간(bins) 직접 계산하기

```python
hist, bins = np.histogram(origin['월수입'], bins=5)
bins = np.round(bins, 1)
```

- `np.histogram`은 **반드시 숫자형(연속형) 데이터**에만 사용 가능
- 반환값: `hist`(각 구간의 빈도수), `bins`(구간 경계값, 구간 개수+1개)
- 이렇게 구한 `bins`를 `sb.histplot(..., bins=bins)`에 그대로 넣으면 x축 구간이 정확히 일치함

### 4-2. kde=True

`sb.histplot(data=df, x='col', bins=bins, kde=True)` → 히스토그램 위에 KDE 곡선을 겹쳐서 표시

## 5. BoxPlot (상자그림)

### 5-1. 호출 패턴

- `sb.boxplot(data=series, orient="h")` : 가로 방향
- `sb.boxplot(data=df, orient="v")` : DataFrame 전체 컬럼을 세로로 비교
- `sb.boxplot(data=df, y='컬럼')` / `x='컬럼'` : 단일 컬럼, y면 세로, x면 가로
- `sb.boxplot(data=df, y='컬럼', hue='범주')` : 범주별 비교

### 5-2. orient 파라미터 규칙

- 데이터를 **x**에 지정하면 자동으로 **가로(h)**
- 데이터를 **y**에 지정하면 자동으로 **세로(v)**
- 명시적으로 `orient="h"` 또는 `"v"`로 강제 지정 가능

## 6. 오늘 틀렸거나 헷갈렸던 부분 (꼭 다시 확인)

### ❌ (1) 범주형(문자열) 컬럼에 `np.histogram` 사용

```python
hist, bins = np.histogram(df1['전공'], bins=6)   # 전공 = 'STAT'/'COMP' 같은 문자열
```

→ `np.histogram`은 숫자형 데이터 전용 함수. **'전공'처럼 카테고리(문자열) 컬럼에는 사용할 수 없다.**
범주형 데이터의 빈도를 보고 싶다면 `value_counts()` + `sb.barplot()` (또는 `sb.countplot()`)을 써야 한다.
→ 이어지는 `sb.histplot(data=origin, x='전공', hue='전공', bins=bins)`도 같은 이유로 잘못된 접근. 범주형 x축에 hue까지 같은 컬럼으로 주면 의미상 중복(같은 컬럼을 x와 hue에 동시에 씀)이기도 함.

### ❌ (2) df1/df2 복사-붙여넣기 실수 (COMP 기말고사 코드)

```python
df2 = origin[origin['전공'] == 'COMP']
...
my_plot.histplot(data=df1,   # ← df2를 써야 하는데 df1(STAT)이 그대로 남아있음
                 x='기말고사', bins=6, kde=True,
                 title='전산학 전공 학생의 중간고사 성적분포', ...)
```

→ 코드를 복사해서 재사용할 때 **데이터프레임 변수명을 같이 안 바꿔서** STAT 데이터(df1)로 COMP 그래프를 그리는 실수. 결과 그래프가 실제로는 COMP가 아니라 STAT 데이터로 그려짐.

### ❌ (3) title 복사 후 안 바꿈

STAT 기말고사 히스토그램에 `title='통계학 전공 학생의 중간고사 성적분포'`라고 그대로 둠 → 기말고사인데 제목은 "중간고사".
→ **복사-붙여넣기 후에는 변수명뿐 아니라 제목 문자열도 항상 다시 확인하는 습관 필요.**

### ❌ (4) pivot_table 사용법 오류 (Covid 연습문제)

```python
pivot1 = pivot_table(origin, index=['서울시 일일 확진', '전국 일일 확진'])
```

→ `index`에는 보통 **그룹 기준이 되는 범주형 컬럼**(예: 날짜, 구분)이 들어가야 하는데, 여기선 **값 컬럼 자체**를 index로 넣어서 의미 없는 결과가 나옴. (pivot_table은 `index`=행 기준, `columns`=열 기준, `values`=집계할 값, `aggfunc`=집계함수 4가지 역할을 구분해서 써야 함)

### ❌ (5) `origin.melt()` 인자 없이 호출

→ `id_vars`, `value_vars`를 지정하지 않으면 **모든 컬럼이 의도와 다르게** variable/value로 풀려버림. melt는 어떤 컬럼을 고정하고 어떤 컬럼을 풀지 항상 명시해야 의도한 long-format이 나온다.

### ❌ (6) `origin.groupby("variable")` — 존재하지 않는 컬럼 호출

→ `'variable'`은 `melt()`를 인자 없이 호출했을 때 **자동 생성되는 기본 컬럼명**인데, 정작 그 결과를 변수에 저장하지 않고 다음 줄에서 `origin`(원본, melt 적용 전)에 대해 groupby를 시도해서 에러 발생. → **melt 결과는 반드시 새 변수에 저장한 뒤에 그 변수로 후속 작업을 해야 함.**

### ❌ (7) `sb.lineplot(x)` — 정의되지 않은 변수 사용

→ 마지막 코드에서 `x`라는 변수가 그 전에 정의된 적이 없는데 그대로 호출 → NameError. 미완성 상태로 남겨둔 코드.

## 7. 오늘의 핵심 요약 (한 줄씩)

1. **seaborn 그래프는 항상 자동인식 / 개별지정 / DataFrame+컬럼명 3가지 패턴이 동일하게 존재한다.**
2. **hue로 범주를 나누려면 데이터가 long-format이어야 하고, wide→long 변환은 `melt`로 한다.**
3. **np.histogram, 통계 함수들은 숫자형 데이터 전용 — 범주형엔 value_counts/countplot.**
4. **pivot_table은 index(행 기준)/columns(열 기준)/values(집계 대상)/aggfunc 역할을 명확히 구분해서 사용.**
5. **melt() 등 변환 함수는 결과를 반드시 새 변수에 저장 후 그 변수를 이어서 사용해야 한다.**
6. **복사-붙여넣기로 코드를 재사용할 때는 데이터프레임 변수명 + title 문자열을 항상 같이 점검할 것.**
