# 베이스 모델 구축 : 회귀 알고리즘 핵심 정리

> **학습 목표**
> 각 알고리즘의 이름에서 원리를 추론할 수 있고,
> **“이 알고리즘은 어떤 질문에 답하는가 → 어떤 방식으로 답을 찾는가 → 무엇을 반드시 알아야 하는가 → 장단점은 무엇인가”**의 흐름으로 이해하는 것을 목표로 함.

강의자료는 주택가격처럼 **연속형 수치를 예측하는 회귀(Regression)** 문제를 중심으로 선형 계열, 비선형 계열, 앙상블 계열 모델을 다룸.

---

# 0. 전체 알고리즘 지도

| 계열             | 알고리즘          | 핵심 아이디어                                     |
| ---------------- | ----------------- | ------------------------------------------------- |
| 선형             | Linear Regression | 하나의**선형식**으로 관계 설명              |

| 최적화 기반 선형 | SGD               | 계수를**조금씩 수정하며 최적값 탐색**       |
| 거리 기반        | KNN               | **가까운 이웃 K개**를 참고                  |
| 커널 기반        | SVR               | **일정 오차는 허용**하고 중요한 오차를 줄임 |

| Boosting 앙상블  | CatBoost          | **범주형 변수 처리에 강한 Boosting**        |

# 1. Linear Regression — 선형회귀

## 1) 이름에서 얻는 힌트

- **Linear** = 선형, 직선
- **Regression** = 회귀, 연속형 값을 예측하는 문제

> **이름의 힌트:** 변수와 결과 사이의 관계를 **직선적인 관계로 표현함**

---

## 2) 어떤 질문에 답하는가?

> **“X가 변할 때 y는 얼마나 달라지는가?”**
>
> 예) 면적, 층, 연식 등이 주어졌을 때 **주택가격은 얼마인가?**

---

## 3) 정의

독립변수 (X)와 종속변수 (y)의 관계를 하나의 선형식으로 표현하는 회귀모형

\beta\_0+\beta\_1x\_1+\cdots+\beta\_px\_p
]

학습 데이터에서 실제값과 예측값의 차이가 가장 작아지도록 회귀계수 (\beta)를 찾음

**MSE를 최소화하는 최소제곱법(OLS)**

---

## 4) 필수 개념

| 개념                       | 쉬운 설명                                                        |
| -------------------------- | ---------------------------------------------------------------- |
| **회귀계수 (\beta)** | 각 변수가 예측값에 **얼마나 영향을 주는지 나타내는 숫자**  |
| **절편 (\beta\_0)**  | 모든 독립변수가 0일 때의 **기본 출발값**                   |
| **예측값 (\hat y)**  | 모델이 계산한 y의 예상값                                         |
| **잔차(Residual)**   | 실제값과 예측값의 차이                                           |
| **MSE**              | 오차를 제곱한 뒤 평균낸 값                                       |
| **OLS**              | 오차 제곱합이 가장 작아지는 회귀선을 찾는 방법                   |
| **다중공선성**       | 독립변수끼리 너무 비슷하여 각 변수의 영향을 구분하기 어려운 상태 |
| **이상치**           | 대부분의 데이터에서 유난히 멀리 떨어진 값                        |

### 핵심 관계

[
Residual=y-\hat y
]

[
MSE=\frac{1}{n}\sum (y-\hat y)^2
]

### 핵심 관계

$$
Residual = y - \hat{y}
$$

$$
MSE = \frac{1}{n}\sum (y - \hat{y})^2
$$

> **선형회귀의 목표 = MSE가 가장 작아지는 계수를 찾는 것**

---

## 5) 특징

- 전체 데이터에 적용되는 **하나의 공통 회귀식**을 만듦
- 각 변수의 계수를 통해 영향 방향과 크기를 해석하기 쉬움
- 비선형 관계를 자동으로 표현하지는 못함
- 이상치와 다중공선성에 영향을 받을 수 있음

---

## 6) 장점

- 구조가 단순함
- 학습과 예측이 빠름
- 결과 해석이 쉬움
- 회귀계수의 의미를 설명하기 좋음
- 다른 모델과 비교하는 **베이스라인 모델**로 적합함

## 7) 단점

- 복잡한 비선형 관계에 한계가 있음
- 다중공선성에 취약함
- 이상치의 영향을 많이 받을 수 있음

### 한 줄 기억

> **Linear Regression = 하나의 직선식으로 X와 y의 관계를 설명하는 모델**

---

# 2. Ridge Regression — 릿지 회귀

## 1) 이름에서 얻는 힌트

- **ridge** = 능선. 계수를 제한했을 때 목적함수의 기하학적 형태에서 능선과 관련된 구조가 나타난데서 유래 

> **“계수가 너무 커지지 않도록 부드럽게 눌러주는 선형회귀”**

---

## 2) 어떤 질문에 답하는가?

> **“변수가 많거나 서로 비슷한 변수들이 있을 때, 회귀계수를 좀 더 안정적으로 만들 수 없을까?”**

---

## 3) 정의

기본 선형회귀의 오차에 **L2 패널티**를 추가하는 정규화 회귀

[
Loss+\lambda\sum\_{j=1}^{p}\beta\_j^2
]

회귀계수가 너무 커지면 벌점을 주어 계수를 작게 만듦

---

## 4) 필수 개념

| 개념                               | 쉬운 설명                                                                   |
| ---------------------------------- | --------------------------------------------------------------------------- |
| **정규화(Regularization)**   | 계수가 지나치게 커지는 것을 억제하여 모델을 단순하고 안정적으로 만드는 방법 |
| **Penalty**                  | 정규화를 위해 목적함수에 추가하는**벌점**                             |
| **L2 정규화**                | 계수를**제곱**해서 벌점을 주는 방식                                   |
| **(\lambda), ****`alpha`** | 벌점을 얼마나 강하게 줄지 정하는 값                                         |
| **계수 축소(Shrinkage)**     | 회귀계수를 0에 가까운 쪽으로 작게 만드는 것                                 |
| **다중공선성**               | 비슷한 변수들이 존재하여 회귀계수가 불안정해지는 문제                       |
| **스케일링**                 | 변수별 크기 차이를 줄여 패널티를 공정하게 적용하는 과정                     |

### 중요한 점

Ridge는

> **계수를 0에 가깝게 줄이지만 일반적으로 정확히 0으로 만들지는 않음.**

따라서 모든 변수를 유지하면서 각 변수의 영향력을 조절함

절편 (\beta\_0)는 일반적으로 정규화 대상에서 제외함
(예측선의 기본 위치를 잡는 절편까지 누를 필요는 없으므로)

---

## 5) 특징

- **L2 정규화**
- 다중공선성 완화에 유용
- 변수를 제거하지 않고 모두 유지
- 변수의 스케일에 영향을 받으므로 스케일링이 중요함

---

## 6) 장점

- 다중공선성을 완화할 수 있음
- 계수가 선형회귀보다 안정적일 수 있음
- 모든 변수를 유지할 수 있음
- 과대적합 완화에 도움을 줄 수 있음

## 7) 단점

- 필요 없는 변수를 자동으로 제거하지는 않음
- `alpha` 값을 적절하게 설정해야 함
- 변수 해석 시 정규화로 인해 계수가 축소되어 있음을 고려해야 함

### 한 줄 기억

> **Ridge = L2 패널티로 모든 계수를 조금씩 줄이는 회귀**

---

# 3. Lasso Regression — 라쏘 회귀

## 1) 이름에서 얻는 힌트

**LASSO**

> **Least Absolute Shrinkage and Selection Operator**

이름에서 특히 중요한 두 단어

- **Shrinkage** = 계수 축소
- **Selection** = 변수 선택

줄이고나서 보니 올가미라는 단어 > 계수를 올가미로 조이듯 줄여서, 필요없는 변수는 0으로 만들어 제거 해 버림

---

## 2) 어떤 질문에 답하는가?

> **“변수가 너무 많은데 중요하지 않은 변수까지 자동으로 제거할 수 없을까?”**

---

## 3) 정의

선형회귀의 오차에 **L1 패널티**를 추가하는 정규화 회귀

[
Loss+\lambda\sum\_{j=1}^{p}|\beta\_j|
]

---

## 4) 필수 개념

| 개념                        | 쉬운 설명                                                            |       |                                   |
| --------------------------- | -------------------------------------------------------------------- | ----- | --------------------------------- |
| **L1 정규화**         | 계수의**절댓값**을 이용해 벌점을 주는 방법                     |       |                                   |
| **절댓값 패널티**     | (                                                                    | \beta | )가 클수록 더 큰 벌점을 받는 방식 |
| **계수 축소**         | 회귀계수의 크기를 줄이는 것                                          |       |                                   |
| **Feature Selection** | 중요하지 않은 변수의 계수를 0으로 만들어 자동으로 변수를 선택하는 것 |       |                                   |
| **희소성(Sparsity)**  | 많은 계수 중 일부만 남고 나머지는 0이 되는 특성                      |       |                                   |
| **스케일링**          | 변수 크기 차이 때문에 패널티가 불공평해지는 것을 막는 과정           |       |                                   |

### 가장 중요한 특징

Lasso는 일부 회귀계수를

[
\beta\_j=0
]

으로 만들 수 있음. 즉 

> **계수가 0인 변수는 최종 예측식에서 사실상 제외됨**

---

## 5) 특징

- **L1 정규화**
- 변수 선택 기능
- 변수가 많은 데이터에서 유용
- 상관관계가 높은 변수들이 여러 개 있으면 변수 선택이 불안정할 수 있음

---

## 6) 장점

- 중요하지 않은 변수 제거 가능
- 자동 Feature Selection 가능
- 모델을 단순하게 만들 수 있음
- 변수가 매우 많은 데이터에서 유용함

## 7) 단점

- 서로 강하게 상관된 변수들 중 어떤 변수를 남길지 불안정할 수 있음
- `alpha` 설정이 필요함
- 스케일링이 중요함

### 한 줄 기억

> **Lasso = L1 패널티로 필요 없는 변수의 계수를 0으로 만드는 회귀**

---

# 4. ElasticNet — 엘라스틱넷

## 1) 이름에서 얻는 힌트

- **Elastic** = 탄력적인
- **Net** = 망

[
L1+L2
]

를 탄력적으로 섞어서 사용 

---

## 2) 어떤 질문에 답하는가?

> **“Ridge의 계수 안정화와 Lasso의 변수 선택을 동시에 사용할 수 없을까?”**

---

## 3) 정의

L1과 L2 패널티를 함께 사용하는 정규화 회귀

[
Loss
+\lambda\_1\sum|\beta\_j|
+\lambda\_2\sum\beta\_j^2
]

---

## 4) 필수 개념

| 개념                 | 쉬운 설명                                        |
| -------------------- | ------------------------------------------------ |
| **L1**         | 일부 계수를 0으로 만들어 변수 선택에 도움        |
| **L2**         | 전체 계수의 크기를 줄여 모델을 안정화            |
| **계수 축소**  | 너무 큰 계수를 작게 만드는 것                    |
| **변수 선택**  | 필요 없는 변수의 계수를 0으로 만드는 것          |
| **다중공선성** | 서로 비슷한 변수 때문에 계수가 불안정해지는 문제 |
| **혼합 비율**  | L1과 L2를 어느 정도씩 사용할지 정하는 값         |

---

## 5) 특징

- Ridge와 Lasso의 장점을 결합
- 다중공선성 완화와 변수 선택을 동시에 추구
- 상관관계가 높은 변수가 많은 상황에서 사용할 수 있음

---

## 6) 장점

- 계수 안정화 가능
- 변수 선택 가능
- 여러 변수가 서로 강하게 관련된 데이터에 유용할 수 있음

## 7) 단점

- Ridge나 Lasso보다 조정해야 할 설정이 더 많음
- 스케일링이 중요함
- 구조가 상대적으로 복잡함

### 한 줄 기억

> **ElasticNet = Ridge의 L2 + Lasso의 L1**

---

# 5. SGD — 확률적 경사하강법

## 1) 이름에서 얻는 힌트

**SGD = Stochastic Gradient Descent**

- **Stochastic** = 확률적인
- **Gradient** = 기울기
- **Descent** = 내려감

> **"오차가 줄어드는 방향으로 조금씩 내려가며 답을 찾는다.”**

---

## 2) 어떤 질문에 답하는가?

> **“정답을 한 번에 계산하지 않고, 반복적으로 조금씩 수정하면서 최적의 계수를 찾을 수 없을까?”**

---

## 3) 정의

전체 데이터를 이용해 해를 한 번에 계산하는 대신, 데이터의 일부를 이용하여 손실함수의 기울기를 계산하고 **계수를 반복적으로 업데이트하는 최적화 방법**

---

## 4) 필수 개념

| 개념                       | 쉬운 설명                                                           |
| -------------------------- | ------------------------------------------------------------------- |
| **Gradient**         | 어느 방향으로 움직이면 오차가 증가하거나 감소하는지 알려주는 기울기 |
| **Gradient Descent** | 오차가 감소하는 방향으로 조금씩 이동하는 방법                       |
| **Learning Rate**    | 한 번 움직일 때 얼마나 크게 움직일지 정하는 값                      |
| **Epoch**            | 전체 학습 데이터를 한 번 모두 학습한 것                             |
| **반복 학습**        | 계수를 한 번에 정하지 않고 여러 번 수정하는 과정                    |
| **스케일링**         | 변수 크기 차이로 인해 학습이 불안정해지는 것을 줄이는 과정          |

---

## 5) 특징

- 반복적으로 계수를 업데이트함
- 대규모 데이터에 활용하기 좋음
- 학습률 설정이 중요함
- 변수 크기에 영향을 받으므로 스케일링이 중요함

---

## 6) 장점

- 데이터가 매우 많을 때 효율적임
- 메모리 사용을 줄일 수 있음
- 점진적인 학습에 활용 가능함

## 7) 단점

- Learning Rate에 민감함
- 반복 횟수 설정이 필요함
- 설정에 따라 최적값으로 안정적으로 수렴하지 않을 수 있음

### 한 줄 기억

> **SGD = 오차가 줄어드는 방향으로 조금씩 이동하며 답을 찾는 방법**

---

# 6. KNN — K-최근접이웃

## 1) 이름에서 얻는 힌트

**KNN = K-Nearest Neighbors**

- **K** = 몇 개
- **Nearest** = 가장 가까운
- **Neighbors** = 이웃

> 알고리즘 이름 자체가 작동 원리를 설명

---

## 2) 어떤 질문에 답하는가?

> **“새 데이터와 가장 비슷한 K개의 기존 사례는 어떤 값을 가지고 있었는가?”**

---

## 3) 정의

새로운 데이터와 가장 가까운 K개의 데이터를 찾은 뒤,

- 분류 → 다수 클래스
- 회귀 → 이웃들의 평균

을 이용해 예측하는 방법

**가까운 K개의 이웃을 이용하는 거리 기반·국소 모형**

---

## 4) 필수 개념

| 개념                         | 쉬운 설명                                                            |
| ---------------------------- | -------------------------------------------------------------------- |
| **K**                  | 예측에 참고할 가까운 이웃의 개수                                     |
| **거리(Distance)**     | 두 데이터가 얼마나 비슷하거나 떨어져 있는지를 수치로 표현한 것       |
| **Euclidean Distance** | 두 점 사이의 직선거리                                                |
| **Manhattan Distance** | 각 변수별 차이의 절댓값을 모두 더한 거리                             |
| **Minkowski Distance** | Euclidean과 Manhattan 등을 포함하는 일반화된 거리                    |
| **Local Model**        | 전체 데이터에 공통된 식을 만들지 않고 새 데이터 주변만 참고하는 모델 |
| **스케일링**           | 변수의 단위와 크기를 비슷하게 맞추는 과정                            |
| **차원의 저주**        | 변수가 너무 많아지면 데이터 간 거리 차이가 뚜렷하지 않아지는 현상    |

---

## 5) 왜 스케일링이 중요한가?

KNN은 **거리로 판단하기 때문**

예:

| 변수 |            값 |
| ---- | ------------: |
| 나이 |        20\~70 |
| 소득 | 2,000\~20,000 |

스케일링하지 않으면 숫자가 큰 소득이 거리 계산에 훨씬 큰 영향을 줄 수 있음.

> **거리 기반 알고리즘 → 스케일링이 매우 중요함**

---

## 6) 특징

- 별도의 복잡한 회귀식을 만들지 않음
- 예측할 때마다 가까운 이웃을 다시 찾음
- 전체보다는 **주변의 지역적 패턴**을 이용함

---

## 7) 장점

- 원리가 직관적임
- 구현이 쉬움
- 비선형 관계 표현 가능
- 지역적 패턴 포착에 유리함

## 8) 단점

- 데이터가 많을수록 예측 비용 증가
- 스케일에 매우 민감
- 이상치 영향을 받을 수 있음
- 변수가 너무 많아지면 거리의 의미가 약해질 수 있음
- 학습 데이터를 계속 보관해야 함

### 한 줄 기억

> **KNN = 나와 가장 가까운 K명의 값을 보고 예측하는 모델**

---

# 7. SVR — Support Vector Regression

## 1) 이름에서 얻는 힌트

**SVR = Support Vector Regression**

SVR은 **SVM(Support Vector Machine)** 계열의 회귀모형

- **Support** = 지지하는
- **Vector** = 데이터 점을 나타내는 벡터
- **Regression** = 회귀

핵심은 **Support Vector**

---

## 2) 어떤 질문에 답하는가?

> **“작은 오차까지 모두 맞추려 하지 말고 일정 범위의 오차는 허용하면서 안정적인 예측선을 만들 수 없을까?”**

---

## 3) 정의

예측선 양쪽에 일정한 허용범위인 **ε-tube**를 만들고,

- tube 안에 들어오는 오차 → 허용
- tube 밖으로 벗어난 오차 → 줄이도록 학습

하는 회귀모형

---

## 4) 필수 개념

| 개념                     | 쉬운 설명                                                                |
| ------------------------ | ------------------------------------------------------------------------ |
| **SVM**            | Support Vector를 이용하여 데이터의 경계나 관계를 찾는 모델               |
| **Support Vector** | 모델의 경계나 예측선을 결정하는 데 중요한 데이터                         |
| **ε-tube**        | 예측선 주변의**“이 정도 오차는 괜찮다”**는 허용구간              |
| **epsilon**        | ε-tube의 폭을 정하는 값                                                 |
| **C**              | 허용범위를 벗어난 오차를 얼마나 강하게 벌줄지 정하는 값                  |
| **Kernel**         | 데이터 사이의 관계를 어떤 방식으로 계산할지 정하는 방법                  |
| **RBF Kernel**     | 가까운 데이터끼리의 유사성을 이용하여 복잡한 비선형 관계를 표현하는 커널 |
| **gamma**          | 하나의 데이터가 주변에 영향을 주는 범위를 조절하는 값                    |
| **스케일링**       | 변수의 크기 차이 때문에 거리·내적 계산이 왜곡되지 않게 하는 과정        |

---

## 5) Kernel 쉽게 이해하기

> **Kernel = SVM이 데이터 사이의 관계를 바라보는 계산 방식**

| Kernel               | 쉽게                                      |
| -------------------- | ----------------------------------------- |
| **Linear**     | 직선 관계                                 |
| **Polynomial** | 다항식 곡선 관계                          |
| **RBF**        | 거리와 유사성을 이용한 복잡한 비선형 관계 |

---

## 6) 주요 하이퍼파라미터

### `C`

> **오차를 얼마나 엄격하게 벌줄 것인가**

- C 큼 → 오차에 엄격
- C 작음 → 어느 정도 오차 허용

### `epsilon`

> **어디까지를 오차로 보지 않을 것인가**

### `gamma`

> **한 데이터가 주변 어디까지 영향을 미칠 것인가**

---

## 7) 특징

- Kernel을 이용하여 비선형 관계 학습 가능
- 일정 수준의 작은 오차는 허용
- Support Vector가 모델을 결정하는 데 중요한 역할을 함
- 스케일링이 매우 중요함

---

## 8) 장점

- 작은 잡음에 지나치게 반응하지 않도록 설계 가능
- Kernel을 이용한 비선형 회귀 가능
- 고차원 데이터에서도 사용할 수 있음

## 9) 단점

- 대용량 데이터에서는 학습 비용 증가
- 스케일에 매우 민감
- 하이퍼파라미터 설정에 민감
- 예측 근거를 직관적으로 설명하기 어려움

### 한 줄 기억

> **SVR = 일정 범위의 오차는 허용하고 중요한 오차를 줄이는 회귀**

---

# 8. Decision Tree — 의사결정나무

## 1) 이름에서 얻는 힌트

- **Decision** = 결정
- **Tree** = 나무

> **질문을 나뭇가지처럼 반복하면서 결정을 내리는 모델**

---

## 2) 어떤 질문에 답하는가?

> **“어떤 조건을 기준으로 데이터를 나누면 비슷한 값끼리 잘 묶일까?”**

예:

```text
면적 > 84㎡?
     ↓
강남권인가?
     ↓
신축인가?
     ↓
예측가격
```

---

## 3) 정의

`if ~ else` 형태의 조건을 반복하여 데이터를 나누고, 최종적으로 비슷한 값을 가진 데이터들이 하나의 Leaf에 모이도록 만드는 규칙 기반 모델임.

회귀에서는 **MSE 감소가 큰 분할**을 선택함.

---

## 4) 필수 개념

| 개념                        | 쉬운 설명                                                                 |
| --------------------------- | ------------------------------------------------------------------------- |
| **Root Node**         | 모든 데이터가 처음 출발하는 최상단 노드                                   |
| **Node**              | 데이터를 나누는 질문 또는 조건                                            |
| **Branch**            | 질문의 결과에 따라 갈라지는 경로                                          |
| **Leaf Node**         | 더 이상 나누지 않고 최종 예측을 내리는 끝점                               |
| **Split**             | 데이터를 조건에 따라 나누는 것                                            |
| **Depth**             | Root에서 Leaf까지 트리가 얼마나 깊은지를 나타내는 값                      |
| **MSE 감소**          | 데이터를 나눈 뒤 예측오차가 얼마나 줄었는지 보는 기준                     |
| **`max_depth`**     | 트리의 최대 깊이                                                          |
| **`min_samples`**   | 분할하기 위해 필요한 최소 데이터 수                                       |
| **과소적합**          | 모델이 너무 단순해서 데이터의 패턴을 충분히 배우지 못한 상태              |
| **과대적합**          | 훈련 데이터에는 지나치게 잘 맞지만 새로운 데이터에는 성능이 떨어지는 상태 |
| **가지치기(Pruning)** | 불필요하게 복잡한 가지를 제거하는 과정                                    |

---

## 5) 가장 중요한 개념 — Depth

- 너무 얕음 → **과소적합**
- 적절한 깊이 → 적절한 일반화
- 너무 깊음 → **과대적합**

> **Tree에서는 Depth가 모델 복잡도를 결정하는 핵심 요소**

---

## 6) 특징

- 규칙 기반
- 비선형 관계 학습 가능
- 변수의 실제 크기보다는 **분할 기준**이 중요
- 따라서 일반적으로 스케일링이 필요하지 않음

---

## 7) 장점

- 규칙이 직관적임
- 해석이 쉬움
- 비선형 관계 학습 가능
- 스케일링 불필요
- 변수 중요도를 확인할 수 있음

## 8) 단점

- 너무 깊어지면 과대적합
- 데이터가 조금 바뀌면 Tree 구조가 달라질 수 있음
- 단일 Tree는 예측성능이 제한될 수 있음

### 한 줄 기억

> **Decision Tree = 스무고개처럼 질문을 반복해 데이터를 나누는 모델**

---

# 9. Random Forest — 랜덤포레스트

## 1) 이름에서 얻는 힌트

- **Random** = 무작위
- **Forest** = 숲

> **여러 개의 Decision Tree를 무작위성을 이용해 만든 숲**

---

## 2) 어떤 질문에 답하는가?

> **“Tree 하나의 결과를 믿기보다 여러 Tree의 의견을 모으면 더 안정적이지 않을까?”**

---

## 3) 정의

여러 Decision Tree를 서로 다르게 학습한 뒤,

- 분류 → 다수결
- 회귀 → 예측값 평균

으로 최종 결과를 만드는 **Bagging 기반 앙상블 모델**

---

## 4) 필수 개념

| 개념                               | 쉬운 설명                                                      |
| ---------------------------------- | -------------------------------------------------------------- |
| **Ensemble**                 | 여러 모델의 결과를 합쳐 하나의 더 강한 모델을 만드는 방법      |
| **Bagging**                  | 여러 표본으로 모델을 따로 학습한 뒤 결과를 합치는 방식         |
| **Bootstrap**                | 원래 데이터에서 복원추출하여 새로운 표본을 만드는 방법         |
| **Decision Tree**            | Random Forest를 구성하는 각각의 개별 나무                      |
| **Random Feature Selection** | 각 분할에서 일부 변수만 무작위로 선택하여 후보로 사용하는 방법 |
| **평균(Average)**            | 회귀에서는 여러 Tree의 예측값 평균을 최종 예측값으로 사용      |
| **Variance 감소**            | 여러 모델의 결과를 평균하여 개별 Tree의 흔들림을 줄이는 효과   |
| **Feature Importance**       | 어떤 변수가 예측에 상대적으로 많이 기여했는지를 나타내는 지표  |

---

## 5) Bagging

**Bagging = Bootstrap + Aggregating**

> **여러 표본 생성 → 여러 모델 독립 학습 → 결과를 평균**

**복원추출 → 독립 학습 → 예측 평균 → 분산 감소**

---

## 6) 특징

- 여러 Tree가 독립적으로 학습
- Tree마다 데이터와 변수에 무작위성을 부여
- 단일 Tree보다 안정적
- 일반적으로 스케일링이 필요하지 않음

---

## 7) 장점

- 단일 Decision Tree의 과대적합을 완화할 수 있음
- 비선형 관계에 강함
- 이상치에 비교적 강건함
- Feature Importance 제공
- 스케일링 불필요

## 8) 단점

- 많은 Tree를 사용하므로 메모리 사용 증가
- 단일 Tree보다 예측이 느릴 수 있음
- 하나의 Tree보다 모델 전체 구조를 설명하기 어려움

### 한 줄 기억

> **Random Forest = 여러 Tree의 예측을 평균해 더 안정적으로 만드는 모델**

---

# 10. XGBoost

## 1) 이름에서 얻는 힌트

**XGBoost = eXtreme Gradient Boosting**

- **eXtreme** = 강화된, 고도로 최적화된
- **Gradient** = 오차가 줄어드는 방향
- **Boosting** = 약한 모델을 순차적으로 보완하여 강화

---

## 2) 어떤 질문에 답하는가?

> **“앞 Tree가 틀린 부분을 다음 Tree가 계속 고쳐 나가면 더 좋은 예측을 만들 수 있지 않을까?”**

---

## 3) 정의

Decision Tree를 순차적으로 추가하면서 **앞 모델이 남긴 오차를 다음 모델이 계속 보완하는 Gradient Boosting 계열 모델**임.

---

## 4) 필수 개념

| 개념                           | 쉬운 설명                                                                     |
| ------------------------------ | ----------------------------------------------------------------------------- |
| **Boosting**             | 앞 모델이 틀린 부분을 다음 모델이 계속 보완하는 방식                          |
| **Gradient Boosting**    | 오차가 감소하는 방향을 이용해 새로운 모델을 순차적으로 추가하는 방법          |
| **Residual**             | 실제값에서 현재 예측값을 뺀 남아 있는 오차                                    |
| **Weak Learner**         | 하나만으로는 성능이 제한적이지만 여러 개를 합쳐 성능을 높일 수 있는 기본 모델 |
| **Learning Rate**        | 새로운 Tree의 영향을 얼마나 강하게 반영할지 정하는 값                         |
| **L1/L2 Regularization** | 모델이 지나치게 복잡해지는 것을 막기 위한 벌점                                |
| **Level-wise**           | 같은 깊이의 노드를 비교적 균형 있게 확장하는 트리 성장 방식                   |

---

## 5) Boosting 핵심

Random Forest와 가장 중요한 차이임.

### Random Forest

> 여러 Tree를 **독립적으로** 만든 후 평균

### Boosting

> Tree를 **순서대로** 만들면서 앞 Tree의 오류를 다음 Tree가 보완

---

## 6) 특징

- Gradient Boosting 기반
- L1/L2 정규화를 이용한 과대적합 제어 기능
- Tree를 순차적으로 추가
- 일반적으로 스케일링 불필요

---

## 7) 장점

- 높은 예측성능을 얻을 수 있음
- 다양한 데이터에 적용 가능
- L1/L2 정규화 지원
- 널리 사용되어 관련 자료와 활용 사례가 많음

## 8) 단점

- LightGBM보다 학습이 느릴 수 있음
- 메모리 사용량이 상대적으로 클 수 있음
- 하이퍼파라미터가 많아 튜닝이 복잡할 수 있음

### 한 줄 기억

> **XGBoost = 앞 Tree의 실수를 다음 Tree가 계속 보완하는 강력한 Boosting 모델**

---

# 11. LightGBM

## 1) 이름에서 얻는 힌트

**LightGBM = Light Gradient Boosting Machine**

- **Light** = 가벼운, 빠른
- **GB** = Gradient Boosting
- **M** = Machine

> **“가볍고 빠르게 만든 Gradient Boosting”**

---

## 2) 어떤 질문에 답하는가?

> **“Gradient Boosting의 성능을 유지하면서 대용량 데이터도 빠르게 학습할 수 없을까?”**

---

## 3) 정의

Gradient Boosting 기반의 Tree 앙상블이지만, **Leaf-wise 방식**으로 Tree를 성장시켜 빠르고 효율적인 학습을 목표로 하는 모델

---

## 4) 필수 개념

| 개념                        | 쉬운 설명                                                                                    |
| --------------------------- | -------------------------------------------------------------------------------------------- |
| **GBM**               | Gradient Boosting Machine                                                                    |
| **Gradient Boosting** | 앞 모델의 오차를 다음 모델이 계속 보완하는 방식                                              |
| **Leaf**              | Tree의 최종 끝점                                                                             |
| **Leaf-wise**         | 모든 가지를 고르게 키우지 않고 오차를 많이 줄일 수 있는 Leaf를 우선적으로 깊게 확장하는 방식 |
| **Learning Rate**     | 새 Tree의 영향을 얼마나 크게 반영할지 정하는 값                                              |
| **Tree Depth**        | Tree가 얼마나 깊게 성장했는지 나타내는 값                                                    |
| **과대적합**          | Tree가 지나치게 복잡해져 훈련 데이터에 너무 맞는 현상                                        |

---

## 5) 특징

- **Leaf-wise 성장**
- 학습 속도가 빠름
- 메모리 효율이 높음
- 대규모 데이터에 유리함
- 일반적으로 스케일링 불필요

---

## 6) 장점

- 매우 빠른 학습 속도
- 적은 메모리 사용
- 대규모 데이터에 적합
- 높은 예측성능을 기대할 수 있음

## 7) 단점

- Leaf-wise 특성상 Tree가 깊어질 수 있음
- 데이터가 작을 경우 과대적합 가능성 증가
- 하이퍼파라미터 관리가 필요함

### 한 줄 기억

> **LightGBM = Leaf-wise 방식으로 빠르고 가볍게 학습하는 Gradient Boosting**

---

# 12. CatBoost

## 1) 이름에서 얻는 힌트

**CatBoost = Categorical Boosting**

여기서 `Cat`은 고양이가 아니라

> **Categorical = 범주형**

---

## 2) 어떤 질문에 답하는가?

> **“지역명, 주택유형처럼 범주형 변수가 많은 데이터도 복잡한 사전 인코딩 없이 Boosting에 사용할 수 없을까?”**

---

## 3) 정의

Gradient Boosting 기반의 Tree 앙상블 모델로, 특히 **범주형 변수를 자체적으로 처리할 수 있다는 점**이 중요한 특징

강의자료에서도 XGBoost·LightGBM과 달리 CatBoost는 범주형 변수의 자동 처리를 지원한다고 구분함

---

## 4) 필수 개념

| 개념                          | 쉬운 설명                                                      |
| ----------------------------- | -------------------------------------------------------------- |
| **Categorical Feature** | 지역명, 유형처럼 숫자의 크기보다 종류가 중요한 변수            |
| **Boosting**            | 앞 모델의 오류를 다음 모델이 계속 보완하는 방법                |
| **Symmetric Tree**      | 같은 깊이에서 동일한 분할 규칙을 적용하는 대칭적인 Tree 구조   |
| **범주형 변수 처리**    | 범주 데이터를 모델이 사용할 수 있도록 처리하는 과정            |
| **Feature Importance**  | 어떤 변수가 예측에 상대적으로 중요한지 보여주는 값             |
| **과대적합 제어**       | 모델이 훈련 데이터에 지나치게 맞지 않도록 복잡도를 관리하는 것 |

---

## 5) 특징

- 범주형 변수 처리 지원
- Boosting 기반
- Symmetric Tree 방식
- 일반적으로 스케일링 불필요
- 범주형 변수가 많은 데이터에서 전처리 부담을 줄일 수 있음

---

## 6) 장점

- 범주형 변수 처리에 편리함
- 별도의 One-Hot Encoding 부담을 줄일 수 있음
- 기본 설정으로도 비교적 안정적인 성능을 얻기 쉬운 편
- Feature Importance 확인 가능

## 7) 단점

- 학습 속도가 상대적으로 느릴 수 있음
- 모델 구조를 직접 해석하기는 선형회귀보다 어려움

### 한 줄 기억

> **CatBoost = 범주형 변수 처리에 특히 강한 Gradient Boosting 모델**

---

# 13. 반드시 구분해야 할 Ensemble 개념

## Ensemble

> **여러 모델을 결합하여 하나의 더 안정적이거나 강력한 모델을 만드는 방법**

앙상블의 대표적인 두 방식이 **Bagging과 Boosting**

---

## Bagging

> **여러 모델을 독립적으로 학습시킨 뒤 결과를 합침**

대표:

> **Random Forest**

흐름:

```text
원본 데이터
   ↓
여러 Bootstrap 표본
   ↓
Tree 1   Tree 2   Tree 3 ...
   ↓       ↓       ↓
예측      예측      예측
      ↓
     평균
```

주요 효과:

> **Variance 감소 → 모델의 흔들림 완화**

---

## Boosting

> **앞 모델의 오차를 다음 모델이 순차적으로 보완함**

대표:

- XGBoost
- LightGBM
- CatBoost

흐름:

```text
Tree 1
 ↓
남은 오차
 ↓
Tree 2
 ↓
남은 오차
 ↓
Tree 3
 ↓
...
```

핵심:

> **“앞에서 틀린 것을 뒤에서 계속 고쳐 나감.”**

---

# 14. 알고리즘별 전처리 감각

강의자료는 알고리즘 특성에 따라 전처리 전략이 달라짐을 강조함!

| 모델군                | 스케일링            | 핵심 이유                      |
| --------------------- | ------------------- | ------------------------------ |
| Linear / 정규화 / SGD | 중요                | 계수 및 정규화 안정성          |
| KNN                   | **매우 중요** | 거리 계산                      |
| SVR                   | **매우 중요** | 거리·내적·Kernel 계산        |
| Decision Tree         | 일반적으로 불필요   | 값의 크기보다 분할 순서가 중요 |
| Random Forest         | 일반적으로 불필요   | Tree의 분할 기준 사용          |
| XGBoost               | 일반적으로 불필요   | Tree 기반                      |
| LightGBM              | 일반적으로 불필요   | Tree 기반                      |
| CatBoost              | 일반적으로 불필요   | Tree 기반                      |

### 핵심 기억

> **거리로 판단한다 → 스케일링이 매우 중요함**

대표:

- KNN
- SVR/SVM

반면 Tree 계열은 변수의 절대 크기보다 **어디에서 분할할 것인가**를 중심으로 판단하므로 일반적으로 스케일링이 필요하지 않음

# 15. 알고리즘 이름만 보고 핵심을 떠올리는 방법

| 알고리즘                    | 이름에서 떠올릴 것          | 핵심 개념                 |
| --------------------------- | --------------------------- | ------------------------- |
| **Linear Regression** | Linear = 직선               | OLS, MSE, 회귀계수        |
| **Ridge**             | 계수 안정화                 | L2, Shrinkage             |
| **Lasso**             | Shrinkage + Selection       | L1, 변수 선택             |
| **ElasticNet**        | 두 규제의 결합              | L1 + L2                   |
| **SGD**               | Gradient를 따라 내려감      | Learning Rate, 반복학습   |
| **KNN**               | K개의 Nearest Neighbor      | 거리, K, Scaling          |
| **SVR**               | Support Vector + Regression | ε-tube, Kernel, C, gamma |
| **Decision Tree**     | 질문을 나무처럼 분기        | Node, Leaf, Depth         |
| **Random Forest**     | 많은 Tree의 숲              | Bagging, Bootstrap, 평균  |
| **XGBoost**           | 강화된 Gradient Boosting    | Residual, Boosting, L1/L2 |
| **LightGBM**          | 가벼운 Gradient Boosting    | Leaf-wise, 속도           |
| **CatBoost**          | Categorical Boosting        | 범주형 변수, Boosting     |

# 16. 최종 암기 — 알고리즘을 한 문장으로

### Linear Regression

> **직선식 하나로 X와 y의 관계를 설명함**

### Ridge

> **L2 패널티로 모든 계수를 조금씩 줄임**

### Lasso

> **L1 패널티로 필요 없는 변수의 계수를 0으로 만들 수 있음**

### ElasticNet

> **Ridge와 Lasso를 동시에 사용함**

### SGD

> **오차가 감소하는 방향으로 계수를 조금씩 수정함**

### KNN

> **가장 가까운 K개의 데이터를 보고 예측함**

### SVR

> **일정 범위의 오차는 허용하고 중요한 오차를 줄임**

### Decision Tree

> **스무고개처럼 질문을 반복하여 데이터를 나눔**

### Random Forest

> **여러 Decision Tree의 예측을 평균함**

### XGBoost

> **앞 Tree의 실수를 다음 Tree가 계속 보완함**

### LightGBM

> **Leaf-wise 방식으로 빠르게 학습하는 Gradient Boosting임**

### CatBoost

> **범주형 변수 처리에 강한 Gradient Boosting임**

# 17. 전체 흐름으로 이해하기

알고리즘을 각각 외우기보다 다음 흐름으로 연결하면 이해하기 쉬움\~\~

```text
① 하나의 식으로 설명할 수 있을까?
        ↓
Linear Regression
        ↓
계수가 너무 불안정한가?
        ↓
Ridge / Lasso / ElasticNet

② 가까운 사례를 이용할 수 있을까?
        ↓
KNN

③ 일정 오차를 허용하고 복잡한 관계까지 볼까?
        ↓
SVR

④ 질문을 반복해 데이터를 나눌까?
        ↓
Decision Tree

⑤ Tree 하나가 너무 불안정한가?
        ↓
Random Forest
→ 여러 Tree를 독립적으로 학습하여 평균

⑥ 앞 Tree의 실수를 계속 보완할까?
        ↓
Boosting

→ XGBoost
→ LightGBM
→ CatBoost
```

# 18. 마지막 정리

> **Linear Regression → 직선**

> **Ridge → L2 → 계수 축소**

> **Lasso → L1 → 계수 0 → 변수 선택**

> **ElasticNet → L1 + L2**

> **SGD → Gradient → Learning Rate**

> **KNN → 거리 → 가까운 K개 → Scaling**

> **SVR → ε-tube → Support Vector → Kernel → C → gamma**

> **Decision Tree → Node → Split → Leaf → Depth**

> **Random Forest → Bagging → Bootstrap → 여러 Tree 평균**

> **XGBoost → Boosting → Residual → L1/L2**

> **LightGBM → Boosting → Leaf-wise → 빠른 학습**

> **CatBoost → Categorical → 범주형 변수 처리 → Boosting**

---

## 가장 중요한 전체 문장

> **선형계열은 하나의 관계식을 찾고, KNN은 가까운 데이터를 찾으며, SVR은 허용오차와 Kernel을 이용하고, Tree는 질문으로 데이터를 나누며, Random Forest는 여러 Tree를 평균하고, Boosting 계열은 앞 Tree의 실수를 다음 Tree가 계속 보완하는 방식입니다. **
